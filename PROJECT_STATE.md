## Що увійшло в 10.5-r8

### 10.5-r8

- виправлено сумісність імпорту XLSX «Шлях» на Windows 7 / Python 3.8 для короткої помилки openpyxl `unexpected keyword argument 'tabId'`;
- compatibility retry спрацьовує лише для фактичного `tabId`-випадку;
- вихідний XLSX не переписується — виправлення робиться тільки в пам’яті;
- сторонні `TypeError` не маскуються.

### Успадковано з 10.5-r7 і попередніх

- локальний цикл щорічного звіряння персонального військового обліку через Дію: отримання → актуалізація → зовнішня фіксація;
- Taxo не імітує державний API і не вважає локальну підготовку офіційним фактом;
- редаговані робочі дані працівників / Дія / «Оберіг» відокремлені від immutable державних snapshots;
- редаговані робочі дані ТЗ / «Шлях» відокремлені від immutable джерела;
- покомпонентна звірка ТЗ з «Шлях» та історія рішень;
- єдиний реєстр документів працівників;
- відомість військово-транспортного обліку підприємства по власному/балансовому транспорту;
- контроль документів ТЗ, ДЦВ, кількох активних документів одного типу, ручного архівування;
- правила plan/fact, бланки підтвердження діяльності, графіки, табелі та шляхові листи збережені.

## Обов’язкове версіювання

- кожен завершений крок = нова ревізія `r1 → … → r10`;
- після `r10` — наступна minor-версія з `r1`;
- уже видану ревізію не перевидавати і не пересувати;
- major-розряд змінює тільки власник;
- після `10.5-r8` будь-яка нова кодова зміна — тільки **10.5-r9**;
- «злити у main» = перевірки → пакети → tag/release → PR → merge → синхронізація документації.

## Постійні межі даних

- робочі БД, SQLite, скани, кеші та персональні документи не публікуються;
- оновлення програми не повинно стирати або підміняти робочі дані;
- державні XLSX/CSV — джерело звірки/доповнення, а не заміна робочої БД;
- raw snapshots державних витягів не переписуються локальними змінами;
- порожнє значення в держреєстрі не видаляє локальне значення автоматично;
- локальне редагування в Taxo не означає зміну даних у Дії, «Оберіг» або «Шлях»;
- імпорт державного XLSX сам по собі не означає офіційно завершене звіряння;
- планові дані не оголошуються фактом без явного підтвердження.
