# Taxo v8.64 — автономні PDF/JPG Бланка

Дата: 12.09.2026

## Що виправлено

- Прибрано концептуальну помилку v8.62/v8.63: PDF/JPG більше не потребують Microsoft Word або LibreOffice.
- Додано вбудований `attestation_visual_template.pdf`, отриманий із того самого офіційного DOCX-шаблона.
- PDF створюється PyMuPDF: офіційний статичний макет лишається незмінним, поверх нього накладаються тільки дані підприємства/водія, дати, період, місце та вибрана позиція 14–19.
- DOCX і PDF/JPG створюються паралельно з одного набору даних, а не через конвертацію один одного.
- JPG1/JPG2 рендеряться з автономного двосторінкового PDF.
- На Windows накладені поля використовують системний Times New Roman за наявності; жодних файлів шрифтів у дистрибутив не додається.
- `pywin32` і COM hidden imports прибрано з Windows-збірки.
- Прокрутки всього вмісту вкладок, безстрокове зберігання бланків, фільтр `Активні / Вилучені / Усі` та `Видалити назавжди` з попередніх кандидатів збережені.

## Перевірка

- `py_compile` — OK.
- Автономний тест DOCX + PDF + JPG без офісного пакета — OK.
- PDF — рівно 2 сторінки A4.
- DOCX і PDF візуально перевірені через render → inspect; макет і структура збігаються.

## Статус

- v8.64 — кандидат для Windows-перевірки.
- GitHub `main` залишається v8.56 до підтвердження.
