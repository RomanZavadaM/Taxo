# Taxo 10.1

[Українська](README.md) · [English](README.en.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

**Stable release: v10.1 — 21 September 2026. Previous stable / rollback: v10.0.**

Taxo is a desktop application for a single transport company. It combines driver scheduling, work-time accounting, route and vehicle data, waybills, activity confirmation forms, reporting, and selective processing of analogue tachograph charts.

## Main features

- personnel and driver registry;
- vehicles, routes and route time scenarios;
- graphical driver schedule;
- work-time timesheets with split shifts, plan and fact;
- single-driver work-time control;
- separate weekly balances for **60:00 work time** and **56:00 driving time**;
- 60-day minute-by-minute driver activity register;
- PDF/Excel reports;
- waybills with numbering, route, odometer and mileage history;
- activity confirmation forms with revisions and archive;
- analogue tachograph scans, recognised intervals, manual confirmation and control protocols;
- configurable local/network/synchronised workspace with backups.
