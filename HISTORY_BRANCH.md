# Taxo — архів історії розробки до 9.0

Ця гілка зберігає повний стан репозиторію на момент переходу Taxo 9.0 до експлуатаційного режиму.

Тут навмисно залишені старі checkpoint-файли, test reports, release notes, publish status, patch-файли, старі source-архіви та попередні release workflows. Вони потрібні лише для історії, відновлення контексту та технічного аудиту.

Для щоденної експлуатації, актуальної документації та поточного коду використовуйте гілку `main`.

Контрольна точка архіву: commit `c6df515f71abbc469b06007ca8b30cd5b4f4d860` — Taxo 9.0 operational baseline після впорядкування документації.
