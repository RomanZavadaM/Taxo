# Taxo — v8.49

Локальна Windows-програма для обліку роботи водіїв, табелів, графіків змінності, попереднього контролю вимог Положення №340, бланків підтвердження діяльності та роботи з аналоговими тахокартами.

## Поточна версія

**v8.49**

### Основні можливості

- база водіїв, автомобілів, маршрутів і шаблонів маршрутів;
- детальний табель одного водія з частинами зміни та часом керування;
- місячний графік змінності: PDF графіка, окремий PDF деталізації та Excel;
- місячний табель / баланс робочого часу по всіх водіях;
- допоміжний контроль вимог Положення №340;
- бланк підтвердження діяльності за структурою чинного Додатка 3;
- резервне копіювання та відновлення бази;
- тестовий модуль аналогових тахокарт.

### Зміни v8.46–v8.49

- **v8.46:** виправлено PDF/XLSX експорт табеля, якщо водій вибраний у вкладці «Табель», але не виділений у вкладці «Водії»;
- **v8.47:** додано місячний табель / баланс по всіх водіях; у денних клітинках друкуються тільки години (`8:00`, `7:30` тощо);
- **v8.48:** назва підприємства у місячному табелі друкується більшим шрифтом за другий рядок заголовка; у бланку заповнюються «Місце / Дата» в блоці водія;
- **v8.49:** місце водія завжди автоматично береться з місця директора / представника перевізника; те саме правило діє на англійському боці.

## Друк

Базовий формат офісних документів — **A4**. Широкі графіки й місячні табелі формуються у A4 landscape і діляться на читабельні частини місяця.

## Запуск у Windows

1. Встановити Python 3.13.
2. Запустити `START.bat`.

Кореневий `main.py` розпаковує базову v8.41, застосовує оновлення v8.45 та v8.49 і запускає актуальну програму.

## Дані користувача

Робоча база даних **не зберігається в GitHub**. Постійні дані знаходяться у:

`%USERPROFILE%\Documents\DriverWorktime\`

SQLite-бази, резервні копії, робочі скани тахографа та сформовані користувачем документи до репозиторію не додаються.

## Важливо про контроль №340

Функція «Підсумки / контроль» є допоміжним автоматичним контролем, а не юридичним висновком.
