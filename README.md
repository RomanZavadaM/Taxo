# Taxo — v8.41

Локальна Windows-програма для обліку роботи водіїв, формування табелів і графіків змінності, попереднього контролю вимог Положення №340, бланків підтвердження діяльності та роботи з аналоговими тахокартами.

## Поточна версія

**v8.41**

### Основні можливості

- база водіїв, автомобілів, маршрутів і шаблонів маршрутів;
- табель із частинами зміни та окремим обліком часу **керування**;
- розрахунки тривалості у хвилинах без накопичення похибки від десяткових частин години;
- **«Підсумки / контроль»** з перевіркою часу керування, перерв 45 хв або 15+30, міжзмінного і щотижневого відпочинку;
- кольорові попередження й експорт аналізу у PDF;
- місячний **графік змінності для всіх водіїв** з PDF;
- резервне копіювання та **відновлення з резервної копії** зі страховою копією поточного стану;
- вибір профілю перевезень для контролю №340, за замовчуванням — **регулярні пасажирські перевезення**;
- модуль аналогових тахокарт;
- формування бланка підтвердження діяльності за структурою чинного Додатка 3 до Положення №340.

### Зміни v8.41

- реквізит посвідчення водія виправлено на **дату видачі посвідчення**, а не місце/орган видачі;
- для дати видачі є календар і окреме поле в БД;
- генератор бланка повернуто до структури чинного Додатка 3 без довільного переписування службових рядків;
- в українських пунктах 10–11 використовується дата видачі посвідчення;
- англійський бік заповнюється відповідно до структури його полів;
- **усі значення, які підставляє Taxo у бланк, виділяються жирним шрифтом**.

## Запуск у Windows

1. Встановити **Python 3.13**.
2. Запустити `START.bat`.

Кореневий `main.py` автоматично розпаковує актуальний пакет:

`releases/Taxo_v8_41_source.zip`

і запускає його локально.

## Де зберігаються дані

Робоча база даних **не зберігається в GitHub**.

Постійні дані користувача знаходяться у:

`%USERPROFILE%\Documents\DriverWorktime\`

Зокрема там зберігаються:

- основна SQLite-база;
- резервні копії;
- сформовані документи та звіти;
- робочі дані модуля тахографа.

## Важливо про контроль №340

Функція **«Підсумки / контроль»** є допоміжним автоматичним контролем, а не юридичним висновком. Спеціальні винятки залежать від виду перевезень і поступово додаються до відповідних профілів.

## Репозиторій

У GitHub публікується програма та необхідні шаблони. SQLite-бази, резервні копії, робочі скани тахографа та сформовані користувачем документи не додаються.
