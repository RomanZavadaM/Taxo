# Taxo — облік роботи водіїв, графіки, табелі та тахограф

**Taxo** — настільна програма для Windows для ведення даних водіїв, планування та обліку робочого часу, формування графіків і табелів, роботи з Бланком підтвердження діяльності та модуля тахографа.

Актуальний контрольний реліз: **v8.56**.

## Що завантажувати

Готові файли знаходяться у розділі **Releases**:

https://github.com/RomanZavadaM/Taxo/releases

Для звичайного користування на Windows рекомендовано:

- **`Taxo_v8_56_Setup_Windows_x64.exe`** — звичайний інсталятор Windows x64;
- **`Taxo_v8_56_Windows_x64_Portable.zip`** — portable-версія без встановлення;
- **`Taxo_v8_56_source.zip`** — контрольний пакет вихідного коду, для звичайної роботи не потрібен;
- **`SHA256SUMS_RELEASE.txt`** — контрольні SHA-256 суми релізних файлів.

Для `Setup.exe` та portable-версії **не потрібно окремо встановлювати Python або бібліотеки Python**.

## Встановлення Windows-версії

1. Відкрийте розділ **Releases** і виберіть реліз **Taxo v8.56**.
2. Завантажте `Taxo_v8_56_Setup_Windows_x64.exe`.
3. Перед оновленням уже робочої системи бажано зробити резервну копію каталогу даних `Documents\DriverWorktime`.
4. Запустіть інсталятор.
5. Пройдіть стандартні кроки встановлення.
6. Після встановлення запускайте **Taxo** з ярлика або меню Windows.

### Якщо Windows показує попередження

Поточний тестовий реліз ще не має комерційного цифрового підпису. Windows SmartScreen може показати попередження про невідомого видавця.

Запускайте інсталятор лише якщо він завантажений з офіційного GitHub-репозиторію `RomanZavadaM/Taxo`. За потреби додатково перевірте SHA-256 за файлом `SHA256SUMS_RELEASE.txt`.

## Перший запуск

Під час першого запуску Taxo використовує окремий каталог даних користувача:

```text
%USERPROFILE%\Documents\DriverWorktime\
```

Основні робочі дані не зберігаються всередині каталогу встановленої програми. Тому перевстановлення або оновлення Taxo не повинно видаляти базу користувача.

Основні каталоги/файли даних:

```text
Documents\DriverWorktime\Data\driver_worktime.sqlite3
Documents\DriverWorktime\Data\tachograph_test.sqlite3
Documents\DriverWorktime\Data\TachographScans\
```

> `tachograph_test.sqlite3` використовується тестовим модулем тахографа окремо від основної робочої бази.

## Як користуватися Taxo

Типова послідовність роботи:

1. **Водії** — внесіть або перевірте картки водіїв і дані посвідчень.
2. **Автомобілі / маршрути** — підготуйте довідники, які використовуються у графіках і табелях.
3. **Планування** — сформуйте планований графік роботи/змінності.
4. **Табель** — ведіть фактичний робочий час, частини зміни, час керування та інші параметри дня.
5. **Підсумки / контроль** — перевіряйте місячні підсумки й контрольні зауваження за даними табеля.
6. **Друк та експорт** — формуйте потрібні PDF/XLSX документи, місячний графік, табель та деталізацію.
7. **Бланк підтвердження діяльності** — формуйте, зберігайте й контролюйте бланки для відповідних періодів діяльності/відпочинку.
8. **ТАХО** — імпортуйте скани аналогових тахографних шайб, перевіряйте розпізнані інтервали та використовуйте підтверджені дані для фактичного обліку.

Автоматичне розпізнавання аналогової тахографної шайби слід розглядати як допоміжний механізм: перед перенесенням даних у робочий облік інтервали треба перевірити по зображенню.

## Бланк підтвердження діяльності у v8.56

У v8.56 програма може не лише показувати історичні незакриті проміжки, а й підготувати **поточний бланк до наступного запланованого ТАХО-виїзду**.

Дата бланка відповідає даті завершення періоду, який цей бланк закриває. Для послідовних календарних ТАХО-днів зайвий бланк між ними не формується.

## Оновлення на нову версію

Перед оновленням рекомендується зробити резервну копію:

```text
%USERPROFILE%\Documents\DriverWorktime\
```

Після цього можна встановити нову версію Taxo. Програма та інсталятор не повинні включати або видаляти робочу базу користувача.

Для кожної контрольної версії використовуються окремі релізні файли, наприклад:

```text
Taxo_v8_56_Setup_Windows_x64.exe
Taxo_v8_56_Windows_x64_Portable.zip
```

## Portable-версія

Якщо встановлення не потрібне:

1. Завантажте `Taxo_v8_56_Windows_x64_Portable.zip`.
2. Повністю розпакуйте ZIP в окрему папку.
3. Відкрийте папку `Taxo`.
4. Запустіть `Taxo.exe`.

Важливо: portable-збірка має структуру **onedir**. Не переносіть лише один `Taxo.exe` — поруч потрібна папка `_internal` та інші файли збірки.

Приклад:

```text
Taxo\
├── Taxo.exe
└── _internal\
```

Portable-версія використовує той самий каталог даних `Documents\DriverWorktime`, тому її можна застосовувати для тестування нової збірки без копіювання бази в каталог програми.

## Резервне копіювання

Найважливіше правило: **робочі дані не повинні зберігатися лише в каталозі програми**.

Для ручної страхової копії можна скопіювати весь каталог:

```text
%USERPROFILE%\Documents\DriverWorktime\
```

у інший диск/каталог перед встановленням нової версії або великими змінами даних.

## Перевірка SHA-256 у Windows

Поруч із релізом публікується `SHA256SUMS_RELEASE.txt`.

У PowerShell SHA-256 завантаженого інсталятора можна перевірити командою:

```powershell
Get-FileHash .\Taxo_v8_56_Setup_Windows_x64.exe -Algorithm SHA256
```

Отримане значення повинно збігатися зі значенням для цього файлу у `SHA256SUMS_RELEASE.txt`.

## Для розробки з вихідного коду

Кінцевому користувачу цей розділ не потрібен. Для запуску з Python використовується `main.py`; залежності перелічені в `requirements.txt`.

```bat
START.bat
```

База користувача, резервні копії та робочі скани не повинні потрапляти в GitHub-репозиторій або source ZIP.

## Контроль версій

Гілка `main` захищена. Зміни проходять через Pull Request і перевірку Windows-збірки. Контрольні релізні теги `v*` захищені від звичайного переписування/видалення.

Детальний внутрішній стан розробки та історія змін зберігаються в `PROJECT_STATE.md`.
