# Taxo 9.0

**Taxo** — настільна система для обліку роботи водіїв і персоналу автопідприємства, планування змін, формування шляхових документів, контролю робочого часу та роботи з даними тахографа.

[Українська](README.md) | [English](README.en.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md)

> **Поточний стабільний реліз: v9.0** — 17.09.2026.  
> Система переведена у режим експлуатації та подальшого вдосконалення за результатами реальної роботи.

## Основний функціонал

- єдиний реєстр працівників із ролями водія, диспетчера, механіка, лікаря та інших працівників;
- графік роботи водіїв і персоналу, план/факт та місячні табелі;
- маршрути, автомобілі, плановий і фактичний пробіг;
- формування, нумерація, архівування і повторний друк шляхових листів форми №1-АП;
- бланки підтвердження діяльності водія;
- облік тахографічних шайб, сканів, інтервалів та результатів розпізнавання;
- контроль режимів роботи відповідно до налаштованих правил: тижневі баланси, 56 годин керування, 60 годин робочого часу, середні показники;
- 60-денний реєстр діяльності водія з похвилинною деталізацією та контролем 24:00 кожної доби;
- PDF/Excel-звіти, місячні баланси та контрольні протоколи;
- локальне, мережеве або синхронізоване робоче сховище з резервними копіями та блокуванням одночасного доступу.

Детальний функціональний опис: **[Опис системи](docs/SYSTEM_OVERVIEW.md)**.

## Правила експлуатації

1. Перед початком роботи переконайтесь, що відкрите правильне робоче сховище.
2. При використанні спільної мережевої/хмарної папки Taxo запускається **лише на одному комп'ютері одночасно**.
3. Для OneDrive/Dropbox/Google Drive після закриття Taxo дочекайтесь завершення синхронізації перед запуском на іншому ПК.
4. Не видаляйте вручну робочі бази, архіви шляхівок, тахографічні скани або службові файли сховища.
5. Перед оновленням програми перевіряйте резервну копію та закривайте всі копії Taxo.

Повна процедура: [Адміністрування та робоче сховище](docs/ADMIN_GUIDE.md).

## Дані та сумісність

За замовчуванням робочі дані зберігаються у `Documents/DriverWorktime`, але сховище можна перенести у локальну, мережеву або синхронізовану папку. Оновлення бази виконуються адитивно: історичні записи не видаляються під час штатної міграції.

Основні дати у програмі відображаються у форматі `ДД.ММ.РРРР`.

## Для розробки

Вихідний запуск на Windows:

```text
START.bat
```

або Python 3.13:

```text
py -3.13 taxo_app.py
```

Залежності встановлюються з `requirements.txt`. Основна гілка `main` відповідає стабільній опублікованій базі; зміни рекомендується вносити через окремі гілки та Pull Request.
