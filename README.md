# Taxo — v8.56

Локальна Windows-програма для обліку роботи водіїв, табелів, графіків змінності, допоміжного контролю вимог Положення №340, Бланків підтвердження діяльності та вибіркового контролю аналогових тахокарт.

## Поточна контрольна версія

**v8.56** — перевірено 11.09.2026.  
Наступна версія для розробки: **v8.57**.

Детальний зафіксований стан: `PROJECT_STATE.md`.  
Контроль публікації та SHA-256: `RELEASE_V8_56.md`.

## Головне у v8.50–v8.56

- режими обліку дня: ТАХО / `Без тахо — стандартні 8 год` / ручний;
- контроль Бланків підтвердження у 56-денному вікні;
- один ТАХО-блок на маршрутний день від першого виїзду до останнього повернення;
- автоматичний поділ міжмаршрутних проміжків за видами діяльності (14/15/16/18/19);
- дата Бланка підтвердження завжди дорівнює даті завершення його періоду;
- у v8.56 програма дивиться вперед у графік та показує поточний період до найближчого запланованого ТАХО-виїзду зі статусами `ПОТОЧНИЙ — ПІДГОТУВАТИ` / `ПОТОЧНИЙ — БЛАНК ГОТОВИЙ`;
- тахокарти є тільки вибірковим контролем і не можуть автоматично змінювати основний графік або табель.

## Запуск у Windows

1. Встановити Python 3.13.
2. Запустити `START.bat`.

У гілці `release-v8.56` кореневий `main.py` відновлює точний runtime v8.56 з перевіреної бази та текстових патчів. Після складання він звіряє SHA-256 `main.py` і `tachograph.py`; при невідповідності запуск припиняється.

## Дані користувача

Робоча база даних **не зберігається в GitHub**. Постійні дані знаходяться у:

`%USERPROFILE%\Documents\DriverWorktime\`

SQLite-бази, резервні копії, робочі скани тахографа та сформовані користувачем документи до репозиторію не додаються.

## Документи і друк

- базовий офісний формат — A4;
- широкі місячні графіки/табелі — A4 landscape;
- у денних клітинках місячного табеля / балансу показуються **тільки години** (`8:00`, `7:30`), не час початку/кінця зміни;
- дати в UI — `ДД.ММ.РРРР`.
