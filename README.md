# Taxo — v8.45

Локальна Windows-програма для обліку роботи водіїв, формування табелів і графіків змінності, попереднього контролю вимог Положення №340, бланків підтвердження діяльності та роботи з аналоговими тахокартами.

## Поточна версія

**v8.45**

### Основні можливості

- база водіїв, автомобілів, маршрутів і шаблонів маршрутів;
- табель із частинами зміни та окремим обліком часу керування;
- розрахунки тривалості у хвилинах;
- «Підсумки / контроль» для допоміжної перевірки вимог Положення №340;
- резервне копіювання та відновлення бази;
- модуль аналогових тахокарт;
- формування бланка підтвердження діяльності за структурою чинного Додатка 3;
- графік змінності з окремими PDF та Excel-експортом.

### Останні зміни

- бланк підтвердження діяльності приведено до структури чинного Додатка 3;
- реквізит посвідчення водія використовується як дата видачі, а не місце/орган видачі;
- значення, які Taxo підставляє у бланк, друкуються жирним шрифтом;
- графік змінності переведено на стандартний офісний формат A4 landscape;
- місяць у графіку ділиться на три читабельні частини для друку;
- додано редагований Excel;
- основний PDF графіка та PDF деталізації формуються окремо;
- у заголовках графіка друкується назва місяця українською, а не його номер.

## Запуск у Windows

1. Встановити Python 3.13.
2. Запустити `START.bat`.

Кореневий `main.py` використовує базовий пакет v8.41 та автоматично застосовує актуальні зміни v8.45 із файлів:

- `releases/Taxo_v8_45_main.part1`
- `releases/Taxo_v8_45_main.part2`
- `releases/Taxo_v8_45_main.part3`
- `releases/Taxo_v8_45_main.part4`

Після цього запускається актуальна версія програми.

## Де зберігаються дані

Робоча база даних не зберігається в GitHub.

Постійні дані користувача знаходяться у:

`%USERPROFILE%\Documents\DriverWorktime\`

Там зберігаються основна SQLite-база, резервні копії, сформовані документи, звіти та робочі дані модуля тахографа.

## Важливо про контроль №340

Функція «Підсумки / контроль» є допоміжним автоматичним контролем, а не юридичним висновком. Спеціальні винятки залежать від виду перевезень і поступово додаються до відповідних профілів.

## Репозиторій

У GitHub публікується програма та необхідні шаблони. SQLite-бази, резервні копії, робочі скани тахографа та сформовані користувачем документи не додаються.
