# Taxo — v8.36

Локальна Windows-програма для обліку робочого часу водіїв, формування табелів, бланків підтвердження діяльності, планування маршрутів, графіків змінності та роботи з аналоговими тахокартами.

## Поточна версія

**v8.36**

### Основні можливості та останні зміни

- вибір водія безпосередньо на вкладці **«Табель»**;
- редагування робочого дня з частинами зміни та окремим полем **«Кер.»** для точного обліку часу керування;
- виправлено збереження відредагованого робочого дня після переходу на формат **ГГ:ХХ**;
- виправлено розташування календаря та полів у вікні редагування дня;
- небезпечну кнопку **«⚠ Заповнити робочі дні 8 год»** перенесено в кінець панелі та додано обов'язкове підтвердження масової дії;
- аналіз **«Підсумки / контроль»** виконує попередню перевірку за Положенням №340, окремо враховуючи час керування, перерви 45 хв або 15+30, міжзмінний та щотижневий відпочинок;
- усі нормативні розрахунки виконуються у хвилинах, щоб уникати похибок десяткових частин години;
- у вікні аналізу є кольорове виділення норми, зауважень і помилок та можливість зберегти звіт у PDF;
- додано **місячний графік змінності для всіх водіїв** з переглядом, підсумками та друком у PDF A3;
- експорт табеля PDF/XLSX включає всі календарні дні вибраного місяця;
- модуль тахографа підтримує імпорт сканів, пошук шайб, кандидатів інтервалів, 24-годинну шкалу та підсумкову статистику;
- формування **«Бланка підтвердження діяльності»** з датами у форматі **ДД.ММ.РРРР**.

## Запуск у Windows

1. Встановити **Python 3.13**.
2. Запустити файл `START.bat`.

У корені репозиторію знаходиться запускний модуль. Повний пакет v8.36 збережено в:

`releases/Taxo_v8_36_source.zip`

Під час запуску пакет автоматично розпаковується локально і запускається основна програма.

## Де зберігаються дані

Робоча база даних **не зберігається в GitHub**.

Постійні дані користувача знаходяться у:

`%USERPROFILE%\Documents\DriverWorktime\`

Зокрема там зберігаються:

- основна SQLite-база;
- резервні копії;
- сформовані документи та звіти;
- робочі дані модуля тахографа.

## Контроль Положення №340

Функція **«Підсумки / контроль»** є допоміжним автоматичним контролем. Вона аналізує, зокрема:

- щоденний і тижневий час керування;
- двотижневий ліміт керування;
- перерви у керуванні після накопичення 4 год 30 хв;
- міжзмінний відпочинок;
- щотижневий відпочинок;
- робочий час, нічну роботу та інші контрольні показники.

«Частини зміни» в Taxo — це внутрішній технічний поділ дня для точного обліку часу керування і проміжків між частинами, а не автоматичний юридичний висновок про вид відпочинку.

## Примітка

SQLite-бази, резервні копії, робочі скани та сформовані користувачем документи не додаються до репозиторію.
