# Taxo — контрольний список релізу

Для кожної нової версії:

1. Скопіювати попередню перевірену папку у нову (`Taxo_v8_54`, `Taxo_v8_55`, ...).
2. Не змінювати стару контрольну папку.
3. Внести лише узгоджені зміни.
4. Виконати `py -3.13 -m py_compile main.py tachograph.py`.
5. Прогнати smoke-test на окремій тимчасовій SQLite-БД.
6. Якщо змінювались PDF/XLSX/DOCX — згенерувати тестові файли та перевірити їх.
7. Переконатися, що ZIP не містить БД користувача, `__pycache__`, тимчасових файлів.
8. Оновити `README.md`, `PROJECT_STATE.md`, `VERSION.txt`.
9. Записати SHA-256 релізних файлів у `SHA256SUMS.txt`.
10. Створити ZIP з унікальною внутрішньою папкою версії.
11. Дати користувачу ZIP для локальної перевірки.
12. Після підтвердження — GitHub commit + tag тієї самої версії.
13. Зберегти контрольний ZIP у ще одному незалежному місці (ChatGPT Library або локальний архів).
