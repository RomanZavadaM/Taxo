# Taxo — контрольний список релізу

Для кожної нової версії:

1. Скопіювати попередню перевірену папку у нову (`Taxo_v8_61`, `Taxo_v8_62`, ...).
2. Не змінювати стару контрольну папку.
3. Внести лише узгоджені зміни.
4. Виконати `py -3.13 -m py_compile main.py tachograph.py attestation_render.py` (якщо модуль присутній).
5. Прогнати smoke-test на окремій тимчасовій SQLite-БД.
6. Якщо змінювались PDF/XLSX/DOCX/JPG — згенерувати тестові файли, перевірити кількість сторінок і візуально перевірити рендер.
7. Для Бланка підтвердження перевірити DOCX/PDF/JPG, дату = `Період по`, обидві мови та одну позицію 14–19. PDF/JPG мають створюватися **без Word/LibreOffice** з `attestation_visual_template.pdf` та візуально збігатися з DOCX. Окремо перевірити, що в PyInstaller bundle присутній візуальний PDF-шаблон.
8. Перевірити редагування/вилучення/відновлення всіх наявних форматів Бланка.
9. Переконатися, що ZIP не містить БД користувача, `__pycache__`, `.pyc`, тимчасових PDF/JPG.
10. Оновити `README.md`, `PROJECT_STATE.md`, `VERSION.txt`, `RECOVERY_MANIFEST.txt`, `TEST_REPORT_*.txt`.
11. Записати SHA-256 релізних файлів у `SHA256SUMS.txt`.
12. Створити ZIP з унікальною внутрішньою папкою версії.
13. Дати користувачу ZIP для локальної перевірки.
14. Після підтвердження — GitHub commit/tag тієї самої версії.
15. Зберегти контрольний ZIP щонайменше у двох місцях: локально + GitHub/Library.
