# Історія розвитку Taxo

У корені репозиторію збережено історичні технічні артефакти попередніх версій. Вони потрібні для простежуваності розвитку, відновлення контексту та перевірки старих рішень, але **не є актуальною експлуатаційною документацією**.

## Типи історичних файлів

- `CHECKPOINT_v*` — контрольні точки окремих етапів;
- `TEST_REPORT_v*` — результати тестування кандидатів;
- `PUBLISH_STATUS_v*` — стан публікації старих кандидатів;
- `RELEASE_NOTES_v*` — примітки до попередніх релізів;
- `PATCH_v*` — службові патчі старої схеми публікації;
- `UI_AUDIT_*` — історичні аудити інтерфейсу;
- `releases/` — ранні джерельні архіви/частини старих версій.

## Що є актуальним зараз

Для поточної роботи використовувати:

1. `README.md`;
2. `docs/README.md`;
3. `CHECKPOINT_CURRENT.md`;
4. `PROJECT_STATE.md`;
5. `VERSION.txt`;
6. `RELEASE_NOTES_v9_0.md`;
7. GitHub Release `v9.0`.

## Чому історія не видалена

Проєкт довго розвивався через послідовні кандидатні версії. Старі файли містять корисні рішення щодо міграцій, UI, документів і тестів. Їх збережено як технічний журнал, щоб уникнути повторного винайдення вже вирішених проблем.
