# Робота з тахографом — Taxo 9.0

Модуль ТАХО призначений для вибіркового контролю аналогових тахокарт і використання перевірених інтервалів як додаткового джерела даних.

## Робочий порядок

1. Додайте скан тахокарти до каталогу.
2. Відкрийте його у вкладці «Перегляд».
3. Перевірте метадані: водія, дату, транспорт, якщо вони визначені.
4. Перегляньте шкалу дня та список розпізнаних інтервалів.
5. Порівняйте інтервали зі сканом.
6. Виправте або підтвердьте результат.
7. За потреби сформуйте/збережіть протокол контролю.

## Автоматичне розпізнавання

Розпізнані інтервали є кандидатами. Вони можуть містити похибки через якість скану, контраст, розмітку тахокарти або особливості заповнення.

Перед використанням у звітах важливі інтервали потрібно перевірити вручну.

## Пріоритет даних

У 60-денному реєстрі підтверджені вручну дані тахографа мають вищу довіру, ніж автоматично розпізнані кандидати. Автоматичний кандидат не повинен непомітно замінювати підтверджені дані табеля або первинного документа.

## Розбіжності з табелем

Якщо тахокарта не збігається з табелем:

- не виправляйте табель автоматично;
- перевірте дату, водія і транспорт;
- перевірте, чи правильно прочитано інтервал;
- перевірте первинні документи;
- після встановлення факту внесіть виправлення у правильне джерело.

## Протоколи

Протокол контролю фіксує результат перевірки конкретної тахокарти. Історія протоколів використовується для простежуваності перевірок.

## Практичні поради для сканів

- скан має бути рівним, без перспективного перекосу;
- уникайте сильного засвічення та тіней;
- не обрізайте робочу область диска;
- для повторної перевірки зберігайте оригінальний скан;
- не видаляйте файл скану вручну зі сховища, якщо він уже зареєстрований у системі.
