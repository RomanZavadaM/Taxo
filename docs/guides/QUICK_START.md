# Taxo 9.0 — швидкий старт

## 1. Виберіть спосіб запуску

Для звичайної експлуатації рекомендується **Windows Setup** або **Windows Portable** / відповідний macOS Portable із GitHub Release `v9.0`.

`Taxo_v9_0_START.zip` призначений для тестування та запуску з Python 3.13. На Windows після розпакування запускається `START.bat`.

## 2. Перший запуск

Під час першого запуску Taxo визначає робоче сховище. За замовчуванням це каталог у `Documents/DriverWorktime`.

Робоче сховище — це не папка програми. Саме там зберігаються:

- основна БД;
- тахографічна БД;
- скани тахокарт;
- сформовані PDF/DOCX/JPG;
- шляхові листи;
- резервні копії;
- журнали помилок.

Якщо на комп’ютері вже є попередня робоча база Taxo, не створюйте нову вручну поверх неї. Підключіть або перенесіть існуюче сховище штатним пунктом `Файл → Робоче сховище…`.

## 3. Мінімальне початкове налаштування

Перед реальною роботою заповніть дані в такому порядку:

1. `Підприємство` — назва, адреса, представник, контактні дані, англомовні реквізити для Бланка підтвердження.
2. `Працівники` — внесіть персонал, ролі, табельні номери, дати прийняття.
3. Для працівників із роллю водія — перевірте картку водія.
4. `Автомобілі` — внесіть транспортні засоби й гаражні дані.
5. `Маршрути` — створіть маршрути та часові сценарії.
6. `Підприємство → Пули серій і номерів` — налаштуйте нумерацію шляхових листів до першого офіційного випуску.

## 4. Типовий робочий день

1. Відкрийте графік водіїв на потрібну дату.
2. Перевірте водія, маршрут, автомобіль, початок/кінець і частини зміни.
3. За потреби сформуйте шляхівку з графіка.
4. Упродовж/після дня внесіть фактичні дані, які не надходять автоматично.
5. Якщо є тахокарта — додайте її в модулі `ТАХО`, перевірте розпізнавання й підтвердьте фактичні інтервали.
6. Перевірте табель і контроль режимів праці/відпочинку.
7. За потреби сформуйте Бланк підтвердження, 60-денний реєстр або інший звіт.

## 5. Перевірка перед друком документа

Перед офіційним використанням PDF/DOCX перевірте:

- ПІБ і табельний номер;
- дату або період;
- маршрут і транспортний засіб;
- час початку/закінчення;
- номер документа;
- показники пробігу, якщо вони введені;
- дату формування звіту;
- відсутність «Невизначено» там, де фактичні дані повинні бути внесені;
- правильність автоматично розпізнаних тахографічних інтервалів.

## 6. Завершення роботи

Закрийте Taxo штатно. Якщо робоче сховище синхронізується через OneDrive/Dropbox/Google Drive і його використовує інший комп’ютер, дочекайтеся завершення синхронізації перед запуском Taxo на іншому ПК.

## 7. Якщо щось не так

Не видаляйте БД і не копіюйте поверх неї випадкові файли. Спочатку перегляньте [Типові проблеми](TROUBLESHOOTING.md) або зробіть резервну копію робочого сховища.
