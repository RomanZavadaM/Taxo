# Типові проблеми — Taxo 10.0

## Програма не запускається

Для `START.bat` перевірте Python 3.13 і успішне встановлення пакетів з `requirements.txt`. Для готової збірки спробуйте запуск із локальної папки, а не безпосередньо з ZIP.

## Робоче сховище зайняте

Переконайтесь, що Taxo не запущено на іншому комп’ютері. Якщо попередній запуск завершився аварійно, спочатку переконайтесь, що іншої активної копії немає, і лише тоді використовуйте штатне відновлення блокування.

## PDF/Excel не перезаписується

Найчастіша причина — файл відкритий у переглядачі або Excel. Закрийте його й повторіть операцію або скористайтеся створенням копії з новою назвою.

## Дані не збігаються між комп’ютерами

Якщо використовується OneDrive/Dropbox/Google Drive, перевірте стан синхронізації. Не запускайте Taxo на другому ПК, доки перший не закритий і синхронізація не завершена.

## У 60-денному реєстрі є «Невизначено»

Це означає відсутність достатнього підтвердженого джерела для певного проміжку. Перевірте табель, тахокарту, бланки підтвердження та інші первинні дані. Не замінюйте «Невизначено» відпочинком без фактичної підстави.

## Тахокарта розпізнана неправильно

Перевірте якість скану, водія/дату, збільште перегляд, відредагуйте інтервали вручну та підтвердьте лише перевірений результат.

## Після оновлення не видно старих даних

Насамперед перевірте, яке робоче сховище відкрито. Не створюйте нову базу і не копіюйте файли навмання. Зафіксуйте шлях до поточного сховища та зверніться до відповідального/розробника.

## Помилка бази даних

Припиніть внесення нових даних. Не відкривайте SQLite сторонніми редакторами. Збережіть повідомлення про помилку, версію Taxo, кроки, після яких вона виникла, і файл журналу `Taxo_errors.log`, якщо він створений.

## Що додати до повідомлення про проблему

Вкажіть:
- версію Taxo;
- Windows/macOS і архітектуру;
- розділ програми;
- точну послідовність дій;
- очікуваний результат;
- фактичний результат;
- текст помилки або скриншот;
- чи повторюється проблема після перезапуску;
- чи використовується локальне, мережеве або хмарне сховище.

Не публікуйте у відкритому GitHub issue базу даних, скани тахокарт або документи з персональними даними.
