# Звіти і друковані документи — Taxo 10.x

## Загальні правила

Перед формуванням звіту перевірте вибраного працівника/водія, період, джерела даних і дату формування. Якщо PDF або Excel уже відкритий в іншій програмі, Taxo може не мати змоги перезаписати його — закрийте файл або створіть копію з новою назвою.

## Місячний табель

Місячний табель формується за вибраним водієм або персоналом та місяцем. Перед друком перевірте:
- види днів;
- план/факт;
- частини зміни;
- підсумкові години;
- дні без факту;
- примітки.

## Графік змінності

**Побудова графіка для конкретних водіїв (10.11-r1):** «Графіки → Місячний графік змінності водіїв» → місяць → **«Водії для звіту…»** → позначити людей → «Застосувати» → вибрати вид документа → **«Переглянути»** або **«Зберегти…»**. Є PDF графіка, PDF деталізації, Excel. Вибір для друку не змінює загальну таблицю або записи обліку.

Ім'я файлу включає вид, рік-місяць, склад водіїв. Наприклад: `Графік_змінності_2026-11_Галань-Михайло.pdf`. Для групи додається короткий код, щоб інша група тієї ж чисельності не перезаписала попередній документ. `3 част.` означає три частини зміни, не три години.

Графік показує планові зміни по водіях. Для складних/поділених змін використовуйте деталізацію, де видно окремі частини та проміжки.

На добовому графіку окремо доступний **«Аудит графіків…»**. Це перевірка якості введених часових даних, а не нормативний звіт: вона шукає перекриття, неповні часові пари, керування поза роботою, порожні частини та активні маршрути без часового сценарію.

## Контроль №340 / баланс одного водія

У вікні можна вибрати іншого водія без повернення до табеля. Контроль відображає окремо:
- робочий час;
- час керування;
- тижневий баланс до 60:00 робочого часу;
- тижневий баланс до 56:00 керування;
- середні показники;
- перерви й відпочинки.

Перед створенням PDF можна змінити «Дату формування». Кнопка «Відкрити PDF» створює актуальний документ у робочому сховищі й відкриває його стандартним переглядачем.

## 60-денний реєстр діяльності

Документ має два рівні:

1. зведення по кожному календарному дню;
2. детальний журнал інтервалів із точністю до хвилини.

Кожна доба контролюється до 24:00. Якщо джерел недостатньо, проміжок позначається «Невизначено». Це сигнал для додаткової перевірки, а не помилка друку.

Для реєстру також можна встановити власну дату формування.

## Бланк підтвердження діяльності

Бланк може формуватися у DOCX/PDF/JPG. Перед створенням перевірте період і вид діяльності. При редагуванні вже сформованого бланка стара редакція архівується.

## Шляховий лист

Перед друком перевірте серію/номер, водія, транспорт, маршрут, календарні дати, точки маршруту, планові часи та показники спідометра. Для рейсу через північ у друкованому документі мають бути фактичні календарні дати. Дані, що підставляються Taxo, друкуються приблизно на 20% більшим шрифтом, а кутовий штамп заповнюється реквізитами підприємства з налаштувань.

## Табель П-5

У розділі **«Персонал → Звіти»** доступні PDF для друку та редагований Excel типової форми № П-5. Звіт містить календарні дні, коди 01–30, фактичні години, підсумкові категорії, причини неявок, стать, оклад/тарифну ставку та підписні блоки.

Якщо є робочий план без внесеного факту, перед формуванням Taxo дає три варіанти: **підставити план / залишити без факту / скасувати**. Підставлений план виділяється та супроводжується явною приміткою у PDF/XLSX.

## Стан документів транспортних засобів

У **«Звіти → Стан документів транспортних засобів»** можна сформувати стан на довільну дату. Для минулої дати Taxo враховує історичні записи. Якщо одночасно чинні кілька документів одного типу, вони не архівуються автоматично; контроль обирає придатний чинний запис, а реєстр зберігає всі активні записи. ДЦВ страхування є необов’язковим і його відсутність не вважається проблемою.

Доступні:
- усі активні транспортні засоби або ширший список;
- повний список документів або тільки проблемні/попереджувальні позиції;
- статуси «Відсутній», «Прострочений», «Закінчується», «Актуальний»;
- PDF для друку;
- Excel для аналізу.

## Перегляд і друк

Для архівних бланків кнопки DOCX / PDF / JPG відкривають саме відповідний формат зовнішньо. «Перегляд у Taxo» відкриває внутрішній переглядач і надає перевагу PDF, потім JPG, потім DOCX.

На Windows PDF та зображення можна передати на принтер без зовнішнього PDF-переглядача. На macOS/Linux використовується системна черга друку.

## Excel

Excel-звіти призначені для аналізу і, де це передбачено, ручного доопрацювання. Не використовуйте відредагований Excel як спосіб непомітно змінити первинні дані Taxo: зміни, які мають впливати на наступні звіти, треба внести в систему.

## Архівування

Готові документи зберігайте в структурі робочого сховища. Не переносіть окремі файли вручну без потреби, якщо вони зареєстровані в базі або входять до історії ревізій.

## Простий місячний графік працівників — 10.11-r2

Для «Простого місячного графіка роботи» файл має показувати не лише місяць, а й вид документа та вибірку. Приклади:

- `Простий_графік_роботи_2026-11_усі-працівники.pdf`;
- `Простий_графік_роботи_2026-11_Галань-Михайло.pdf`;
- для групи — перші прізвища та короткий код конкретного набору, щоб інша група того самого місяця не перезаписала файл.

У PDF цього простого графіка колонка «Роль» не друкується: місце віддано ПІБ і дням місяця. В Excel колонка «Роль» зберігається для робочого опрацювання. Це не змінює ролі працівника в базі чи інших звітах.

## Стабільна версія 10.18-r3

У цьому випуску поліпшено сортування робочих реєстрів, а не правила підрахунку звітних годин. Як і раніше, перед друком перевірте період, обраних працівників та джерела фактичних даних: план не підмінює факт автоматично.
