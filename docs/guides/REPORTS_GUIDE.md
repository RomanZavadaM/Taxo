# Звіти і друковані документи — Taxo 9.0

## Загальні правила

Перед формуванням звіту перевірте вибраного працівника/водія, період, джерела даних і дату формування. Якщо PDF або Excel уже відкритий в іншій програмі, Taxo може не мати змоги перезаписати його — закрийте файл або створіть копію з новою назвою.

## Місячний табель

Місячний табель формується за вибраним водієм або персоналом та місяцем. Перед друком перевірте:
- види днів;
- план/факт;
- частини зміни;
- підсумкові години;
- дні без факту;
- примітки.

## Графік змінності

Графік показує планові зміни по водіях. Для складних/поділених змін використовуйте деталізацію, де видно окремі частини та проміжки.

## Контроль №340 / баланс одного водія

У вікні можна вибрати іншого водія без повернення до табеля. Контроль відображає окремо:
- робочий час;
- час керування;
- тижневий баланс до 60:00 робочого часу;
- тижневий баланс до 56:00 керування;
- середні показники;
- перерви й відпочинки.

Перед створенням PDF можна змінити «Дату формування». Кнопка «Відкрити PDF» створює актуальний документ у робочому сховищі й відкриває його стандартним переглядачем.

## 60-денний реєстр діяльності

Документ має два рівні:

1. зведення по кожному календарному дню;
2. детальний журнал інтервалів із точністю до хвилини.

Кожна доба контролюється до 24:00. Якщо джерел недостатньо, проміжок позначається «Невизначено». Це сигнал для додаткової перевірки, а не помилка друку.

Для реєстру також можна встановити власну дату формування.

## Бланк підтвердження діяльності

Бланк може формуватися у DOCX/PDF/JPG. Перед створенням перевірте період і вид діяльності. При редагуванні вже сформованого бланка стара редакція архівується.

## Шляховий лист

Перед друком перевірте серію/номер, водія, транспорт, маршрут, календарні дати, точки маршруту, планові часи та показники спідометра. Для рейсу через північ у друкованому документі мають бути фактичні календарні дати.

## Excel

Excel-звіти призначені для аналізу і, де це передбачено, ручного доопрацювання. Не використовуйте відредагований Excel як спосіб непомітно змінити первинні дані Taxo: зміни, які мають впливати на наступні звіти, треба внести в систему.

## Архівування

Готові документи зберігайте в структурі робочого сховища. Не переносіть окремі файли вручну без потреби, якщо вони зареєстровані в базі або входять до історії ревізій.
