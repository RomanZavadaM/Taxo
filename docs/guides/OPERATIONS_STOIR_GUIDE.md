# Експлуатація, СТОІР і накази

Це короткий робочий порядок для щоденної експлуатації транспорту. Він описує, **з чого починати**, а не внутрішню будову Taxo.

## 1. З чого почати

Відкрийте **«Експлуатація»**. Перша вкладка **«Документи»** є робочим столом:

- **Шляхові листи на день** — щоденний випуск;
- **СТОІР — стан автопарку** — технічна готовність, ТО, ремонти й несправності;
- **Контроль документів ТЗ** — строки та чинність документів;
- **Відомість ТЦК** — військово-транспортний облік;
- **Накази та розпорядження** — кнопка **«Оформити новий наказ…»** веде одразу до вибору потрібної дії; поруч лишаються реєстр, закріплення та відповідальні.

Старі прямі входи залишаються доступними, але для звичайної роботи краще починати з цього робочого столу.

## 2. СТОІР: нормальний робочий цикл

### Спочатку — стан автопарку

Відкрийте **«СТОІР — стан автопарку»**. Перша вкладка показує всі активні ТЗ:
- поточний підтверджений одометр;
- середній фактичний пробіг;
- стан ТО-1;
- стан ТО-2;
- кількість відкритих заявок.

Виберіть ТЗ у таблиці та натисніть **«Відкрити вибране ТЗ»**. Подвійний клік лишається швидким скороченням для досвідченого користувача.

### Періодичність ТО

У **«Огляд ТЗ / прогноз»** натисніть **«Налаштувати періодичність ТО…»**.

Можна вибрати базовий профіль або вказати індивідуальні інтервали за документацією виробника. Зміна профілю впливає на майбутній прогноз і **не переписує історію виконаних ТО**.

### Внести виконане ТО або ремонт

У **«ТО і ремонти»** виберіть тип події. Вкажіть:
- дату;
- фактичний одометр;
- опис робіт;
- виконавця;
- документ/наряд;
- примітку.

Це факт виконаної роботи. Прогноз сам по собі таким фактом не є.

### Несправність / заявка на ремонт

У вкладці **«Заявки на несправності»**:
1. **«Нова заявка…»** — описати несправність, пріоритет, хто повідомив.
2. **«Взяти в роботу…»** — призначити виконавця.
3. **«Закрити з результатом…»** — вказати, що фактично зроблено.

Taxo не дає закрити заявку без результату.

### ОТК

Вкладка **«Технічний контроль (ОТК)»** показує чинний протокол. Сам файл зберігається у документах ТЗ; кнопка **«Відкрити документи ТЗ…»** веде прямо до відповідного реєстру.

## 3. Накази: з чого почати

На робочому столі **«Експлуатація → Документи»** натисніть **«Оформити новий наказ…»**. Відкриється блок **«Що потрібно оформити?»**.

Для найчастіших випадків є прямі дії:
- закріпити ТЗ за водіями;
- організувати ТО / ремонти;
- призначити відповідальних;
- встановити порядок випуску / повернення ТЗ.

Повний каталог лишається нижче.

## 4. Життєвий цикл наказу

1. Створіть **чернетку** потрібного типу.
2. Перевірте номер, дату, тему, вступ, пункти й відповідального за контроль.
3. Для наказу про закріплення додайте ТЗ / водіїв.
4. Натисніть **«Ввести в дію в Taxo»**. Це робить структуровані дані чинними для внутрішньої роботи Taxo, але **не замінює юридичне підписання**.
5. Сформуйте PDF і після фактичного підписання натисніть **«Позначити паперовий оригінал підписаним»**.
6. Для перевірки змін використовуйте **«Історія…»**.

Чинний або підписаний наказ не редагується заднім числом. Якщо щось треба змінити — оформіть новий наказ. Скасувати з інтерфейсу можна лише чернетку.

## 5. Важливо

- Наказ не підміняє факт ТО, ремонту, технічного контролю чи робочого часу.
- СТОІР не вигадує виконане ТО: якщо немає факту останнього ТО, прогноз позначається як невідомий.
- ОТК і ТО-1/ТО-2 — різні речі.
- Історичні факти не повинні переписуватися під виглядом «виправлення інтерфейсу».
