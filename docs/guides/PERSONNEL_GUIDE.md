# Робота з персоналом — Taxo 9.1 candidate r9.4

## Загальна структура

У Taxo з'явився окремий верхній розділ **«Персонал»**. Він призначений для кадрового обліку, планування робочих змін, ведення табеля та формування звітів по всіх працівниках підприємства.

Розділ містить чотири вкладки:

- **Реєстр** — картки працівників, табельні номери, посади та спеціальні ролі;
- **Планування** — робочі зміни та масові відсутності;
- **Табель** — щоденний табель, план/факт і місячний баланс;
- **Звіти** — PDF/Excel, включно з табелем за структурою П-5.

Окрема вкладка **«Водії»** лишається для водійських реквізитів, посвідчень та пов'язаних документів.

## Реєстр працівників

Працівника вводьте один раз. Основна посада використовується для загального кадрового планування. Спеціальні ролі (наприклад, «Водій», «Лікар», «Механік», «Диспетчер») використовуються там, де від ролі залежить функціональність Taxo.

Водій є працівником із додатковою роллю та водійською карткою.

## Режими робочого часу

Перед масовим плануванням задайте працівникові **режим робочого часу** через **Персонал → Реєстр → Режим робочого часу**.

Доступні 5-денний, 6-денний, підсумований та індивідуальний режими. Норма зберігається окремо по днях Пн–Нд і може мати історію за датами дії.

Типові шаблони:
- **5/40** — 8:00 × 5;
- **6/40** — 7:00 + 7:00 + 7:00 + 7:00 + 7:00 + 5:00;
- **6/36** — 6:00 × 6;
- **6/24** — 4:00 × 6.

Не використовуйте «8 годин» як універсальну денну норму. Для шестиденного або скороченого режиму Taxo бере норму конкретного дня з картки режиму.

Через **Персонал → Планування → Норма за режимом → план місяця** можна заповнити лише порожні нормативні робочі дні. Для підсумованого обліку автоматичне розкладання змін не виконується — потрібен фактичний затверджений графік.

## Тижневий баланс

Кнопка **«Тижневий баланс»** показує по всіх працівниках:
- базову норму тижня;
- зменшення норми через відпустку/лікарняний;
- скориговану норму;
- план;
- факт;
- відхилення.

Відсутність зменшує норму на години саме того дня за режимом працівника. Наприклад, при 6/40 відпустка в суботу зменшує норму на 5:00, а не на 8:00.

Для підсумованого обліку тижневе відхилення є довідковим; надурочні визначаються за встановлений обліковий період.

## Масове планування робочих змін

Відкрийте **Персонал → Планування → Робочі зміни — масово**.

Вкажіть:
1. працівника;
2. роль або основну посаду;
3. період;
4. схему роботи;
5. номер зміни;
6. час початку/закінчення;
7. за потреби D+ для переходу через північ;
8. місце роботи;
9. примітку.

Схеми: щодня, Пн–Пт, вибрані дні тижня, через день, 2/2, 7/7 або власний цикл.

Перед записом натисніть **«Переглянути»**. Система покаже дні, які буде додано, пропущено або заблоковано через конфлікт.

Фактичний запис автоматично не перезаписується.

## Масові відпустки / лікарняні / відсутності

Відкрийте **Персонал → Планування → Відпустки / лікарняні / інші відсутності**.

Вкажіть працівника, вид відсутності, дату «з» і «до» та примітку.

Підтримуються, зокрема:
- основна та додаткова щорічна відпустка;
- відпустки без збереження зарплати;
- навчальні/творчі відпустки;
- лікарняні;
- відрядження;
- простій;
- прогул;
- інші причини неявок.

Відсутність **не видаляє історичний робочий графік**. У табелі вона має пріоритет над автоматичним планом на цей день. Якщо вже є фактичні години, день не змінюється автоматично і потребує ручного рішення.

Лікар або механік, який має табельну відсутність, не підставляється в шляховий лист як черговий на цей період.

## Табель П-5

У **Персонал → Звіти** виберіть місяць/рік і натисніть:
- **«Табель П-5 — PDF»** — для друку;
- **«Табель П-5 — Excel»** — для редагування/подальшої роботи.

Звіт містить:
- календарні числа 1–31;
- повну легенду кодів 01–30;
- фактичні години;
- надурочні, нічні, вечірні та роботу у вихідні/святкові;
- підсумок робочих днів і годин;
- групи причин неявок;
- стать;
- оклад / тарифну ставку;
- підписні блоки.

У картці працівника заповнюйте **«Стать для П-5»** та **«Оклад / тарифна ставка»**. У щоденному табелі за потреби окремо вводяться фактичні категорії П-5.

Якщо є план без факту, Taxo не підставляє його мовчки. Перед формуванням користувач вирішує: **підставити план**, **залишити без факту** або **скасувати**. Підставлені планові години явно позначаються у документі.

## Excel

Excel-табель містить окремий аркуш умовних позначень та формули для основних підсумків. Редагування Excel не змінює базу Taxo. Якщо зміна має впливати на наступні документи — внесіть її безпосередньо в програму.
