# Керівництва з експлуатації Taxo 9.0

Цей розділ призначений для працівників підприємства, які щоденно працюють із системою.

## Основні інструкції

- [Швидкий старт](QUICK_START.md) — перший запуск і базове налаштування.
- [Інструкція для персоналу](STAFF_OPERATIONS.md) — порядок роботи за ролями.
- [Адміністрування](ADMINISTRATION.md) — сховище, резервування, оновлення, кілька комп’ютерів.
- [Звіти та контроль](REPORTS_AND_CONTROLS.md) — табелі, №340, 60-денний реєстр, бланки, шляхівки.
- [Типові проблеми](TROUBLESHOOTING.md) — практичні сценарії відновлення й діагностики.

## Кому що читати

**Диспетчер:** `QUICK_START` + `STAFF_OPERATIONS` + розділ про шляхівки у `REPORTS_AND_CONTROLS`.

**Табельник / кадровик:** `STAFF_OPERATIONS` + `REPORTS_AND_CONTROLS`.

**Відповідальний за тахограф:** `STAFF_OPERATIONS` + розділи про ТАХО і 60-денний реєстр.

**Адміністратор / керівник:** `ADMINISTRATION` + `../system/DATA_STORAGE.md` + `../system/MAINTENANCE_POLICY.md`.

## Принцип експлуатації v9.0

Під час реальної роботи не потрібно «підганяти» дані під очікуваний результат. Якщо система показує невизначений проміжок, попередження або відхилення, спочатку перевіряється джерело даних. Зміна даних лише для того, щоб прибрати попередження, суперечить моделі Taxo.
