# Taxo 10.4-r6 — квартальна звірка з державними реєстрами

Базова періодичність: **один раз на календарний квартал**.

- Q1: 01.01–31.03
- Q2: 01.04–30.06
- Q3: 01.07–30.09
- Q4: 01.10–31.12

Правило актуальності:
- якщо успішне звіряння виконане в поточному кварталі — стан «Актуально»;
- після переходу в новий квартал — «Потрібне звіряння» до нового успішного імпорту;
- повторне ручне звіряння дозволене будь-коли;
- кожен новий файл створює новий snapshot, історія не стирається;
- невирішені конфлікти залишаються активними незалежно від факту нового імпорту.

Застосовується до:
- реєстрових XLSX по працівниках / військовому обліку;
- ліцензійного реєстру «Шлях» по ТЗ;
- наступних державних реєстрів, інтегрованих у Taxo.

У UI показувати дату, квартал, стан актуальності та кількість невирішених розбіжностей.
