# Taxo — квартальна звірка з державними реєстрами

**Рішення власника:** 27.09.2026

## Періодичність

Базова періодичність звіряння Taxo з державними реєстрами — **один раз на календарний квартал**.

Квартали:
- Q1: 01.01–31.03
- Q2: 01.04–30.06
- Q3: 01.07–30.09
- Q4: 01.10–31.12

## Правило актуальності

Для кожного підтримуваного реєстру Taxo зберігає дату останнього успішного імпорту/звіряння.

Стан **«Актуально»** означає, що успішне звіряння вже виконано в поточному календарному кварталі.

При переході в новий квартал стан автоматично переходить у **«Потрібне звіряння»**, доки не буде завантажено й успішно опрацьовано новий витяг/експорт.

Ручне повторне звіряння дозволене в будь-який момент; новіший файл створює новий реєстровий snapshot і не стирає історію попередніх звірянь.

## Реєстри

Правило застосовується щонайменше до:
- Реєстру військовозобов'язаних / реєстрових XLSX по працівниках;
- ліцензійного реєстру Укртрансбезпеки «Шлях» по транспортних засобах;
- наступних державних реєстрів, які будуть підключені до Taxo.

## UI

У відповідних реєстрах/картках показувати:
- дату останнього звіряння;
- квартал останнього звіряння;
- стан: «Актуально», «Потрібне звіряння», «Є невирішені розбіжності»;
- кількість невирішених жовтих/червоних розбіжностей;
- кнопку повторного імпорту/звіряння.

Квартальна актуальність не означає, що невирішені конфлікти вважаються закритими: вони залишаються активними до рішення користувача або наступного підтвердженого реєстрового знімка.
