# Taxo 10.4-r6 — квартальна звірка з державними реєстрами

**Рішення власника:** 27.09.2026

## Періодичність

Базова періодичність звіряння Taxo з державними реєстрами — **один раз на календарний квартал**.

- Q1: 01.01–31.03
- Q2: 01.04–30.06
- Q3: 01.07–30.09
- Q4: 01.10–31.12

## Правило актуальності

- якщо успішне звіряння виконане в поточному календарному кварталі — стан **«Актуально»**;
- після переходу в новий квартал — стан **«Потрібне звіряння»** до нового успішного імпорту;
- ручне повторне звіряння дозволене у будь-який момент;
- кожен новий файл створює новий snapshot, попередня історія не стирається;
- невирішені конфлікти лишаються активними незалежно від нового імпорту.

## Реєстри

Правило застосовується щонайменше до:
- реєстрових XLSX по працівниках / військовому обліку;
- ліцензійного реєстру Укртрансбезпеки «Шлях» по транспортних засобах;
- наступних державних реєстрів, інтегрованих у Taxo.

## UI

Показувати:
- дату останнього звіряння;
- квартал останнього звіряння;
- стан: «Актуально», «Потрібне звіряння», «Є невирішені розбіжності»;
- кількість невирішених жовтих/червоних розбіжностей;
- кнопку повторного імпорту/звіряння.

Квартальна актуальність не закриває невирішені розбіжності автоматично.
