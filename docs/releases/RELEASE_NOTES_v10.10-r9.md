# Taxo 10.10-r9 — виправлення графіка водіїв та відсутностей

Статус: інтегровано до `main` 05.11.2026, candidate для користувацького тестування. **Stable лишається `v10.10-r5`.**

## Що виправлено

- Графік для вибраних працівників тепер показує водійські дні з основного реєстру водійського графіка (worklog), а не з типової норми працівника.
- Прив’язаний водій із посадою «Водій автотранспортних засобів» не отримує другий автоматичний план через загальний планувальник.
- Коригування відсутностей тепер приймає чинний виклик із шістьма аргументами, усуваючи аварію `adjusted() takes 5 positional arguments but 6 were given`.
- Додано regression `tests/test_v10_10_r9.py` для графіка та виклику обчислення відсутностей.
- Персональний PDF/XLSX будується з того самого місячного набору даних, що й вікно; сторонні працівники та внутрішні службові примітки не включаються.

## Важливі обмеження

- Роль водія, його періоди та існуючі записи worklog не переписуються.
- Раніше створені дублюючі employee_shifts **не видаляються автоматично**.
- Факт діяльності не підміняється планом.
- База користувача і скани не входять до release.
- Можливі старі конфліктні записи потребують окремої діагностики на копії даних.

## Перевірки

PR #160: Windows, Windows 7, macOS ARM64/Intel — SUCCESS, із новими регресійними тестами. Main checkpoint: `66882a2164bea1a72a30ec1db74d36d1613d0c68`; exact-main START/platform gates мають перевірятися окремо.
