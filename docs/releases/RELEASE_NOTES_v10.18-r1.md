# Taxo 10.18-r1 — військово-транспортні реєстри: сортування та стабільний вибір

**Тип:** тестова кодова ревізія / candidate.  
**База:** Stable/Latest [v10.17-r10](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.17-r10). Stable не змінюється.

## Що змінено

- У центрі «Військово-транспортний облік ТЗ» усі п'ять робочих таблиць отримали клікабельне сортування.
- Для дат, часу подання і статусів застосовано явні типи, а не текстове сортування.
- Повторний клік перемикає ▲/▼; після оновлення попередній порядок застосовується знову.
- Вибір наряду, дії, відомості або зв'язку працівника відновлюється за стабільним ID, якщо рядок лишається видимим.
- Сортування не записує дані й не змінює військові статуси, наряди, строки, plan/fact або документи.

## Не входить у r1

- Бібліотека шаблонів і сховище документів.
- Ручне приймання Windows DPI 100/125/150 %, фокуса/табуляції та X/повторного відкриття — окремий pending gate.
- Stable/Latest залишається 10.17-r10.
