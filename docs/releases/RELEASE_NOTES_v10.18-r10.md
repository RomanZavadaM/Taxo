# Taxo 10.18-r10 — security/release cleanup checkpoint

## Для чого ця збірка

`10.18-r10` не додає нових функцій Taxo. Вона потрібна, щоб безпечно повернути тестові Windows-збірки після попередження Firefox на r8.

Stable/Latest `v10.18-r3` не змінюється.

## Що змінено

- збережено блокування публікації r8;
- Windows і Windows 7 перед видачею проходять Microsoft Defender scan, після якого повторно звіряються контрольні суми;
- збірки записують точне походження: Git revision, Python, PyInstaller і встановлені пакети;
- перевіряється саме точний код кандидата, а не тимчасовий GitHub merge-варіант;
- файли Windows, Windows 7 і macOS беруться лише зі своїх перевірених збірок і більше не змішуються між собою;
- ручний тестовий випуск за замовчуванням містить тільки Portable-архіви, START і SHA256; інсталятори додаються лише в окремому full-режимі;
- якщо Defender тимчасово не може оновити базу через Windows Installer conflict `0x80070652`, оновлення повторюється обмежену кількість разів; інші помилки і невдала перевірка як і раніше блокують видачу.

## Важлива межа

Успішна перевірка Defender не скасовує попередження Firefox і не доводить, що попередній сигнал був хибним. Якщо Firefox знову позначить нову Portable-збірку як malware/danger, виконавчі файли залишаються на паузі до окремого розбору причини.
