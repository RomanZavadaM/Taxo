# Taxo 10.22-r10 — зрозуміла робота з папками документів

**Статус:** тестовий кандидат, не Stable/Latest.

У каталозі «Документи» виправлено сценарій роботи з власними папками:

- **«Додати документ у цю папку…»** відкриває весь каталог з пошуком, навіть коли папка порожня;
- після створення папки чи додавання документа вибрана папка залишається відкритою;
- користувач може перемістити папку в іншу папку або на верхній рівень;
- папку з усіма вкладеними можна архівувати та повернути з архіву;
- архівна папка не приймає нові документи до відновлення;
- безпека: документи, скани та незмінні файли сховища не видаляються і фізично не переміщуються;
- резервне копіювання включає дерево, архівний стан і прив'язки документів.

Ділова кореспонденція за PR #543 залишається окремим наступним етапом. **Stable/Latest 10.21-r2 не змінюється.**
