# Taxo 10.6-r1 — фільтр неактивних транспортних засобів

**Дата:** 28.09.2026  
**Тип:** candidate / fast-test  
**Stable baseline:** Taxo 10.3

## Що змінено

У вікні **«Транспортні засоби — реєстр документів»** додано прапорець **«Сховати неактивні автомобілі»**.

- прапорець увімкнений за замовчуванням ще до першого завантаження списку;
- неактивні автомобілі тому не захаращують щоденний робочий реєстр;
- після зняття прапорця весь історичний парк, включно з неактивними ТЗ, одразу знову показується;
- фільтр впливає лише на відображення рядків і не змінює статус ТЗ, картку автомобіля, документи чи історичні записи;
- кнопка «Оновити» зберігає поточний стан фільтра;
- розміщення фільтра не прив'язане до історичної назви кнопки додавання автомобіля, щоб зміни UI-підписів не ховали сам фільтр.

## Сумісність і спадкоємність

10.6-r1 побудований поверх виданого 10.5-r10. Збережені без зміни:

- поділ плану і факту;
- виправлення аудиту графіків 10.5-r10;
- шляхівка **«Поза маршрутом…»** з 10.5-r9;
- документи ТЗ, ДЦВ, ручне архівування та кілька активних документів одного типу;
- державні реєстрові snapshots і локальні робочі дані;
- робочі БД та персональні дані не входять у START-пакет.

## Нумерація

- `10.5-r10` уже виданий та immutable;
- цей крок: **10.6-r1**;
- після видачі 10.6-r1 наступна кодова ревізія — **10.6-r2**.

## Перевірка

Перед публікацією candidate обов'язково проходять повний regression suite, чистий START package guard та перевірка прямого GitHub Release asset.
