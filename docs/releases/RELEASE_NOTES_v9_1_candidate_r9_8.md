# Taxo 9.1 candidate r9.8

Waybill duty-staff consistency fix поверх **Taxo 9.1 candidate r9.7**.

Stable baseline залишається **Taxo 9.0.1**.

## Виявлена проблема

У вікні «Шляхівки на день» дві шляхівки одного дня могли отримати різних лікарів і механіків для тієї самої I зміни.

Ручний приклад:
- дата графіка: 20.09.2026;
- один рейс завершується 21.09.2026;
- другий завершується 20.09.2026;
- обидва показували поле I зміни, але з різними ПІБ.

## Root cause

Для кожної шляхівки Taxo окремо викликав пошук чергових по **повному інтервалу рейсу**.

Для нічного рейсу, який переходив через 00:00, у вибірку потрапляла I зміна наступної дати. Оскільки результат мав лише ключ `doctor_1/mechanic_1`, пізніший запис міг перезаписати персонал дати графіка.

Додатково місце випуску фактично могло створювати кілька операційних слотів для тієї самої ролі/дати/зміни.

## Правило r9.8

Для одного АТП операційний слот персоналу визначається так:

**роль + дата графіка + номер зміни**

Місце випуску є описовим реквізитом і не створює другого лікаря/механіка для тієї самої зміни.

## Що виправлено

- персонал шляхівки розраховується один раз на дату графіка;
- усі шляхівки цієї дати використовують один набір `doctor_1/doctor_2/mechanic_1/mechanic_2`;
- нічний рейс через 00:00 не підхоплює I/II зміну наступної дати;
- ручне планування блокує друге призначення тієї самої ролі на ту саму дату/зміну незалежно від місця;
- масове планування теж вважає роль+дату+зміну єдиним slot;
- старі дублікати не переписуються автоматично;
- якщо в старій БД є два працівники в одному slot, Taxo показує `конфлікт чергових` і блокує видачу шляхівки до ручного виправлення.

## Regression tests

Додано `tests/test_v9_1_r9_8.py`:
- 20.09 не бере Лікаря I/Механіка I з 21.09;
- duplicate same role/date/shift across different locations стає явним conflict;
- `_waybill_schedule_rows` обчислює day-duty один раз до циклу шляхівок;
- ручний slot duplicate check більше не залежить від location.

## Збережено

- кнопка «Відкрити деталізацію» r9.7;
- Windows-safe START.bat r9.6;
- canonical intervals / аудит графіків / №340 / П-5 / Персонал;
- stable main 9.0.1.

## Manual retest

1. Відкрити дату 20.09.2026.
2. «Шляхівки на день».
3. Для всіх шляхівок цієї дати звірити Лікар I / Механік I.
4. Нічний рейс, що завершується 21.09, має показувати той самий персонал I зміни 20.09, що й денний рейс.
5. Якщо Taxo покаже «конфлікт чергових», відкрити «Зміни лікаря/механіка» і залишити одне призначення на role/date/shift.
6. Після виправлення конфлікту оновити список і сформувати шляхівку.
