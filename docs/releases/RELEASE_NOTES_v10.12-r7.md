# Taxo 10.12-r7 — runtime gate для Центру документів

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Центр документів усередині «Експлуатації» раніше мав лише статичні перевірки структури. r7 додає живу перевірку, що вкладка реально з'являється після побудови вікна і всі ключові дії доступні користувачу.

## Жива перевірка охоплює

- «Шляхові листи на день»;
- «Контроль документів ТЗ»;
- «Відомість ТЦК — транспорт підприємства»;
- «Реєстр усіх працівників»;
- переходи до «Накази», «Закріплення водіїв», «Відповідальні», «Каталог наказів»;
- захист від дублювання вкладки «Документи» при повторному відкритті.

Для кожної дії перевіряється фактична видимість у Tk-вікні та правильний перехід/виклик.

## Не змінено

Бізнес-логіка, БД, документи, накази та user data не змінюються.
