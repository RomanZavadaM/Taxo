# Taxo 10.5-r5 — сумісність XLSX реєстру «Шлях»

**Дата:** 28.09.2026  
**Тип:** candidate / fast-test START  
**Статус:** issued, immutable  
**Issued code head:** `23064b775087c9dfc05867dc65f27e6d6d87e9b4`

## Виправлено

Під час імпорту окремих XLSX-експортів транспортних засобів з реєстру «Шлях» програма могла зупинятися з помилкою:

`ChildSheet.__init__() got an unexpected keyword argument 'tabId'`

Причина — окремі файли містять атрибут `tabId` у записі аркуша всередині `xl/workbook.xml`, тоді як зафіксована в Taxo версія openpyxl 3.1.5 не приймає цей атрибут у `ChildSheet`.

## Рішення

- штатне читання XLSX залишається першим шляхом;
- compatibility retry запускається лише для точного збою `ChildSheet/tabId`;
- Taxo формує тимчасову копію XLSX **у пам'яті**, прибираючи тільки несумісний `tabId` з елементів `<sheet>`;
- оригінальний файл користувача не переписується й не змінюється;
- після цього використовується та сама логіка розпізнавання колонок і звірки ТЗ з «Шлях»;
- інші помилки XLSX не приховуються цим workaround.
