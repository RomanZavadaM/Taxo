# Taxo 10.22-r6 — окремий напрям «Сезонні заходи»

- У загальному каталозі **«Документи»** накази типу `seasonal_operation` тепер мають окрему категорію **«Сезонні заходи»**, а не губляться всередині загального «Експлуатаційні».
- Категорія визначається тільки за вже наявним структурованим типом наказу; слова у темі або тексті документа не використовуються для вгадування.
- Кадрова серія зберігає пріоритет: кадровий наказ не стає сезонним лише через тип.
- «Сезонні заходи» автоматично з'являються у чинному фільтрі категорій та працюють разом з іншими фільтрами каталогу.
- Не змінено файли документів, DocumentVault, скани, паперовий підпис, backup/restore, схему БД, накази, пари водій↔ТЗ або Stable/Latest.
- Перевірка: окремий regression для класифікації та читання старих наказів плюс повний CI.
