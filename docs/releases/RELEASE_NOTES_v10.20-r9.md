# Taxo 10.20-r9 — індикатор сканів у каталозі документів

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.20-r5, без змін.

## Що змінилось

- У загальному вікні **«Документи»** додано окрему колонку **«Скани»**.
- Для документа, збереженого у DocumentVault, одразу видно **«Немає»** або **«Є: N»** за кількістю активних сканів паперового оригіналу.
- Скан, який у 10.20-r8 був явно **«Прибраний»**, не рахується активним і не збільшує показаний лічильник.
- Якщо сховище сканів пошкоджене або не проходить перевірку цілісності, сам каталог документів залишається доступним; у колонці показується **«Помилка перевірки»**.
- Статус перевірки сканів також показується у службовому рядку стану каталогу.
- Індикатор працює через чинне захищене сховище сканів і не створює нових форматів даних.

## Що не змінювалось

- Наявність скана не означає, що документ підписано.
- КЕП / електронний підпис не додавались.
- Автоматичний статус «підписано» не встановлюється.
- Фізичне видалення immutable-файлів не додавалось.
- Міграція старих документів не виконується.
- Бізнес-статуси документів не змінювались.
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1419 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після антивірусного сканування.
