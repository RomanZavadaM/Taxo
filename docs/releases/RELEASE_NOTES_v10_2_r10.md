# Taxo 10.2-r10 — candidate

## Узгодження Бланків після зміни фактичного ТАХО-часу

### Виявлена причина
Якщо межі вже сформованого Бланка підтвердження змінювалися після уточнення графіка або ТАХО-факту, контроль 56 днів виконував математичне віднімання інтервалів. Невеликий залишок (наприклад 30–40 хвилин) помилково сприймався як окремий новий період і пропонувався для нового бланка.

### 10.2-r10
- частково перекритий проміжок з одним активним бланком позначається «УТОЧНИТИ БЛАНК №…»;
- система показує старі та нові межі;
- «Сформувати / уточнити бланк» не створює дубль, а редагує існуючий запис новою ревізією;
- попередні DOCX/PDF/JPG архівуються;
- audit trail та revision зберігаються;
- немає спеціального допуску «40 хв»: правило працює для будь-якої зміни меж;
- справді нові проміжки без перекриття й надалі створюють новий бланк.

r9-захист DOCX з перевіркою фактичних дат збережено.

Stable 10.1 не змінюється.
