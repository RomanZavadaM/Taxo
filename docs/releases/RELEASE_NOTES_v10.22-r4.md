# Taxo 10.22-r4 — Test Portable

## Що нового

У загальному вікні **«Документи»** команда **«Відкрити вибране»** тепер реально відкриває документ, який уже збережений у DocumentVault.

- Перед переглядом Taxo заново перевіряє індекс, розмір і SHA-256 незмінної копії.
- Оригінальний файл у `Data/DocumentVault` не передається Word або іншій зовнішній програмі.
- Для перегляду створюється окрема тимчасова копія тільки для читання; її можна переглянути у вбудованому DOCX-вікні або відкрити зовнішньо.
- Якщо файл сховища пошкоджений або підмінений, перегляд блокується з помилкою цілісності.
- База даних, скани, backup/restore, бізнес-статуси, підпис і stable-версія не змінюються.

Окремі регресійні перевірки: точність байтів копії, розміщення поза DocumentVault, read-only режим, блокування пошкодженого об'єкта та підключення дії у каталозі.
