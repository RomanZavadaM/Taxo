# Taxo 10.10-r4 — release notes

Статус: **candidate / test line**. Stable `v10.9-r10` не змінюється.

## Виправлено

- Канонічна версія застосунку береться з `VERSION.txt` / `main.APP_VERSION` і використовується для всього поточного UI.
- Після проходження історичних feature-layer модулів старі значення на кшталт `10.8-r5` або `10.9-r9` більше не повинні залишатися в заголовках головного чи дочірніх вікон.
- Нові діалоги, відкриті вже після старту програми, також нормалізують branding/version під час появи.
- Історичний текст документації та довідки не переписується: змінюються лише UI-поля, які мають вигляд версії/брендингу.

## Пакети

Для 10.10-r4 CI має формувати:
- Windows 10/11 x64: Setup + Portable;
- Windows 7 SP1 x64: **Setup + Portable**;
- macOS arm64/x86_64: Portable;
- START/source package та SHA-256.

Win7 Setup повернуто в активний workflow; у README посилання буде додано тільки після фактичної публікації релізного asset.

## Перевірка

Додано регресійний тест `tests/test_v10_10_r4.py` для:
- головного вікна;
- існуючих дочірніх widgets;
- вікон, відкритих після запуску;
- захисту історичного тексту від помилкового переписування;
- синхронізації `VERSION.txt` і `main.APP_VERSION`.
