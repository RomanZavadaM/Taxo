# Taxo 10.9-r6 — персонал, баланс, П-5

Fast-test ревізія поверх immutable `v10.9-r5`. Stable `v10.3` не змінюється.

- планові `Вихідний` та `Відпочинок` більше не зменшують норму як відпустка/лікарняний;
- історичні неявки в місячному балансі накладаються за датою працевлаштування, без lossy `{driver_id: employee_id}` mapping;
- поточний `active` не використовується як критерій для історичної неявки;
- додані поведінкові тести 2/2 і довільного 3/3 циклу;
- нова поведінка підключена окремим runtime layer без зміни схеми БД;
- `START.bat` контролює наявність r6-модуля.

Злиття в `main` — тільки за окремою командою власника.
