# Taxo 10.12-r6 — runtime gate для центру даних працівників

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Після r3 центральний вхід **«Дані / Дія / документи…»** вже не може тихо зникнути. r6 перевіряє наступний рівень: чи не зникла якась важлива дія вже всередині самого центру.

## Жива перевірка охоплює

- завантаження XLSX / звірку;
- масові дії з останнього імпорту;
- робочі дані з реєстрів;
- картку та документи вибраного працівника;
- загальний реєстр документів;
- контроль обов'язкових документів;
- офіційний цикл Дії;
- військовий облік / строки.

Для кожної дії перевіряється, що кнопка реально відображається у створеному Tk-вікні і викликає правильний робочий маршрут.

## Не змінено

Імпорт, дані працівників, документи, правила Дії/військового обліку, БД та user data не змінюються.
