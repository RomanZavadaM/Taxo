# Taxo 10.2-r9 — candidate release notes

## Бланки підтвердження

Після створення нового бланка Taxo тепер автоматично виділяє саме щойно створений запис у таблиці історії.

Причина дефекту: генератор DOCX отримував правильні `period_from/period_to`, і ім'я нового файла також містило правильний період. Але після `load_att_history()` інтерфейс відновлював попереднє виділення. Тому наступне натискання кнопки «DOCX» могло відкрити старий раніше вибраний документ, що виглядало як неправильні дати у щойно сформованому DOCX.

Код генерації DOCX і сам DOCX-шаблон між r7 та r8 не змінювалися.

## PDF / PyMuPDF

- PyMuPDF (`fitz`) повністю вилучено з runtime-залежностей.
- PDF більше не рендериться всередині Taxo.
- PDF відкривається системною програмою за замовчуванням або браузером.
- Внутрішній перегляд лишився для raster-зображень.
- Для DOCX лишився спрощений текстово-табличний preview та кнопка відкриття оригіналу.
