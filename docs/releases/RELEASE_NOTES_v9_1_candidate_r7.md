# Taxo 9.1 candidate r7

Source-candidate поверх r6 для експлуатаційної перевірки перед рішенням щодо stable 9.1.

## Виправлення «План за режимом → місяць»

- після preview і підтвердження кожен день повторно перевіряється безпосередньо перед INSERT;
- повторно перевіряються ручний запис табеля, графік водія/маршрут та employee_shift;
- INSERT має `ON CONFLICT(employee_id,work_date) DO NOTHING`;
- повторний запуск не створює дублікати і не падає на UNIQUE;
- план/факт, що з'явився між preview та apply, не перезаписується.

## Тести

Додано регресійні тести:
- повторне застосування плану за режимом залишає один запис;
- поява водійського/змінного плану перед INSERT блокує новий запис.

Усі можливості r6 зберігаються. Stable baseline — Taxo 9.0.1. r7 не зливається в main до експлуатаційної перевірки.
