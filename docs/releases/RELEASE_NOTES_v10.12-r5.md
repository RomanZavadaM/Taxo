# Taxo 10.12-r5 — runtime gate для історично ламких layout-контролів

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Закрити два сценарії, які вже реально ламались у попередніх ревізіях:

1. у масовому плануванні персоналу прапорець перепланування колись перекривався іншими елементами;
2. у шляхівках крайні команди колись ставали невидимими у вузькому вікні.

## Додано

- живу Tk-перевірку вікна масового планування на мінімальному підтримуваному розмірі;
- перевірку, що прапорець **«Перепланувати: замінити існуючий ПЛАН…»** реально відображається та має ненульовий розмір;
- живу перевірку панелі з усіма 9 діями шляхівок при вузькій ширині;
- перевірку, що після переносу на кілька рядків усі 9 кнопок mapped, жодна не втрачена і кожна викликає свою дію;
- обидва маршрути позначені в реєстрі функцій як обов'язкові для runtime-smoke.

## Не змінено

Бізнес-логіка планування, шляхових листів, БД, PDF, нумерації документів та user data не змінюються.
