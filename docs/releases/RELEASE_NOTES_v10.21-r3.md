# Taxo 10.21-r3 — candidate release notes

- у загальному каталозі «Документи» додано read-only фільтр **«Тип»**;
- список типів формується з уже наявних структурованих значень документів у поточному каталозі, без вгадування категорій і без міграції даних;
- точний тип застосовується до повного snapshot до пагінації та комбінується з пошуком, джерелом, сканами і періодом «Від / До»;
- фільтр не редагує записи, файли, скани, DocumentVault, backup/restore або бізнес-статуси;
- нормалізація категорій БДР/охорони праці/кадрових і навігація за працівниками/ТЗ не входять у цей вузький slice;
- КЕП/e-signature, auto «підписано», physical purge, migration і нові залежності не додаються.
