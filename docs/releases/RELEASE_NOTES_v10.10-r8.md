# Taxo 10.10-r8 — простий місячний графік для вибраних працівників

Статус: **candidate / test revision**. Stable залишається `v10.10-r5`.

## Що додано

- У **Персонал → Планування** додано **«Простий місячний графік…»**.
- Перед формуванням графіка можна вибрати конкретних працівників.
- Підтримані прості шаблони:
  - Пн–Пт;
  - 2/2;
  - 3/3;
  - щодня;
  - вибрані дні тижня.
- Задаються час початку/кінця та неоплачувана перерва.
- Існуючий факт, відпустка/лікарняний, конфліктна зміна або водійський графік не перезаписуються.
- Працівник з єдиною неводійською роллю планується через ту саму таблицю змін, що й детальний планувальник.
- Водій, який має лише роль «Водій», **не отримує дубль плану**: його робота залишається у спеціалізованому графіку водіїв.

## Кому показується графік

Є два режими перегляду:

1. **Внутрішній робочий** — для керівника/диспетчера.
2. **Графік для вибраних працівників** — тільки вибрані люди.

PDF та Excel для працівників формуються лише з другого, відфільтрованого набору. Вони **не містять** службових проблем інших ролей, нестач персоналу чи внутрішніх діагностичних приміток.

Отже, якщо у зміну водія не призначено контролера, це може залишатися внутрішньою проблемою підприємства, але у персональному графіку водія така інформація не з'являється.

## Друк

- PDF ділить місяць на дві читабельні частини, щоб 31 день не стискався в один нерозбірливий ряд.
- Excel містить тільки вибраних працівників.
- Внутрішні службові зауваження в employee-facing export не передаються.

## Перевірки r8

Додано тести на:
- цикл 3/3;
- планування лише вибраних працівників;
- відсутність дублювання плану водія;
- захист уже внесеного факту;
- відсутність службових приміток у графіку для працівника;
- відсутність інших працівників у персональному Excel.
