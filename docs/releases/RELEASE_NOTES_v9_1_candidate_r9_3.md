# Taxo 9.1 candidate r9.3

Контрольна source/START точка після r9.2.

## Типова форма № П-5

П-5 актуалізовано за структурою типової форми, затвердженої наказом Держкомстату України від 05.12.2008 № 489.

Реалізовано:
- повну легенду кодів 01–30;
- календарні дні 1–31;
- підсумки: дні, години, надурочні, нічні, вечірні, робота у вихідні/святкові;
- групи причин неявок;
- стать працівника;
- оклад / тарифну ставку;
- підписні блоки;
- PDF та Excel.

У картці працівника додано поля «Стать для П-5» та «Оклад / тарифна ставка».

У щоденному табелі персоналу можна окремо ввести фактичні надурочні, нічні, вечірні години та роботу у вихідні/святкові.

### План замість відсутнього факту

Taxo не підставляє план мовчки.

Якщо під час формування П-5 є робочі дні з планом, але без внесеного факту, користувач отримує вибір:
- **Так** — підставити планові години замість відсутнього факту;
- **Ні** — сформувати документ тільки за внесеним фактом;
- **Скасувати** — не формувати документ.

Якщо план підставлено, відповідні клітинки виділяються, а у PDF/XLSX додається явна примітка з кількістю таких днів.

## Архів бланків підтвердження діяльності

- новіші бланки показуються зверху;
- опція «Тільки вибраний водій»;
- опційний відбір за місяцем/роком;
- «Скинути відбір»;
- редагування працює по відфільтрованому списку.

## Місячний контроль водія

Вікно «Підсумки та контроль №340» стало інформативнішою панеллю:
- компактні місячні показники зверху;
- вкладка «Дні місяця» з графіком/частинами, перервами, роботою, керуванням, надурочними, маршрутом і результатом контролю;
- подвійний клік відкриває конкретний день для редагування;
- вкладка «Контроль №340» лишає повний пояснювальний протокол;
- кнопка «Відкрити деталізацію» формує й відкриває PDF робочого часу вибраного водія/місяця.

## Контроль графіків

Збережено r9.2:
- аудит існуючих днів і активних маршрутів;
- контроль перекриттів, неповних пар часу та керування поза робочим інтервалом;
- старі дані автоматично не переписуються;
- нове некоректне введення блокується.

Stable baseline залишається Taxo 9.0.1. r9.3 не зливається в main до експлуатаційної перевірки.
