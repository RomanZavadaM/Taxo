# Taxo 10.22-r1 — Test Portable

## Що змінилось

У спільному каталозі **«Документи»** додано швидку навігацію за **роком і місяцем**.

- «Рік» показує лише роки, які реально є у коректних датах каталогу.
- «Місяць» показує місяці, наявні для вибраного року.
- При зміні року місяць скидається на «Усі місяці», щоб старий вибір не створював випадково порожній список.
- Місяць можна використати і без вибраного року — тоді показуються записи цього місяця за всі роки.
- Рік/місяць комбінуються з уже наявними пошуком, джерелом, сканами, періодом «Від / До», типом і категорією до розбиття на сторінки.
- Старі записи з порожньою або некоректною датою залишаються видимими у звичайному режимі, але не вважаються такими, що входять у активний календарний фільтр.

## Межі зміни

Не змінювались файли документів, DocumentVault, скани, backup/restore, схема БД, бізнес-статуси, залежності та механізм пар водій↔ТЗ. Stable/Latest автоматично не змінюється.
