# Taxo 10.5-r1 — відомість військово-транспортного обліку

**Статус:** development / fast-test candidate  
**Дата:** 28.09.2026  
**База:** final green `10.4-r10` guard `5c964a2278d59f40542cb5b4679b95cc56b809fb`.

## Мета

Додати окреме формування відомості по власному/балансовому транспорту підприємства для військово-транспортного обліку — **додаток 1 до Положення про військово-транспортний обов'язок №1921**.

## Інваріанти

- належність ТЗ до власного/балансового парку задається явно;
- `vehicles.active`, дані «Шлях», наряд або статус `designated/ordered` не визначають автоматично включення до відомості;
- невідома належність показується як `Потрібно визначити`;
- формування PDF/XLSX не є фактом подання;
- подання й вихідний реквізит залишаються окремою дією в існуючому журналі;
- відсутні реквізити не вигадуються, а виводяться як попередження перед формуванням.

## Дані відомості

Заплановані колонки:
1. № з/п;
2. тип;
3. марка;
4. державний номер;
5. технічний стан;
6. рік випуску;
7. залишкова (балансова) вартість, тис. грн;
8. ПІБ працівника;
9. рік народження;
10. номер військово-облікової спеціальності;
11. військове звання;
12. місце проживання.

Працівники беруться лише з явного зв'язку працівник↔ТЗ, уже введеного в r10.

## Пакування

Під час інтенсивної розробки для r1 використовується START artifact. Portable/Setup не збираються для кожного проміжного кроку.
