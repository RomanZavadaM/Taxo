# Taxo 10.5-r7 — цикл звіряння персонального військового обліку через Дію

**Дата:** 28.09.2026  
**Тип:** candidate / fast-test START

## Мета

`10.5-r6` уже перевів інтерфейс на актуальний електронний порядок 2026 року. `10.5-r7` робить цей порядок операційним: Taxo веде локальний контроль циклу **отримання відомостей → актуалізація → фіксація**, але не видає локальну дію за державну операцію.

## Нормативна та сервісна основа

Постанова КМУ №812 від 10.06.2026 (чинна з 27.06.2026) змінила Порядок №1487 і додала електронне звіряння засобами Порталу Дія / кабінету персонального обліку. Додаток 28-1 прямо передбачає електронну взаємодію з Реєстром і визначає, що сформоване та підписане повідомлення про проведення звіряння блокується для редагування та підтверджує проходження звіряння.

Офіційні сервіси, на які спирається інтерфейс r7:
- `https://diia.gov.ua/services/otrymannia-vidomostei-personalnoho-obliku-z-reiestru-viiskovozoboviazanykh` — отримання відомостей персонального обліку;
- `https://diia.gov.ua/services/aktualizatsiia-vidomostei-personalnoho-obliku-pratsivnykiv` — актуалізація доступних відомостей працівників;
- `https://diia.gov.ua/services/fiksatsiia-vidomostei-personalnoho-obliku` — фінальна фіксація відомостей персонального обліку.

## Що реалізовано

### Окремий локальний цикл Дія

Додано `diia_reconciliation.py` і таблицю `military_diia_reconciliation_cycles`. Вона зберігає лише локальну підготовку підприємства:
- рік циклу;
- знімок ЄДРПОУ на момент початку;
- який державний імпорт використано;
- коли відомості фактично імпортовано/звірено в Taxo;
- коли користувач позначив необхідні актуалізації завершеними або непотрібними;
- дату та реквізит фактичної зовнішньої фіксації в Дії;
- короткий результат і примітку.

Ця таблиця **не дублює** наявний офіційний журнал `military_official_reconciliations`.

### Вікно «Звіряння через Дію»

На сторінці працівників додано окремий вхід **«Звіряння через Дію»**. Вікно показує:
- ЄДРПОУ підприємства;
- останній імпорт державного витягу в Taxo;
- кількість активних працівників, наявність РНОКПП та військових карток;
- стан поточного циклу;
- три офіційні етапи й кнопки відкриття точних сервісів Дії;
- резервний порядок на випадок технічної недоступності електронного способу.

### Жорстка межа між підготовкою і фактом

Перші два локальні кроки — «відомості отримано й імпортовано» та «актуалізації завершено / не потрібні» — **ніколи не створюють** статус офіційної звірки.

Запис `RECONCILIATION_DIIA` у чинний `military_official_reconciliations` створюється лише через дію **«Записати результат фіксації»**, коли користувач окремо підтверджує, що операцію вже реально завершено в офіційному сервісі Дії. Для запису потрібен номер/реквізит підтвердження або опис фактичного результату.

Taxo при цьому прямо повідомляє: програма не відправляє дані до Дії / Реєстру «Оберіг» і не може автоматично підтвердити зовнішній державний результат.

## Резервний порядок

Якщо електронний спосіб технічно недоступний або підприємство не має коду ЄДРПОУ, Taxo не блокує військовий облік і нагадує про резервний порядок відповідно до пункту 46 Порядку №1487.

## Безпека даних

- державні XLSX та персональні дані не публікуються в GitHub;
- raw snapshots попередніх ревізій не змінюються;
- локальний цикл не переписує Реєстр «Оберіг»;
- офіційний журнал лишається append-only за змістом проведених процедур;
- regression використовує лише синтетичні дані.

## Перевірка

Додано тести, які перевіряють:
- створення локального циклу без появи офіційної звірки;
- заборону позначення «відомості отримано» без реального імпорту державного витягу;
- відсутність офіційного статусу після локальних підготовчих етапів;
- створення `RECONCILIATION_DIIA` тільки після фактичної фіксації;
- вимогу реквізиту/опису результату;
- readiness-підсумок;
- використання лише офіційних URL `diia.gov.ua/services/...`;
- outermost r7 layer та наявність r7 runtime у START guard.

Точні дані фінального regression run і START artifact додаються після green CI. Після видачі `10.5-r7` ревізія стає immutable; наступний кодовий крок — тільки `10.5-r8`.
