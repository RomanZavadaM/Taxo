# Taxo 10.2-r1 — документи транспортних засобів

**Статус:** candidate  
**База:** Taxo 10.1 stable  
**Дата:** 21.09.2026

## Що додано

У каталог транспортних засобів додано окремий реєстр документів:

- страховка;
- діагностика / техконтроль;
- тимчасовий реєстраційний документ;
- техпаспорт / свідоцтво про реєстрацію;
- протокол перевірки тахографа.

Постійний техпаспорт / свідоцтво про реєстрацію контролюється **завжди**. Тимчасовий реєстраційний документ є додатковим, але якщо в картці авто позначено, що він потрібен, то він стає **обов’язковим**: Taxo контролює його наявність, обов’язкову дату завершення, прострочення та попередження за 30 днів. Постійний і тимчасовий документи мають незалежну історію; новий документ архівує лише попередній документ того самого типу.

Для документа зберігаються номер/серія, видавець або страхова організація, дата початку, строк дії, примітка та копія файла.

## Копії документів

Копії PDF/JPG/PNG/TIFF зберігаються окремо від програми у робочому сховищі:

Інші формати файлів для копій не приймаються; перевірка виконується також у бекенді, а не лише файловим діалогом.

`Data/VehicleDocuments/<vehicle_id>/<document_type>/...`

У БД зберігається переносимий workspace-шлях. Оновлення програми не видаляє копії документів.

## Контроль актуальності

Для активних транспортних засобів Taxo показує:

- **Відсутній** — документа немає;
- **Прострочений** — дата дії минула;
- **Закінчується** — до завершення не більше 30 днів;
- **Актуальний** — документ чинний.

Для страховки, діагностики/техконтролю, тимчасового реєстраційного документа та протоколу перевірки тахографа дата завершення обов’язкова. Для постійного техпаспорта вона може бути порожньою.

Кнопка **«Контроль документів»** збирає проблемні позиції по всіх активних транспортних засобах.

Під час формування шляхового листа Taxo повторно перевіряє документи вибраного автомобіля **на дату шляхового листа**. Якщо документ відсутній, прострочений, не має обов’язкової дати завершення або закінчується протягом 30 днів, програма показує застереження з переліком проблем і вимагає явного підтвердження перед продовженням формування.

## Вбудований перегляд документів

Taxo має спільний внутрішній переглядач для сформованих та архівних документів:
- PDF — сторінки, навігація, масштаб і «По ширині»;
- JPG/JPEG/PNG/TIFF/BMP/WEBP — перегляд без зовнішньої програми;
- DOCX — змістовний preview тексту й таблиць з явним застереженням, що це не точний макет Word;
- є «Зберегти копію», «Відкрити зовнішньо» і друк.

На Windows друк PDF/зображень виконується самим Taxo через GDI, без залежності від установленого PDF-проглядача.

## Звіт стану документів транспортних засобів

У сторінці **«Звіти»** додано звіт на вибрану дату. Він використовує історію документів і не підставляє новий документ у звіт за дату, коли той ще не діяв. Доступні повний список або тільки проблемні/попереджувальні позиції, PDF та Excel.

## Резервні копії та перенесення

Резервування розділено на два режими:

- **звичайний backup** — основна і тахографічна БД копіюються завжди; копії документів авто, тахографічні скани та Output можна додати окремими галочками;
- **повна копія / перенесення** — створює робочу копію для іншого комп'ютера або нового екземпляра Taxo з БД, документами, сканами, шляхівками, бланками, звітами й архівами.

Історія старих резервних копій та технічні логи не дублюються у повній міграційній копії, щоб не роздувати її без потреби.

## Історія

Старі документи не видаляються: запис можна архівувати, а копія лишається у робочому сховищі.

Команда видалення автомобіля перейменована на **«Вивести з експлуатації»**. Вона не стирає історичні записи, документи, шляхові листи чи пробіг.

## Перевірка

Додано regression tests для:
- п’яти типів документів;
- статусів строку дії;
- відсутніх документів;
- 30-денного попередження;
- копіювання файла всередину робочого сховища;
- відхилення непідтримуваних форматів копій документів;
- застереження про проблемні документи під час формування шляхового листа.
