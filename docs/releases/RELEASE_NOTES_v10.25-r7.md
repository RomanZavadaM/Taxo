# Taxo 10.25-r7 — бібліотека шаблонів та оформлення Інструктажів

**Статус:** Test candidate. Stable/Latest залишається 10.24-r9 до окремого прямого рішення власника.

## Що виправлено після ручного приймання r6

- Кнопка «Створити власну копію» більше не завершується помилкою, якщо копія цієї редакції вже існує: Taxo знаходить її та відкриває для редагування.
- У Бібліотеці додано окрему дію «Заповнити поля / підготувати», яка веде від перевіреного шаблону до форми заповнення без пошуку потрібного вікна вручну.
- У перегляді шаблону вкладка «Поля для заповнення» тепер прямо пояснює, де ці поля заповнюються і що Taxo може підставити автоматично.
- Технічні типи на кшталт `order`, `instruction_program`, `notice` у списку замінено зрозумілими українськими назвами.
- Старі видимі дії «Створити власну копію» та «Підготувати чернетку» збережено, щоб не втратити звичний функціонал.
- Підготовлений DOCX Інструктажу явно формується як A4.
- На листі ознайомлення замість внутрішнього/табельного номера друкується посада працівника; сам номер не видаляється зі структурованих даних.
- Для нового планувального шляху у друкованому документі показується людська редакція програми `rN`; старі виклики зберігають exact ID для сумісності та трасування.
- Prepared як і раніше не означає conducted або paper-signed.

## Межі

- Issue #237 залишається відкритим до повторного ручного owner acceptance r7.
- Єдине сховище документів у цьому етапі не починається.
- Реальна робоча база власника автоматичними тестами не відкривається.

## Перевірка

Для r7 додано окремий synthetic regression на існуючу власну копію, прямий шлях заповнення, людські типи документів, A4, посаду на листі підписів і відсутність внутрішнього номера на папері. Повний candidate/exact-source CI фіксується окремо після успішного проходження.
