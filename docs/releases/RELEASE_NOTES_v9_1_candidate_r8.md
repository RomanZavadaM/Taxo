# Taxo 9.1 candidate r8

Source-candidate поверх r7. Основне виправлення — єдине відображення стану дня водія у «Табелі» та «Графіку водіїв».

## Виправлено розходження між вкладками

На реальному сценарії 19.09.2026 для водія з вихідним днем:
- «Табель» показував «Вихідний / 0:00»;
- «Графік водіїв» показував порожній рядок, бо малював лише часові смуги.

r8 вводить спільний `driver_day_view(...)` для обох представлень.

Тепер:
- вихідний на графіку явно підписаний **«Вихідний»**;
- робочий запис без точного часу підписаний **«Робота · час не задано»**;
- порожній будній день без плану підписаний **«Немає плану»**;
- робочі/керувальні інтервали й далі малюються смугами;
- відсутність із `employee_time_entries` однаково перекриває історичний план у табелі й графіку, але сам `worklog` та `work_segments` не видаляються.

## Тести

Додано окремі регресійні тести r8:
- явний вихідний 19.09.2026 не є порожнім станом;
- порожній календарний вихідний має той самий ефективний статус;
- робочі та керувальні сегменти утворюють однакові смуги;
- відсутність персоналу приховує історичний план лише на рівні представлення.

Stable baseline залишається Taxo 9.0.1. r8 не зливається в main до експлуатаційної перевірки.
