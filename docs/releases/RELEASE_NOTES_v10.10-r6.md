# Taxo 10.10-r6 — Працівники: єдиний центр даних і масове поновлення

Статус: **candidate / test revision**. Stable залишається `v10.10-r5`.

## Що змінено

- На головному екрані працівників окремі кнопки роботи з державними даними, Дією, військовим обліком і документами зведено в один вхід **«Дані / Дія / документи…»**.
- Новий центр явно показує обидва підтримувані державні XLSX:
  - «Відомості персонального обліку»;
  - «Відомості про працівників».
- З центру доступні:
  - завантаження/звіряння XLSX;
  - робочі дані вибраного працівника;
  - картка й документи;
  - загальний реєстр документів;
  - офіційний цикл Дії;
  - військовий облік і строки.
- Додано окреме **масове поновлення з останнього імпорту** для вибраних працівників:
  - «Заповнити порожні» — не змінює вже внесені значення;
  - «Прийняти безконфліктні зміни» — може оновити непорожні неідентифікаційні поля.
- Ключові ідентифікаційні реквізити (РНОКПП, дата народження, паспорт/ID та ідентифікатор особи у Реєстрі) не перезаписуються масово при розбіжності й лишаються для ручної перевірки.
- Перед масовим записом Taxo намагається зробити окрему резервну копію основної БД.
- Оригінальні державні snapshots залишаються незмінними.

## Що навмисно НЕ входить у r6

- правила обов'язковості документів конкретного працівника;
- гарантоване копіювання файлів документів у workspace;
- простий місячний графік і персональні/рольові представлення.

Це наступні окремі ревізії, щоб не змішувати кілька великих змін даних та інтерфейсу в один крок.

## Перевірки r6

- нові regression-тести перевіряють масове заповнення порожніх полів;
- масове прийняття незахищених реєстрових змін;
- захист РНОКПП та registry-person-id;
- незмінність raw snapshot після масового застосування;
- старий macOS startup guard збережений для наступних revision.
