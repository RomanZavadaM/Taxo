# Taxo 10.16-r9 — test, portable only

**Статус:** тестовий structural checkpoint, НЕ стабільний. Основна stable / Latest — [v10.16-r8](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.16-r8).

## Що змінилося

- Форма картки водія відділена від реєстру водіїв у `src/taxo/driver_form_ui.py`. Реєстр лишився відповідальним за таблицю водіїв та відомі дії над ними; `driver_registry_ui.driver_form` збережений як сумісний виклик.
- Збережено наявні поля, скролінг, перевірку дат, редагування даних водія, відображення українських/англійських ПІБ для Бланка, дії ролі водія (початок, завершення, виправлення старої помилкової ролі), SQL-запис та оновлення пов'язаного реєстру працівників.
- Додано regression `tests/test_v10_16_r9.py` і перевірку повноти START-пакета на новий модуль.
- **Не змінено:** структура бази даних, шаблони, каталог документів, формати DOCX/PDF, правила backup/restore, масове закріплення водіїв за ТЗ, стабільна r8.
- Стара незавершена r9-гілка заготовок документів не включена у цей випуск.

## Що перевірити вручну

1. Розпакувати ZIP повністю. Відкрити реєстр водіїв.
2. Створити тестового водія, заповнивши ПІБ українською та англійською, дати й посвідчення, зберегти, повторно відкрити картку; перевірити дані та їх відображення.
3. Перевірити вертикальну прокрутку картки на невеликих вікнах і видимість кнопки «Зберегти».
4. Перевірити пов'язаний запис працівника і роль «Водій»; на тестових даних відпрацювати завершення ролі, відновлення та відміну дії, переконатися, що історія не зникає.
5. Перевірити, що інші розділи Taxo (табель і Бланк) бачать ті самі дані водія.

**Увага:** Windows 7 перевіряється в CI на Python 3.8, а не на фізичному Windows 7. Використовуйте тестові дані або резервну копію робочого сховища.

Реліз включає 4 portable ZIP (Windows, Windows 7, macOS Intel/Apple Silicon), START/source ZIP і SHA256. **Інсталяторів у тестовій версії немає.**
