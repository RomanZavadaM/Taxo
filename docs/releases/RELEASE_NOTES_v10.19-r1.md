# Taxo 10.19-r1 — власні копії шаблонів

## Мета

Перший продуктовий крок після завершення security cleanup. Початкова бібліотека
шаблонів лишається read-only. Користувач може створити окрему власну копію
вибраної редакції для майбутнього редагування.

## Що додано

- окреме сховище `CompanyTemplates` у робочому просторі;
- дія «Створити власну копію» у бібліотеці шаблонів;
- копія містить точне походження: пакет, версію, template/revision ID і SHA-256;
- одна й та сама початкова редакція не копіюється повторно випадково;
- початковий `TemplateLibrary` не змінюється;
- `TemplateLibrary` і `CompanyTemplates` включаються у повний backup/restore;
- читання та створення копії не виконуються у Tk UI thread.

## Не входить у r1

- редагування тексту власної копії;
- генерація кінцевого DOCX/PDF;
- архів готових документів;
- міграція `Data/PaperDocuments`;
- автоматичне юридичне затвердження.

Stable/Latest `v10.18-r3` не змінюється.
