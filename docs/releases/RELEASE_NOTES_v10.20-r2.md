# Taxo 10.20-r2 — DocumentVault core

**Тип:** тестова кодова ревізія / Test prerelease.  
**Stable/Latest:** v10.18-r3, без змін.

## Що змінено

- Додано окреме робоче сховище `Data/DocumentVault` для готових та архівних документів.
- До сховища явно реєструється одна конкретна контрольована Word-редакція з `PaperDocuments`.
- Зберігаються точні байти DOCX, SHA-256 та походження: ID документа, prepared snapshot, сім'я і номер редакції, шаблон та його редакція.
- Дві Word-редакції одного документа залишаються двома окремими незмінними об'єктами.
- Повторна реєстрація тієї самої редакції, пошкоджений індекс, змінений файл і файл без запису відхиляються.

## Межі цієї ревізії

- Наявні `PaperDocuments` не переносяться автоматично і не змінюються.
- UI для перенесення документа до DocumentVault ще не додано.
- Скани, оригінали, КЕП та інші підписні докази ще не додаються.
- Наявність запису у DocumentVault не означає «підписано» і не змінює бізнес-статус документа.
- Stable/Latest не просувається автоматично.

## Перевірка

- 1379 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender malware gates для Windows/Win7.
- Перевірка цілісності пакетів після сканування.
