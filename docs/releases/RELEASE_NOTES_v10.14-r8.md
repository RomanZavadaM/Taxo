# Taxo 10.14-r8 — керування водіями і ТЗ у вже створеному наказі

**Дата:** 09.11.2026  
**Тип:** candidate / Feature Loss regression fix.  
**Stable:** без змін, `v10.14-r4`.

## Що показав owner-test

На 10.14-r6/r7 створення нового наказу про закріплення мало масовий вибір водіїв і ТЗ, але у вже створеному наказі через «Редагувати наказ» цей механізм був відсутній.

Причина: блок закріплень створювався лише для нового наказу (`existing is None`).

## Що змінено

- у «Редагувати наказ» для наказу про закріплення видно поточний список ТЗ / держномер / водій;
- «Додати багато…» відкриває масовий вибір саме для цього наказу;
- «Керувати закріпленнями» відкриває штатну вкладку для редагування або видалення окремих пар;
- статус наказу та паперовий підпис не блокують робочі зміни;
- попередження про паперовий підпис більше не накладається на поле тексту наказу.

## Контроль від втрати функції

Сценарій додано як окремий 26-й critical route:
`operations.assignment_existing`.

Він підключений до строгого gate з 10.14-r7:
- mapped;
- onscreen;
- usable;
- activation.

Live-test проходить шлях:
існуючий наказ → «Редагувати наказ» → поточні закріплення видимі → «Додати багато…» активується → відкривається bulk picker → два списки водіїв/ТЗ реально доступні.
