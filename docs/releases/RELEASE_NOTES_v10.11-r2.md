## Зміни

- «Простий місячний графік роботи» формує змістовні назви `Простий_графік_роботи_YYYY-MM_<вибірка>.pdf/.xlsx`.
- Для одного працівника в назві є прізвище та ім'я; для групи — перші прізвища та короткий стабільний код набору; для повної вибірки — `усі-працівники`.
- Лише в PDF простого графіка прибрано колонку «Роль»; ширину передано ПІБ і дням місяця.
- Excel навмисно зберігає колонку «Роль».
- Ролі в БД, кадрові дані, план/факт, графік водіїв, історія та резервування не змінюються.
