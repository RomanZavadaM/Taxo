# Taxo 10.11-r2 — простий графік працівників: друк та назви файлів

**Дата:** 05.11.2026  
**Статус:** candidate / IN PROGRESS до повного CI та ручного приймання.  
**Stable:** без змін, `v10.10-r5`.  
**Попередній виданий кандидат:** `v10.11-r1` — immutable, не переписувати.

## Зміни

- «Простий місячний графік роботи» формує змістовні назви `Простий_графік_роботи_YYYY-MM_<вибірка>.pdf/.xlsx`.
- Для одного працівника в назві є прізвище та ім'я; для групи — перші прізвища та короткий стабільний код набору; для повної вибірки — `усі-працівники`.
- Лише в PDF простого графіка прибрано колонку «Роль»; ширину передано ПІБ і дням місяця.
- Excel навмисно зберігає колонку «Роль».
- Ролі в БД, кадрові дані, план/факт, графік водіїв, історія та резервування не змінюються.

## Перевірки

- 30 і 31 день; довгі ПІБ; одна/кілька/всі вибірки; різні набори однакової чисельності.
- PDF landscape A4; збереження «Роль» у XLSX при її відсутності у PDF.
- Повний Windows / Windows 7 / macOS / START CI обов'язковий перед видачею архіву.
