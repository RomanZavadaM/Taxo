# Taxo 10.18-r2 — військовий облік працівників: узгодження UI

**Тип:** тестова кодова ревізія / candidate.  
**База:** перевірений test checkpoint 10.18-r1; Stable/Latest лишається [v10.17-r10](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.17-r10).

## Що змінено

- Огляд військового обліку, журнал дій і журнал офіційних звірянь стали single-instance вікнами.
- Дві робочі таблиці отримали type-aware сортування та відновлення вибору за стабільним ID.
- Перед «Позначити виконаною» додано підтвердження.
- Загальний helper сортування/відновлення вибору винесено до `table_sorting.py` і повторно використовується військово-транспортним обліком r1.

## Не змінено

Юридичні строки, схема БД, зміст дій і звірянь, plan/fact, документи, backup, бібліотека шаблонів і сховище документів. Stable/Latest — 10.17-r10.
