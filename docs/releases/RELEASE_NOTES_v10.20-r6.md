# Taxo 10.20-r6 — скани паперових оригіналів у вікні документів

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.18-r3, без змін.

## Що змінилось

- У звичайному вікні **«Документи»** для документа, який уже збережений у сховищі, доступна кнопка **«Скани…»**.
- Окреме вікно показує всі прикріплені скани: назву файла, тип, розмір і SHA-256.
- Через **«Додати скан…»** можна вибрати PDF, JPG/JPEG, PNG або TIFF.
- Копіювання великого файла виконується у фоні, тому основне вікно не повинно зависати.
- Після успішного додавання список сканів одразу оновлюється.
- Файл перевіряється чинним захищеним механізмом r5: формат, розмір, дубль і цілісність.
- Кнопка доступна тільки для документа, який уже має запис у сховищі.

## Що не змінювалось

- Скан не означає, що документ підписано.
- КЕП / електронний підпис не додавались.
- Старі документи не переносяться автоматично.
- Бізнес-статуси документів не змінюються через наявність скана.
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1404 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після антивірусного сканування.
