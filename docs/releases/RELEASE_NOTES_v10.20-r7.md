# Taxo 10.20-r7 — відкриття вибраного скана

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.20-r5, без змін.

## Що змінилось

- У вікні **«Скани паперових оригіналів»** для вибраного файла додано явну кнопку **«Відкрити»**.
- Кнопка активна лише тоді, коли вибрано конкретний скан і немає іншої фонової операції.
- Перед відкриттям Taxo повторно читає вкладення через чинний захищений механізм і перевіряє його тип, розмір та SHA-256.
- Перевірка виконується у фоні, щоб основне вікно не зависало.
- Після успішної перевірки PDF або зображення відкривається чинним переглядачем Taxo.
- Автоматичного відкриття немає: файл показується лише після дії користувача.
- Якщо вікно сканів закрити під час фонової перевірки, пізній результат ігнорується і файл уже не відкриється.

## Що не змінювалось

- Скан не означає, що документ підписано.
- КЕП / електронний підпис не додавались.
- Старі документи не переносяться автоматично.
- Бізнес-статуси документів не змінюються через відкриття або наявність скана.
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1408 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після антивірусного сканування.
