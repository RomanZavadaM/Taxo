# Taxo 10.13-r2 — зрозуміліший щоденний СТОІР і накази

**Статус:** candidate / у перевірці

## Що виправлено

Після інтеграції 10.13-r1 повторний UX-аудит показав, що функціональний цикл уже є, але частина щоденних дій усе ще подана технічно або захована у неочевидних жестах.

### СТОІР
- у «Стан автопарку» є явна кнопка **«Відкрити вибране ТЗ»**; подвійний клік лишився як швидке скорочення;
- технічні коди подій `STO` / `REPAIR` більше не показуються користувачу — відображаються «Сезонне ТО» / «Ремонт»;
- джерела одометра мають людські українські назви;
- ISO-дати й timestamps у робочих таблицях показуються у звичному форматі `ДД.ММ.РРРР` / `ДД.ММ.РРРР ГГ:ХХ`.

### Накази
- на робочому столі «Експлуатація → Документи» є пряма дія **«Оформити новий наказ…»**;
- дії реєстру наказів розкладені на кілька рядків замість одного довгого горизонтального toolbar;
- найчастіші типи наказів у «Що потрібно оформити?» показуються адаптивною сіткою 2×N.

## Межі

Не змінюються:
- схема БД;
- plan/fact;
- факти ТО/ремонтів і одометра;
- життєвий цикл/незмінність наказів;
- типові нормативні тексти наказів;
- release/build/security механізми.

## Перевірки

Перед інтеграцією обов'язкові Windows, Windows 7, macOS ARM64/Intel та START checks.
