# Taxo 9.1 candidate r6

Контрольна pre-release точка розвитку модуля **«Персонал»** поверх стабільної 9.0.1.

## Режими робочого часу

У картці/розділі персоналу з'явився окремий **«Режим робочого часу»** з історією дії за датами.

Підтримуються:
- 5-денний робочий тиждень;
- 6-денний робочий тиждень;
- підсумований облік;
- індивідуальний / інший режим.

Шаблони:
- 5/40 — 8+8+8+8+8;
- 6/40 — типовий шаблон 7+7+7+7+7+5, який можна змінити під встановлений на підприємстві графік;
- 6/36 — до 6 год на робочий день;
- 6/24 — до 4 год на робочий день.

Taxo не використовує універсальне правило «8 годин на день» для шестиденного тижня.

## Тижневий баланс персоналу

Додано **тижневий баланс усього персоналу**:
- індивідуальна норма;
- зменшення норми через законні відсутності;
- скоригована норма;
- план;
- факт;
- різниця;
- дні без факту;
- режим та примітка.

Для підсумованого обліку тижнева різниця є довідковою; Taxo не називає її надурочною до завершення встановленого облікового періоду.

Відпустка або лікарняний зменшує норму на години того дня, які за режимом або затвердженим графіком мали бути робочими.

## Масове планування та внутрішнє сумісництво

- один працівник може мати кілька ролей в один день;
- точні часові інтервали не повинні перетинатися;
- приклад 07:00–10:00 механік + 11:00–17:00 водій допускається;
- «8 годин» без початку/кінця — це лише тривалість, не 08:00–16:00;
- план без точного часу дає попередження, а не вигаданий часовий конфлікт;
- точні перетини перевіряються по work_segments, межах worklog і точних route_segments;
- роль «Водій» не дублюється через employee_shifts для працівника, уже пов'язаного з карткою водія.

## Відсутності

Масове внесення:
- щорічних і додаткових відпусток;
- відпусток без збереження зарплати;
- лікарняних;
- інших кодованих відсутностей П-5.

Режими інтервалу:
- лише дні з робочим планом;
- Пн–Пт;
- усі календарні дні.

Факт не перезаписується автоматично.

Нові відсутності відображаються також у старому табелі водія й старому місячному балансі. Історичний маршрут/worklog фізично не видаляється.

## Табель П-5

- PDF;
- редагований Excel .xlsx;
- повна легенда кодів 01–30;
- календар 1–31;
- дата формування, підрозділ, ЄДРПОУ;
- кнопка відкриття сформованого файла відразу після створення;
- кнопки «Відкрити останній PDF / Excel».

Якщо факту ще немає, П-5 використовує планові години з графіка/маршруту. Після появи факту саме факт має пріоритет.

## Сумісність і дані

r6 додає службову таблицю `employee_work_regimes` для історії режимів працівника. Існуючі таблиці робочого часу не переписуються.

Бази даних, скани, кеші та персональні дані не входять до START/Portable/Setup/macOS пакетів.

Стабільною версією залишається **9.0.1**. r6 — pre-release для експлуатаційної перевірки.
