# Taxo 10.2-r7

**Candidate / corrected packaging checkpoint — 21.09.2026**

10.2-r7 переносить без змін функціональний UI-крок 10.2-r6 і виправляє помилкове ім'я тестового ZIP, яке було опубліковане у r6.

## UI

Збережено переробку великих secondary windows у стилі stable 10.1:
- контроль документів транспортних засобів;
- резервна копія;
- робоче сховище;
- реєстр працівників;
- місячний баланс;
- аудит графіків;
- місячний графік;
- персонал випуску;
- шляхівки;
- контроль №340;
- контроль бланків;
- історія змін бланка.

## Packaging fix

Правильна назва пакета цієї ревізії:

`Taxo_v10_2_candidate_r7_START.zip`

У v10.2-r6 помилково був створений asset із префіксом `Taxo_v10_1_...`. Історичний r6 не перезаписується і не пересувається.

## Безпека

- stable `v10.1` не змінюється;
- БД та розрахункова логіка не змінюються;
- попередні tags/releases не переписуються;
- r7 має окремий immutable tag/release.
