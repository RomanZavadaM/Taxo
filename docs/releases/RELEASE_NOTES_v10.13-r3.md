# Taxo 10.13-r3 — «Експлуатація → Інструктажі та журнали»: перша робоча основа

**Статус:** candidate / перевірка; НЕ stable; НЕ повноцінний електронний журнал.

## Що користувач отримує

- В «Експлуатації» окрема видима вкладка **«Інструктажі та журнали»**.
- Два напрями: **безпека дорожнього руху (БДР)** і **охорона праці**; для кожного правильні назви видів інструктажу.
- Видимий квартал і перехід між кварталами як інструмент організації. Це **не** автоматичне юридичне призначення строків.
- Можливість підготувати допоміжний CSV-список для інженера: вид, дата, тема/програма, підстава для позапланового, вибір активних працівників.
- Людські назви файлів, відкриття лише нового файлу без мовчазного перезапису.

## Чого поки НЕ зроблено

- Немає збереження програм і квартальних планів, автоповтору/нагадувань, друку офіційних журналів або реєстрації проведення.
- Немає електронного підпису: фактичне проведення й підписання паперових журналів — відповідальність інженера.
- Підготовчий CSV — **не** офіційний журнал, не доказ проведення і не підтвердження допуску до роботи.
- Не змінювали DB schema, plan/fact, кадрові/транспортні дані, stable, release/build security.

## Правові правила для подальших етапів

- БДР: наказ Мінтрансзв'язку №975 від 05.08.2008, https://zakon.rada.gov.ua/laws/show/z0776-08 ; види й строки за затвердженням керівника, сезонні переходи та окремі подієві підстави.
- ОП: НПАОП 0.00-4.12-05, https://zakon.rada.gov.ua/laws/show/z0231-05 ; строки повторного визначаються відповідними нормами та умовами роботи, загалом не рідше 3/6 місяців залежно від виду робіт.
- Квартал — робочий календар, а не універсальна періодичність; позапланові події не скасовують регулярні.

## Перевірки

- Валідація виду, дати, теми, підстави та вибраних осіб.
- CSV містить очевидну позначку «не журнал» і не містить фіктивних підписів/проведення.
- Старий файл не перезаписується.
- Live UI: вкладка й дія дійсно відображаються і реагують на натискання; старі «Накази»/«Каталог наказів» не зникають.
- Платформні Windows/Win7/macOS та START ще підлягають CI під час випуску цієї ревізії.

## Наступна черга

Окремо спроєктувати сховище затверджених програм і квартальних планів, дати проведення, журналів/метаданих паперових підтверджень; після review — безпечна міграція з тестами на збереження історії.
