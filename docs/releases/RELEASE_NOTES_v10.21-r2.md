# Taxo 10.21-r2 — candidate release notes

- у загальному каталозі «Документи» додано необов'язковий період «Від / До» у форматі РРРР-ММ-ДД;
- межі періоду включні та застосовуються до повного списку до розбиття на сторінки;
- період комбінується з пошуком, джерелом і фільтром наявності сканів;
- записи без коректної дати не видаються за такі, що входять у вибраний період, але без фільтра залишаються видимими;
- сховище, скани, backup/restore, бізнес-статуси, шаблони й формати документів не змінюються;
- КЕП/e-signature, auto «підписано», physical purge і migration не додаються.
