# Taxo 10.20-r10 — заміна скана зі збереженням історії

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.20-r5.

## Що змінилось

У вікні **«Документи» → «Скани…»** для вибраного активного скана доступна **«Замінити…»**.

- Виберіть новий PDF/JPG/PNG/TIFF і підтвердьте заміну.
- Новий файл зберігається окремо. Попередній зникає з активного списку, але його незмінна копія залишається у сховищі й повній резервній копії.
- **«Історія…»** показує попередній скан з дією **«Замінено»**.
- Скасування вибору або відмова від підтвердження нічого не записують.
- Помилковий формат, повтор того самого файла та невдалий запис історії не забирають попередній скан.
- Кнопки розміщені у два ряди, щоб лишатися доступними у вузькому вікні та зі збільшеним шрифтом.

Наявність скана не означає «підписано». Бізнес-статус документа не змінюється.

## Перевірка

- 1430 regression tests, включно з full backup/restore попереднього та нового скана.
- Перевірка відмови/скасування, помилки запису історії й відкату, пошкодження збереженої старої копії.
- Tk-перевірка кнопок у 900×600, 1024×700 та 1366×768, також зі збільшеним шрифтом.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender і перевірка цілісності пакетів після сканування для Windows/Win7.

## Межа випуску

КЕП/e-signature, автоматичне «підписано», фізичне очищення історичних файлів, міграція, нові бізнес-статуси та залежності не додавались. Повний каталог за всіма напрямами Issue #289 ще розвивається.

Комплект тестового випуску: чотири Portable, START і SHA256. Stable/Latest v10.20-r5 лишається поточною стабільною версією.
