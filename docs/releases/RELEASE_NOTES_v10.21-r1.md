# Taxo 10.21-r1 — фільтр документів за наявністю сканів

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.20-r5.

## Що змінилось

У загальному вікні **«Документи»** додано фільтр **«Скани»**:

- **Усі** — чинний повний каталог;
- **Є скани** — документи сховища з одним або кількома активними сканами;
- **Немає сканів** — документи сховища без активних сканів;
- **Помилка перевірки** — документи, для яких стан сканів неможливо безпечно підтвердити.

Фільтр поєднується з пошуком і вибором джерела та застосовується до повного списку до поділу на сторінки.

## Межі

- Записи без копії у сховищі не видаються за документи «без сканів».
- Помилка або невідомий стан не прирівнюється до відсутності скана.
- Фільтр нічого не змінює у файлах, історії, резервних копіях або бізнес-статусі документа.
- Наявність скана не означає «підписано»; КЕП/e-signature не додано.
- Stable/Latest v10.20-r5 не змінюється.
