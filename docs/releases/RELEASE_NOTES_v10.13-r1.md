# Taxo 10.13-r1 — Експлуатація та СТОІР: цілісний робочий сценарій

## Навіщо

«Експлуатація» і СТОІР накопичувалися окремими ревізіями й мали робочі функції, але не складалися в простий сценарій для людини. 10.13-r1 не переписує облік — вона з'єднує вже наявні можливості у зрозумілий робочий процес.

## Що змінено

### СТОІР

- «Стан автопарку» став першою вкладкою;
- подвійний клік по ТЗ переходить до його огляду;
- з UI можна налаштувати періодичність ТО конкретного ТЗ;
- факт ТО/ремонту тепер дозволяє ввести виконавця та примітку;
- пріоритети та стани показуються українською;
- заявка проходить зрозумілий цикл «нова → у роботу → закрита з результатом»;
- закриття без результату блокується;
- з ОТК є прямий перехід до документів ТЗ.

### Експлуатація / накази

- перша вкладка «Документи» стала робочим столом із прямим входом до СТОІР;
- каталог починається з питання «Що потрібно оформити?» і найчастіших дій;
- внутрішня дія названа «Ввести в дію в Taxo» та прямо відділена від юридичного підписання;
- чинні, підписані й скасовані накази не пропонуються для звичайного редагування;
- позначка паперового оригіналу стала однозначною незворотною дією;
- додано перегляд історії наказу й пов'язаних закріплень;
- скасування з UI доступне лише для чернетки.

## Безпека даних

Не змінено:
- plan/fact;
- схему робочої БД;
- історичні записи;
- доменну логіку незмінності наказів 10.9-r8;
- типові тексти наказів;
- release/build workflows.

## Перевірки

Додано regression для:
- збереження індивідуального профілю ТО;
- збереження результату закритої заявки;
- побудови реального STOIR UI з новими діями;
- наявності нового життєвого циклу наказу;
- прямого переходу з робочого столу «Експлуатації» до СТОІР.

Перед інтеграцією потрібні Windows / Windows 7 / macOS Intel+ARM / START checks.
