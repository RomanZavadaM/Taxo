# Taxo 9.1 candidate r9.4

Передетапна стабілізаційна контрольна точка поверх r9.3.

Stable baseline залишається **Taxo 9.0.1**. r9.4 публікується як окремий pre-release і не зливається в main до ручної експлуатаційної перевірки.

## Аудит графіків

Колишню кнопку **«Перевірити графіки»** перероблено на зрозумілий центр **«Аудит графіків…»**.

На добовому графіку тепер одразу видно стан поточного дня:
- `✓ день: помилок немає`;
- або кількість знайдених технічних помилок.

У вікні аудиту можна вибрати область:
- **Поточний день**;
- **Весь місяць**;
- **Активні маршрути**;
- **Місяць + маршрути**.

Перевіряються:
- перекриття робочих частин;
- перекриття інтервалів керування;
- неповні пари часу;
- керування поза межами робочого інтервалу;
- порожні часові частини;
- активні маршрути без жодної часової частини;
- старі worklog без work_segments, якщо точні години збережені у legacy-полях.

Для проблемного дня в результаті тепер показується код/назва пов’язаного маршруту. Подвійний клік відкриває конкретний день або маршрут для ручного виправлення.

Аудит **не переписує історичні дані автоматично**.

## Межа з контролем №340

Технічний аудит графіків навмисно відділено від нормативного контролю. У вікні прямо пояснюється, що Положення №340 — 4:30, добове/тижневе керування, міжзмінний/щотижневий відпочинок тощо — перевіряється окремим модулем. Для вибраного водія є кнопка **«Контроль №340 для водія»**.

## П-5 та персонал

Збережено r9.3:
- типова форма № П-5 у PDF/XLSX;
- стать і оклад/тарифна ставка в картці працівника;
- фактичні категорії надурочних/нічних/вечірніх/вихідних-святкових годин;
- явний вибір перед підстановкою плану замість відсутнього факту;
- виділення та примітка, якщо план використано замість факту.

У документації прибрано застарілі описи, де план виглядав як автоматичний факт.

## Архів бланків і місячний контроль

Збережено r9.3:
- новіші бланки зверху;
- фільтр за вибраним водієм;
- опційний фільтр місяць/рік;
- скидання фільтрів;
- місячна панель водія з вкладками «Дні місяця» і «Контроль №340»;
- кнопка «Відкрити деталізацію».

## Build / release cleanup

Перед r9.4 проведено окремий технічний аудит релізної частини:
- синхронізовано версію в `taxo_app.py`, `v91_features.py`, `personnel_v91.py`, `Taxo.spec`, `Taxo_macos.spec`;
- синхронізовано `BUILD_WINDOWS.bat`, `BUILD_MACOS.sh`, `BUILD_INSTALLER.bat`, `installer/Taxo.iss`;
- поточні Windows/macOS workflows більше не називають нові артефакти v8.70/r11;
- checksum-файли кандидатних build-артефактів мають r9.4-імена;
- source/START publisher використовує новий immutable tag `v9.1-r9.4` і не змінює попередні теги.
