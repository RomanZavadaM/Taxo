# Taxo 10.7-r9 — candidate release notes

## Експлуатація / накази

- додано редаговані типові тексти для основних експлуатаційних наказів;
- при створенні нового наказу поле «Текст пунктів» більше не порожнє для типів, для яких є заготовка;
- при зміні типу нового наказу синхронізуються тема, вступ і типовий текст;
- додано кнопку «Типовий текст» з підтвердженням перед заміною вже відредагованого тексту;
- власний текст користувача має пріоритет і не підмінюється під час збереження;
- додано типи наказів:
  - призначення відповідальних осіб;
  - порядок випуску ТЗ на лінію та повернення;
  - сезонна підготовка транспортних засобів;
- нові типи включені до каталогу та предметних груп.

## Межі

Типові тексти — це внутрішні редаговані заготовки. Вони не містять зашитих номерів статей/пунктів нормативних актів і не замінюють перевірку фактичних реквізитів та змісту наказу перед підписанням.

Stable `v10.3` не змінюється.
