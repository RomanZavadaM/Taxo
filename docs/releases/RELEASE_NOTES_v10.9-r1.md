# Taxo 10.9-r1 — data-access foundation

## Основне

Це перша ревізія лінійки 10.9. Вона продовжує архітектурне розвантаження ядра і готує Taxo до подальшого розширення великими функціональними блоками.

- додано доменно-нейтральний `data_access.py`;
- нові модулі можуть отримувати читання, запис і транзакції через `ApplicationServices.data`, не імпортуючи великий `main.py`;
- доступ до головної БД через `WorkspaceServices` тепер використовує єдину SQLite policy з `database_runtime.py`;
- шлях до робочої БД визначається на кожну нову операцію, тому перемикання workspace не залишає старого cached DB path;
- додано регресійні тести commit/rollback, workspace switching та відсутності UI/domain dependencies у новому infrastructure layer;
- START/source-package guards розширюються актуальними infrastructure modules.

## Сумісність

- схема БД не змінюється;
- дані користувача не мігруються і не перезаписуються;
- предметні SQL-запити старих модулів масово не переписуються;
- UI та бізнес-логіка цією ревізією не змінюються;
- історичні compatibility contracts зберігаються.

## Для подальшої розробки

Нові великі можливості Taxo слід підключати через чіткі межі `domain -> service -> repository/data access -> infrastructure`, з UI як окремим зовнішнім шаром. Існуючі домени переводяться на таку структуру поступово, по одному завершеному блоку на ревізію.
