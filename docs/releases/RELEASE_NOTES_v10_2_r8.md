# Taxo 10.2-r8 — release-safety checkpoint

Це окремий тестовий checkpoint після 10.2-r7.

## Що змінило

- Додано кореневий `PROJECT_RULES.md` як канонічне джерело постійних правил розробки.
- `PROJECT_STATE.md` лишається джерелом актуального стану і наступного кроку.
- Зміни файлів правил тепер запускають обов'язковий Windows CI.
- Додано regression-тести для унікальності назви START-пакета й переходу `r8 -> r9`.
- Видана ревізія r7 не переписується і не видається повторно як новий тест.

## Пакет для ручного тестування

`Taxo_v10_2_candidate_r8_START.zip`

Коренева папка всередині:
`Taxo_v10_2_candidate_r8_START/`

## Важливо

Функціональна логіка програми в цьому checkpoint не змінюється від прийнятого 10.2-r7. Мета r8 — зафіксувати безпечний і однозначний процес наступних тестових видач.

Stable `v10.1` не змінюється.
