# Taxo 10.6-r4 — адаптивна панель дій шляхівок

**Дата:** 28.09.2026  
**Тип:** candidate / fast-test  
**Stable baseline:** Taxo 10.3  
**Base full checkpoint:** Taxo 10.6-r3

## Причина зміни

Під час UI-аудиту після повного checkpoint 10.6-r3 виявлено, що вікно «Шляхівки» містить дев'ять команд в одному горизонтальному рядку. Саме вікно дозволяє звуження до 850 px, а системне масштабування та відмінності шрифтів Windows/macOS додатково збільшують фактичну ширину кнопок. Через це крайні команди могли ставати невидимими без явної прокрутки панелі.

Окремо пояснювальний текст мав фіксований `wraplength=1050`, що суперечило адаптивній геометрії вікна.

## Що змінено

10.6-r4 додає зовнішній runtime-шар `v1064_features.py`, який після створення стандартного вікна шляхівок:

- знаходить уже створений контейнер команд;
- зберігає всі дев'ять чинних кнопок та їхні callback-и;
- прибирає лише старий однорядковий `pack` для цих кнопок;
- розкладає ті самі віджети через `grid` у стільки рядків, скільки потрібно за фактичною шириною контейнера;
- перебудовує рядки при зміні ширини вікна;
- синхронізує `wraplength` пояснювального тексту з шириною вікна.

Команди не перейменовані й не вилучені: «Оновити», «Сформувати / видати PDF», «Відкрити PDF», «Перегляд у Taxo», «Анулювати номер», «Папка шляхівок», «Спідометр / пробіг», «Історія пробігу», «Зміни лікаря/механіка».

## Що не змінено

- видача, повторна видача та анулювання шляхівки;
- номер/серія документа;
- regular/nonregular route logic;
- PDF renderer і payload;
- лікар/механік;
- спідометр і пробіг;
- plan/fact;
- база даних і schema;
- таблиця шляхівок та її вертикальна/горизонтальна прокрутка.

UI-polish навмисно не блокує робочий сценарій: якщо адаптивний post-processing не може застосуватися через нетипове Tk-середовище, базове вікно продовжує працювати.

## Regression contract

Додано `tests/test_v10_6_r4.py`, який перевіряє:

- перенесення елементів за доступною шириною без втрати та зміни порядку;
- повний набір дев'яти команд;
- outermost runtime chain `v1064 → v1063`;
- наявність `v1064_features.py` у START package guard;
- reflow через `Configure`, перехід `pack → grid` і адаптивний wrap;
- збереження обох scrollbar-ів таблиці шляхівок;
- відсутність у r4-шарі доступу до БД/PDF/business-data sources.

## Нумерація

- `10.6-r3` виданий, інтегрований у `main` і immutable;
- цей крок — **10.6-r4**;
- після видачі 10.6-r4 наступна кодова ревізія — **10.6-r5**;
- r4 не зливається у `main` без окремої команди власника.
