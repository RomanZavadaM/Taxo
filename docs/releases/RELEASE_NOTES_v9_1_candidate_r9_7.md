# Taxo 9.1 candidate r9.7

UI hotfix для вікна **«Місячний графік змінності водіїв»** поверх candidate r9.6.

Stable baseline залишається **Taxo 9.0.1**. START hardening r9.6 та функціональний baseline r9.4 збережені.

## Виявлена проблема

У місячному графіку були:
- `PDF — графік`;
- `Відкрити графік PDF`;
- `PDF — деталізація`.

Але для деталізації не було симетричної дії **«Відкрити деталізацію»**, хоча така вимога була зафіксована раніше. Користувач міг лише зберегти деталізацію через діалог, але не відкрити актуальний документ одним натисканням.

## Що зроблено

У панель дій додано кнопку:

**«Відкрити деталізацію»**

Поведінка:
1. бере поточні рік/місяць і фільтр «Тільки активні водії»;
2. формує актуальний PDF через вже наявний `export_monthly_shift_detail_pdf`;
3. використовує стандартний шлях `Деталізація_графіка_змінності_YYYY_MM.pdf`;
4. одразу відкриває сформований файл;
5. не показує зайвий діалог «Зберегти як».

Кнопки впорядковано логічними парами:
- `PDF — графік` → `Відкрити графік PDF`;
- `PDF — деталізація` → `Відкрити деталізацію`.

## Regression test

Додано `tests/test_v9_1_r9_7.py`.

Тест перевіряє:
- кнопку `Відкрити деталізацію` у UI;
- прив'язку до `open_monthly_shift_detail_pdf`;
- використання вибраного року/місяця;
- передачу поточного active-only filter;
- виклик `export_monthly_shift_detail_pdf`;
- автоматичне відкриття сформованого файла.

## Що не змінювалось

- алгоритми розрахунку робочого часу;
- П-5;
- Контроль №340;
- Аудит графіків;
- маршрути;
- табель;
- схеми БД;
- backup/restore;
- START.bat hardening з r9.6.

## Manual retest

1. Відкрити «Графік водіїв».
2. Відкрити «Місячний графік змінності».
3. Перевірити, що видно кнопку **«Відкрити деталізацію»**.
4. Натиснути її.
5. PDF деталізації має сформуватись і відкритися без діалогу «Зберегти як».
6. Звірити рік/місяць та дані документа з матрицею.

До завершення operational gate `main` залишається на stable 9.0.1.
