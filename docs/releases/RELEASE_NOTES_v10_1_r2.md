# Taxo 10.1-r2

**Candidate / UI test checkpoint — 20.09.2026**

10.1-r2 продовжує candidate-лінію після `v10.1-r1`. Stable `v10.0` та попередній candidate `v10.1-r1` залишаються immutable.

## Візуальний стиль

- світла синьо-біла офісна шапка в стилі погодженого макета;
- жовтий автобус на кремово-жовтому графічному знаку без вбудованої назви підприємства;
- назва підприємства виводиться окремим динамічним текстом з поля «Назва підприємства»;
- той самий brand-мотив використовується в головній шапці, secondary windows та іконці збірки;
- додано живий попередній перегляд шапки у вкладці підприємства.

## Табель персоналу

Вікно «Табель робочого часу всіх працівників» перероблено під погоджений макет:
- верхні картки: працівники, план, факт, відхилення, дні без факту;
- підсумок місяця має окрему колонку «Статус»;
- рядки з планом без факту виділяються окремим станом;
- подвійний клік відкриває щоденну деталізацію;
- щоденна вкладка має власні підсумкові картки;
- лікарняні, відпустки, вихідні, ручні записи та відсутній факт мають різні візуальні стани;
- небезпечну кнопку масового «8 год у порожні будні» прибрано з UI.

### Звіти прямо з табеля

У верхню панель винесено:
- «Відкрити деталізацію»;
- «PDF звіт» по всьому персоналу;
- «Excel звіт» по всьому персоналу;
- «Підсумки / контроль»;
- «Місячний табель / баланс»;
- «П-5».

На щоденній вкладці лишаються окремі PDF/Excel та контроль для вибраного працівника.

## Картка працівника

- оформлення приведено до нового стилю;
- основні дані, спеціальні ролі та стан працівника візуально розділено;
- окремо показується історична дата завершення ролі водія;
- прямо пояснено, що статус «Працює / Звільнений» не є роллю «Водій»;
- збережено логіку 10.1-r1: завершення ролі не звільняє працівника, `driver_end_date` не втрачається.

## «Про програму»

Додано окреме брендоване вікно з:
- логотипом і динамічною назвою підприємства;
- версією та типом checkpoint;
- платформою;
- типом бази;
- шляхом робочого workspace;
- шляхом резервних копій;
- переходом до GitHub releases;
- переходом до папки даних;
- переходом у вбудовану довідку.

## Вбудована довідка

- відкривається через меню «Довідка → Довідка користувача» або `F1`;
- має пошук;
- розділи: початок роботи, працівники/ролі, табелі, маршрути/транспорт, документи/П-5, тахограф, резервні копії, гарячі клавіші, FAQ;
- оформлена в тому ж стилі, що й програма.
