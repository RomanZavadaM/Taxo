# Taxo 10.7-r2 — «Експлуатація», накази та закріплення водіїв

**Дата:** 29.09.2026  
**Тип:** candidate / fast-test  
**Stable baseline:** `v10.3`  
**Попередній fast-test:** `v10.7-r1`  
**Попередній full multi-platform checkpoint:** `v10.6-r10`

## Новий контур «Експлуатація»

У головній навігації додано окремий розділ **«Експлуатація»**. Це не дублювання вкладки «Транспорт», а місце для організаційних та експлуатаційних документів підприємства.

Перший крок містить:

- реєстр наказів;
- структуроване закріплення водіїв за транспортними засобами;
- відповідальних осіб;
- окреме місце для майбутніх форм ТО / ремонтів та інших експлуатаційних документів.

## Накази

Модель наказу побудовано за наданими підприємством зразками 2023 року. Підтримано спільний каркас:

- назва підприємства;
- дата, номер, місце;
- тема;
- вступ / підстава;
- блок «НАКАЗУЮ»;
- пункти або таблиця;
- відповідальний за контроль;
- підпис керівника.

Початкові групи наказів:

- закріплення транспортних засобів за водіями;
- зберігання транспортних засобів;
- організація / підсумований облік робочого часу;
- місця відпочинку водіїв;
- спеціальна підготовка / стажування водіїв;
- охорона праці / пожежна безпека;
- інший наказ з експлуатації.

Для наказу про закріплення реалізована таблиця **Транспортний засіб — держномер — водій**. Закріплення має дату початку та необов'язкову дату завершення.

Затверджений наказ стає структурованим фактом Taxo. Склад затвердженого наказу не редагується як чернетка: зміну слід оформлювати наступним наказом.

## Відомість ТЦК

Для відомості по власних / балансових транспортних засобах додано внутрішнє затвердження відповідальним за військово-транспортний обов'язок.

- відповідальний вибирається у `Експлуатація → Відповідальні`;
- затвердження фіксує контрольний fingerprint даних на обрану дату;
- якщо після затвердження реквізити або рядки відомості змінилися, перед PDF/XLSX потрібне повторне затвердження;
- чинне закріплення водія з затвердженого наказу використовується у відомості на відповідну дату;
- якщо нового структурованого закріплення ще немає, збережено сумісність зі старим механізмом зв'язків.

**Важливо:** у затверджену форму для подання не друкуються службові позначки Taxo про джерело імпорту, дату імпорту чи внутрішню історію звірки.

## Дані після імпорту з Дії / державного реєстру

Підтверджені після імпорту реквізити є робочими даними бази Taxo. Для військової робочої картки додано масове перенесення всіх непорожніх розпізнаних реквізитів з останнього імпортованого знімка однією дією.

Оригінальний raw snapshot імпорту лишається незмінним для історії та аудиту. Порожнє поле джерела не використовується як команда очистити локальне значення.

## Незмінні межі

10.7-r2 не змінює:

- plan/fact semantics;
- робочий час, графіки та табель;
- тахографічні виправлення 10.7-r1;
- видані historical tags/releases;
- stable `v10.3`.

## Перевірка

До видачі fast-test обов'язкові:

- повний regression suite;
- clean START package verify;
- перевірка на Windows/macOS через поточні PR gates;
- окремі regression cases для чинності закріплення, затвердження відомості та PDF наказу.

## Далі

Після видачі `10.7-r2` наступна кодова ревізія — **10.7-r3**. Подальші експлуатаційні форми (ТО, ремонти тощо) повинні вбудовуватися у цей контур, а не створювати нові розрізнені розділи.
