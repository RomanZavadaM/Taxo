# Taxo 10.19-r3 — типізована чернетка шаблону

## Мета

Третій крок системи шаблонів. r3 бере **точну власну редакцію**
`CompanyTemplates`, перевіряє типізовані фактичні дані та формує
структуровану чернетку лише в пам'яті для подальшого preview.

## Що додано

- декларативні placeholder-и виду `{{ variable.name }}` підставляються лише
  для полів, оголошених у `variables`;
- підтримані типи: text, date, integer, person_ref, vehicle_ref, pairs,
  participants, sections, table_rows;
- обов'язкові відсутні поля дають явну помилку;
- невідомі поля даних та неоголошені placeholder-и відхиляються;
- optional-поля не зникають мовчки: у preview лишається видимий маркер і warning;
- date нормалізується до ISO у snapshot і показується як DD.MM.YYYY;
- person/vehicle/pairs зберігають стабільні ID у snapshot;
- dynamic_table після підстановки стає звичайною таблицею з конкретними
  рядками; data_source не переноситься у виконувану чернетку;
- чернетка містить SHA-256 та edit revision вихідного CompanyTemplate;
- початковий шаблон, індекс, БД, накази, інструктажі й архів документів при
  формуванні preview не змінюються.

## Безпека і межі

- немає eval/exec/subprocess/SQL write;
- немає виконуваних expression/visible_when;
- немає сліпого перетворення всього шаблону на один текст;
- блоки, списки, таблиці та додатки залишаються структурованими;
- vendor `TemplateLibrary` і власний `CompanyTemplates` не змінюються.

## Не входить у r3

- автоматичне збирання всіх фактів із конкретного наказу/інструктажу;
- фінальний UI заповнення складних наборів pairs/participants;
- DOCX/PDF;
- друк;
- запис у `DocumentArchive`;
- optional scan/PDF підписаного оригіналу.

Stable/Latest `v10.18-r3` не змінюється автоматично.
