# Taxo 10.7-r8 — candidate release notes

- реєстр наказів отримав предметні групи та фільтр за групою;
- тип наказу і група відображаються окремими колонками;
- вкладка-заглушка «ТО / ремонти» замінена повним каталогом експлуатаційних наказів;
- з каталогу можна одразу створити вибраний тип наказу;
- збережені всі типи, додані в r7: БДР, технічний контроль, ТО/ремонти, ДТП/комісії, охорона праці, пожежна безпека та попередні типи.
