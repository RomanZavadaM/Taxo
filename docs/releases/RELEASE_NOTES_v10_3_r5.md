# Taxo 10.3-r5 — candidate

## Архів бланків і контрольне вікно

### Виправлено сортування
Старий код помилково вважав `period_to` ISO-датою. Реальні записи можуть мати формат `19:45 09.09.2026`, тому текстове сортування фактично сортувало спочатку години.

Тепер доступно:
- «Останні створені/змінені» — типовий режим;
- «Період — новіші»;
- «Період — старіші».

Щойно створений або уточнений бланк автоматично виділяється. Додано колонку «Змінено».

### Виправлено лічильники
Активні/вилучені рахуються в тому самому відборі водія та місяця, що й таблиця. Загальний розмір архіву показується окремо.

### Виправлено «Підставити у форму»
- для нового незакритого проміжку — підставляє період у форму;
- для рядка «УТОЧНИТИ ФАКТ БЛАНКА» — одразу відкриває редактор фактичних меж;
- для вже закритого рядка дія недоступна.

Логіка ручного проміжку між роботою і відпочинком з 10.3-r4 не змінюється.

Stable `v10.1` не змінюється.
