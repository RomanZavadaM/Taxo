# Taxo 10.23-r3 — робоча область документів і вибір учасників наказів

Підготовлений тестовий кандидат; статус публікації визначає GitHub Releases. Stable 10.23-r1 не змінюється.

- Документи (бланки): вертикальний розділювач між формою та історією, кнопки збільшення областей, прокручування форми.
- Каталог: регульована ширина дерева папок, компактні ряди дій і дій зі сховищем.
- Учасники / ТЗ: накопичення вибору при зміні пошуку, лічильник, очищення всього вибору, тема активного наказу, прямий перехід до закріплень; підтвердження результату додавання.
- Додано живі регресійні перевірки розділювачів і збереження вибору; 36 суворих UI-маршрутів у реєстрі.

Реальне ручне приймання на різних розмірах та DPI (#562, #553, #556) ще потрібне. Схему даних і механізми збереження документів не змінено.
