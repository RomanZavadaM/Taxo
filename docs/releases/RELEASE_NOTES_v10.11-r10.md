# Taxo 10.11-r10 — спрощення звіту табеля персоналу

**Дата:** 06.11.2026  
**Статус:** candidate / prerelease checkpoint.  
**Stable:** без змін, `v10.10-r5`.  
**Попередній immutable candidate:** `v10.11-r9`.

## Мета

Продовжити системне спрощення інтерфейсу з UX Issue #164 одним вузьким slice без змін облікових даних, plan/fact, БД, маршрутів чи графіків.

## Зміна

У вікні **«Табель робочого часу всіх працівників»**:

- дві паралельні дії «PDF звіт — весь персонал» і «Excel звіт — весь персонал» замінено на один вибір формату;
- формати підписані людською мовою: **«PDF — для друку»** та **«Excel — для редагування»**;
- після вибору формату використовується одна дія **«Зберегти…»**;
- для цього загального звіту ім'я файла уніфіковано як тип + період + коло осіб:
  `Табель_робочого_часу_YYYY-MM_усі-працівники.pdf/.xlsx`.

Внутрішній окремий екран «Місячний табель / баланс» та його поведінка не змінювались.

## Межі

- plan і fact не змінюються;
- розрахунки табеля не змінюються;
- схема БД і дані не змінюються;
- графіки водіїв, маршрути та шляхівки не змінюються;
- CI/release logic не змінюється.
