# Taxo 10.22-r7 — сортування документів за категорією

- У загальному каталозі **«Документи»** заголовок **«Категорія»** став активним: перше натискання сортує напрями А→Я, повторне — Я→А.
- Сортування виконується для всього вже відфільтрованого списку **до** розбиття на сторінки.
- Записи **«Не визначено»** залишаються внизу в обох напрямках.
- Скидання фільтрів повертає стандартний порядок за датою.
- Не змінено БД, DocumentVault, файли й скани, паперовий підпис, backup/restore, накази, пари водій↔ТЗ або Stable/Latest.
- Перевірка: окремий regression для сортування категорій + повний CI.
