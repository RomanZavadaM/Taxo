# Taxo 9.1 candidate r9.5

Пакувально-запускний hotfix поверх **Taxo 9.1 candidate r9.4**.

Stable baseline залишається **Taxo 9.0.1**. r9.5 не змінює функціональну логіку r9.4; він виправляє тестовий START-пакет і робить помилковий запуск прямо з ZIP зрозумілим для користувача.

## Що виправлено

### Запуск START.bat прямо з ZIP

Якщо у Windows/7-Zip запустити `START.bat` без повного розпакування архіву, архіватор може тимчасово витягнути лише сам BAT-файл. У такій папці немає `requirements.txt`, `taxo_app.py` та решти програми.

Раніше користувач отримував технічну помилку:

`ERROR: Could not open requirements file: [Errno 2] No such file or directory: 'requirements.txt'`

У r9.5:
- `START.bat` спочатку перевіряє цілісність папки;
- перевіряються `requirements.txt` і `taxo_app.py`;
- якщо пакет неповний, `pip` не запускається;
- показується чітка інструкція повністю розпакувати ZIP через **Extract all / Видобути все**;
- скрипт завершується окремим кодом `2`;
- окремо перевіряється наявність Python launcher `py`.

### Видима інструкція в архіві

До кореня пакета додано `00_README_START.txt`, який одразу пояснює:
1. не запускати `START.bat` всередині ZIP;
2. повністю розпакувати архів;
3. відкрити розпаковану папку;
4. запускати `START.bat` вже звідти.

## Імена START-архівів

Виправлено генератор імен кандидатних архівів.

Раніше загальний source workflow міг трактувати:
- `r9.4` як `r9`;
- `r9.5` як `r9`.

Тепер повний revision зберігається:
- `9.1 candidate r9.4` → `Taxo_v9_1_candidate_r9_4_START.zip`;
- `9.1 candidate r9.5` → `Taxo_v9_1_candidate_r9_5_START.zip`.

Для цього додано `release_naming.py`.

## Контроль вмісту ZIP

Source package workflow тепер окремо перевіряє наявність:
- `START.bat`;
- `requirements.txt`;
- `taxo_app.py`;
- `00_README_START.txt`;
- `release_naming.py`.

Як і раніше, БД, SQLite, кеші та персональні дані не допускаються до пакета.

## Regression tests

Додано `tests/test_v9_1_r9_5.py`:
- dotted candidate revision не обрізається;
- stable naming залишається сумісним;
- START guard знаходиться перед `pip install`;
- інструкція першого запуску присутня.

Windows CI додатково відтворює неповне витягання: копіює лише `START.bat` у порожню папку і перевіряє, що отримано контрольований exit code `2` та підказку про ZIP.

## Функціональний стан

Усі зміни r9.4 збережені:
- «Аудит графіків…»;
- окремий «Контроль №340»;
- П-5 PDF/XLSX;
- Персонал і режими робочого часу;
- архів бланків;
- місячний контроль;
- canonical exact intervals.

## Як тестувати

**Важливо:** навіть у r9.5 ZIP потрібно повністю розпакувати. Виправлення не робить запуск ізсередини ZIP коректним — воно блокує та пояснює такий неправильний сценарій.

Правильний порядок:
1. завантажити `Taxo_v9_1_candidate_r9_5_START.zip`;
2. **Видобути все / Extract all**;
3. відкрити папку `Taxo_v9_1_candidate_r9_5_START`;
4. запустити `START.bat`;
5. продовжити manual operational gate r9.4/r9.5.

Stable `main` не змінюється до завершення ручної експлуатаційної перевірки.
