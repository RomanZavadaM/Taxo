# Taxo 10.14-r5 — стабілізація редагування додатків до наказів

**Кандидат для експлуатаційного тестування. Stable `v10.14-r4` не змінюється до окремого приймання.**

## Знайдений залишковий дефект

Після переходу наказів на правило «паперовий оригінал контролює людина, Taxo не блокує виправлення» основні накази вже редагувалися незалежно від статусу. Але старий модуль **додатків до наказів** усе ще дозволяв редагування лише у чернетці.

Це було залишкове обмеження старої логіки й суперечило чинному правилу власника.

## Що виправлено

- додаток можна додати, виправити або видалити незалежно від стану наказу;
- «Діє в Taxo», «Скасовано» та паперовий підпис не використовуються як програмний замок для додатків;
- у вікні додатків прибрано текст про редагування лише чернетки;
- при видаленні наказу технічний audit snapshot тепер зберігає також повний перелік його додатків перед видаленням;
- картки працівників/ТЗ і вже створені DOCX/PDF/JPG цією зміною не видаляються.

## Межі

Це вузька стабілізація наказів. Бізнес-логіка план/факт, СТОІР, інструктажі, нумерація, release/build/dependencies та інші робочі дані не змінюються.

## Перевірка

Додано regression для:
- редагування додатка після введення наказу в дію;
- редагування/видалення після скасування;
- збереження додатків у snapshot перед видаленням наказу;
- відсутності старих UI-заборон.

Windows / Windows 7 / macOS / START мають пройти PR CI перед інтеграцією.
