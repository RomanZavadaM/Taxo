# Taxo 10.21-r6 — test prerelease candidate

Вузьке UX-покращення за зауваженням власника: вікно **«Шляхівки»** отримує власну навігацію по даті для зручного перенесення фактичного кілометражу з паперових шляхівок.

- Поле дати у форматі ДД.ММ.РРРР працює незалежно від дати головного графіка.
- Enter або кнопка «Перейти» відкриває шляхівки вибраного дня.
- «День -», «Сьогодні», «День +» дозволяють швидко працювати послідовно по днях.
- Зміна дати лише оновлює рядки вже існуючого вікна; дані не переписуються автоматично.
- Без змін БД/schema, правил пробігу, видачі/анулювання шляхівки, plan/fact, backup/restore, security або залежностей.
