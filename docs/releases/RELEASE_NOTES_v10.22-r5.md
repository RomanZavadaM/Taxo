# Taxo 10.22-r5 — паперовий підпис документа

- У загальному каталозі «Документи» для документа, який уже збережено в DocumentVault, доступна дія «Паперовий підпис…».
- Власник документа явно вводить дату фактичного підписання (РРРР-ММ-ДД), підтверджує дію; в каталозі окрема колонка «Папір / підпис» показує «Підписано: дата» або «Не позначено».
- Помилкову позначку можна прибрати окремою дією. Історія внесення/скасування не стирається.
- Скан НЕ є доказом підписання і не змінює стан автоматично. Підпис може бути позначений без скана; скан можна зберегти окремо через «Скани…».
- Журнал зберігається у workspace Data/DocumentVault/paper_original_events.json, входить до повного backup/restore. Відсутній журнал не означає підпис; пошкоджений журнал не перезаписується.
- Це облікова позначка про **паперовий** оригінал; не юридична перевірка підпису і не КЕП.
- Не змінено immutable DOCX, первинний файл, SQLite, структуру сканів, статус «ready/archived», пари водіїв і ТЗ, stable/latest.
- Перевірки: tests/test_v10_22_r5_paper_original.py, загальний regression suite та exact-source CI перед публікацією.
