# Taxo 10.16-r7 — тестовий portable-випуск

**Статус:** prerelease / тільки для тестування. **Стабільна версія: [v10.15-r5](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.15-r5).**

## Що змінилось

- Винесено транзакційне створення/редагування наказів у `order_editor_persistence.py`.
- Інтерфейс створення наказу залишився відповідальним за поля, вибір водіїв і ТЗ та діалоги.
- До підтвердження збереження звіряється кількість усіх пар водій–ТЗ; помилка зберігання відкатує транзакцію.
- Існуючі формати наказів, схема БД, архів документів і резервне копіювання не змінені.
- Нові перевірки покривають масові пари, неповний запис, редагування та звичайні накази.

## Пакети

Для цього тестового випуску публікуються **лише portable ZIP**: Windows x64, Windows 7 x64 (сумісність), macOS Intel, macOS Apple Silicon і START/source; SHA256SUMS додається окремо. **Інсталятори не публікуються.**

Це тестова структурна гілка, не інтегрована у `main`; реліз не змінює stable/latest. Перед використанням на реальних даних створіть резервну копію. Для перевірки використовуйте окреме тестове сховище.

**CI-перевірки сумісності з Windows 7 не рівнозначні запуску на фізичній Windows 7.**
