# Taxo 10.3-r2 — candidate

## Плановий бланк + фактичні винятки

Початкова логіка Taxo збережена: «ПОТОЧНИЙ — ПІДГОТУВАТИ» формує бланк за планом до виїзду. У звичайному випадку план автоматично вважається фактом — окремий дубль у БД не створюється.

### Коли факт відрізняється
Якщо водій виїхав/повернувся в інший час, маршрут завершився раніше через несправність, водій захворів посеред зміни або виконував роботу поза тахокартою, початковий план не стирається. Taxo записує лише nullable factual override:
- fact_work_start_time
- fact_work_end_time
- fact_work_hours
- fact_source
- fact_updated_at

### Бланк підтвердження
- плановий бланк можна підготувати наперед;
- після факту його можна відредагувати новою ревізією;
- для 14/15/16 зміна меж може встановити фактичну межу роботи;
- 17/18/19 не трактуються як відпочинок;
- плановий час керування не переписується і не блокує раннє фактичне завершення;
- якщо причин кілька, використовуються кілька послідовних бланків.

### План / факт
- графік і планувальні екрани залишаються плановими;
- офіційні табелі та 60-денний реєстр використовують факт, якщо є override, інакше план.

Stable 10.1 не змінюється.
