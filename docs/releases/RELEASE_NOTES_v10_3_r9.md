# Taxo 10.3-r9 — full main checkpoint

## Статус

Ревізія 10.3-r9 завершує прийнятий користувачем стан 10.3-r8 як повний релізний checkpoint перед подальшою розробкою.

Це **пакувальний/релізний крок без нової бізнес-логіки**. Функціональна поведінка відповідає прийнятому 10.3-r8.

## Що фіксується

- manual gate 10.3-r8 прийнятий власником;
- macOS sidebar fix r8 входить у checkpoint;
- виправлення вікна резервної копії r7 входить у checkpoint;
- Windows x64 Setup;
- Windows x64 Portable;
- macOS ARM64 Portable;
- macOS Intel x86_64 Portable;
- START/source;
- SHA-256 окремо для платформ і загальний manifest;
- LICENSE.md, COPYRIGHT.md та THIRD_PARTY_NOTICES.md у пакетах.

## Дані і сумісність

- схема БД не змінюється;
- робочі БД, скани, документи користувача та кеші в release не входять;
- робоче сховище користувача не переноситься і не очищується;
- stable `v10.3` лишається immutable rollback/stable checkpoint і не пересувається.

## Нумерація

Після виданого `10.3-r9` наступний кодовий крок — тільки `10.3-r10`.
