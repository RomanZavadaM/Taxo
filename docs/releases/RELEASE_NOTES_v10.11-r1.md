# Taxo 10.11-r1 — кандидат для тестування інтерфейсу

**Дата:** 05.11.2026  
**Статус:** prerelease / test candidate. **Стабільна версія залишається 10.10-r5.**  
**Правовласник:** Roman Zavada (Роман Завада), © 2026. All rights reserved.

## Що нового

- Вікно «Місячний графік змінності водіїв»: зрозумілий вибір документа (графік PDF / деталізація PDF / редагований Excel) та дві послідовні дії «Переглянути» і «Зберегти…» замість п’яти кнопок.
- Вибір конкретних водіїв для графіка й деталізації; збережено загальний перегляд.
- Вихідні назви звітів водіїв містять тип, місяць, прізвище або склад вибраної групи та формат.
- Українське скорочення «част.» замість російського «ч» в описі частин зміни.

## Попередні виправлення в цій кандидатній лінії

- 10.10-r9: вирівнювання місячного вигляду водіїв з авторитетним водійським планом і виправлення аварії коригування відсутностей.
- 10.10-r10: вибір водіїв для PDF/Excel; українська легенда.

## Відомі зауваження, перенесені до наступної ревізії

Під час користувацької перевірки виявлено, що «Простий місячний графік роботи» зберігає файл із надто загальною назвою `Графік_працівників_2026_11.pdf`, а колонка «Роль» у PDF цього звіту не потрібна. Це **не виправляли повторно в уже виданій r1**, щоб не підміняти протестовану ревізію. Обидва питання внесені в Issue #164 для **10.11-r2**.

## Перевірки

Точний інтегрований код 10.11-r1 перевірено GitHub Actions: Windows, Windows 7, macOS ARM64, macOS Intel та START — SUCCESS. Обов'язкова додаткова перевірка завантаженого застосунку на реальних робочих даних ще триває.

## Дотримання безпеки та сумісності

- Windows (portable, installer), Windows 7 (portable, installer), macOS ARM64 і Intel, вихідний START, SHA256.
- Плани, факт, історичні записи, сховище, БД, скани, документи працівників не змінюються через спрощення вікна.
- **Кандидат не означає нову stable**. Для відкату використовувати підтверджену stable v10.10-r5.
- У пакети не включаються робочі бази чи особисті файли.

## Подальша робота

Приймання власником r1 і продовження Issue #164 наступними ревізіями. Жодних автоматичних змін до кадрового обліку або документів користувача.
