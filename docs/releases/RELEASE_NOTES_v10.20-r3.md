# Taxo 10.20-r3 — DocumentVault UI bridge

**Тип:** тестова кодова ревізія / Test prerelease.  
**Stable/Latest:** v10.18-r3, без змін.

## Що змінено

- У каталозі підготовлених документів додано явну дію «Зберегти вибрану редакцію у сховищі».
- До DocumentVault потрапляє тільки конкретна вибрана контрольована DOCX-редакція; зберігається її незмінна точна копія.
- Додано окремий read-only перегляд DocumentVault зі списком документів і карткою походження.
- Для запису видно назву, тип, дату, стан, редакцію документа, PaperDocuments/PreparedDocuments/CompanyTemplate provenance та exact SHA-256.
- Повторне збереження тієї самої редакції відхиляється зрозумілою помилкою.
- Читання сховища лишається fail-closed при порушенні індексу, об'єкта або контрольного хеша.
- UI-робота винесена в окремий модуль; бізнес-логіка не переносилась у `main.py`.

## Межі цієї ревізії

- Наявні PaperDocuments не переносяться автоматично.
- Скани та оригінали ще не прикріплюються.
- КЕП/digital signature та інші підписні докази не додаються.
- Запис у DocumentVault не означає автоматично «підписано» або «проведено».
- Stable/Latest не просувається автоматично.

## Перевірка

- 1385 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender malware gates для Windows/Win7.
- Перевірка цілісності пакетів після сканування.
