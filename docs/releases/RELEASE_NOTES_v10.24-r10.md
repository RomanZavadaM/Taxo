# Taxo 10.24-r10 — завершальне наскрізне приймання контуру «Накази»

**Статус:** Test release. Stable/Latest залишається 10.24-r9 до окремого прямого рішення власника.

## Що перевіряє r10

10.24-r10 не додає нових бізнес-правил наказів. Це контрольний випуск, який збирає раніше розрізнені гарантії в один наскрізний synthetic-сценарій без доступу до робочої бази власника.

На ізольованому тимчасовому workspace перевіряється:

- звичайний наказ із кількома працівниками та ТЗ;
- редагування ролі/примітки без переписування frozen identity snapshot;
- видалення та повторне додавання учасника;
- наказ про закріплення водій–ТЗ;
- масове додавання пар;
- редагування, видалення та повторне додавання пари;
- закриття SQLite і повторне читання persisted даних;
- перехід «Чернетка → Діє в Taxo» без втрати учасників/пар;
- формування DOCX, PDF та всіх JPG-сторінок;
- однакові ключові реквізити в DOCX/PDF;
- full backup з увімкненим Output;
- restore у новий порожній workspace;
- повна рівність відновлених записів наказів, учасників і пар;
- побайтове SHA-256 порівняння всіх відновлених DOCX/PDF/JPG.

Підготовчий isolated START-прогін перед оформленням candidate: **1713/1713 PASS**, включно з новим r10 end-to-end gate.

## Межі

- Реальна база власника не відкривається і не змінюється цими тестами.
- Це не автоматичне ручне приймання UI; Issue #553 не закривати до перевірки власником Test release.
- Stable/Latest 10.24-r9 не змінюється.
- Draft PR #543/#395 не чіпати.
- Automatic e-mail/mailbox sync, external integrations, OCR/AI APPLY і physical attachment purge не входять у r10.
