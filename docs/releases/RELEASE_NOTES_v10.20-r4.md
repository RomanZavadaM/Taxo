# Taxo 10.20-r4 — єдиний список документів зі сховищем

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.18-r3, без змін.

## Що змінилось

- Документи зі сховища тепер видно у звичайному вікні **«Документи»**.
- Якщо одна й та сама контрольована Word-редакція є і в каталозі, і у сховищі, вона показується одним рядком: **«Word + сховище»**.
- Для об'єднання використовується точний внутрішній зв'язок документа. Однакові назви або дати самі по собі не вважаються одним документом.
- Додано фільтр **«У сховищі»** і колонку **«Джерело»**.
- Якщо сховище пошкоджене або недоступне, справні Word-документи та накази залишаються видимими.
- Після збереження Word-редакції у сховище список оновлюється і одразу показує новий стан.

## Що не змінювалось

- Старі документи не переносяться автоматично.
- Скани, оригінали та електронні підписи не додавались.
- Збереження у сховищі не означає «підписано» або «проведено».
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1390 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після сканування.
