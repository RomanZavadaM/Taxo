# Taxo 10.19-r9 — повторне відкриття чернеток і історія Word-редакцій

10.19-r9 продовжує шлях документа після 10.19-r8. Уже збережені у `PreparedDocuments` чернетки тепер мають окремий список: їх можна знайти після перезапуску Taxo, переглянути, повторно експортувати в DOCX або явно додати до каталогу, не заповнюючи шаблон заново.

Для prepared DOCX у каталозі додано контрольований цикл редагування. Taxo створює окрему зовнішню копію для Word, а відредагований файл приймає назад як нову редакцію `r2`, `r3` і далі. Попередній DOCX не перезаписується. Запис редакції містить сім'ю документа, номер редакції, ID попередньої редакції та SHA-256 фактичного DOCX.

Prepared-документ із каталогу більше не відкривається напряму для редагування: звичайне відкриття пропонує створити контрольовану копію. Це захищає вже записану редакцію від випадкової зміни на місці.

Старі prepared-записи 10.19-r8 читаються як перша редакція без міграції та без переписування. Legacy-документи каталогу залишаються сумісними.

Ця ревізія не створює PDF/print, не вводить DocumentVault, скани чи цифровий підпис і не перетворює prepared DOCX на факт проведення або підписання документа.
