# Taxo 10.15-r2 — готові заготовки наказів та інструктажів

## Що додано

### Інструктажі з безпеки дорожнього руху

У вкладці «Інструктажі та журнали» з'явилася бібліотека готових редагованих програм:
- вступний;
- первинний для водія автобуса;
- передрейсовий/цільовий за маршрутом і погодою;
- цільовий перед перевезенням групи дітей;
- періодичний/повторний;
- осінньо-зимовий для автобусів;
- весняно-літній для автобусів;
- позаплановий при складних погодних/дорожніх умовах;
- позаплановий після події, порушення або появи небезпечної ділянки.

Зимова програма окремо охоплює оглядовість, шини/гальма, склоочисники й омивач, обігрів/опалення, двері та аварійні виходи, ожеледицю, дистанцію, плавне керування, мости/підйоми/спуски, зупинки, пасажирів, вимушену зупинку та залізничні переїзди.

### Охорона праці

Готові заготовки:
- вступний;
- первинний для водія автобуса;
- первинний для механіка/ремонтного персоналу;
- повторний для водіїв;
- зимові умови біля автобуса;
- позаплановий;
- цільовий;
- разова робота біля несправного автобуса на дорозі.

### Накази

Для типів «Безпека дорожнього руху», «Охорона праці», «Навчання / перевірка знань з безпеки» та «Сезонна підготовка транспортних засобів» доступно кілька готових текстів. Користувач вибирає «Типова заготовка» і лише після натискання «Вставити заготовку» замінює тему, вступ і пункти наказу.

Серед готових наказів:
- організація системи інструктажів з БДР;
- осінньо-зимовий і весняно-літній інструктаж водіїв автобусів;
- позаплановий БДР через складні дорожні/погодні умови;
- організація інструктажів з охорони праці;
- повторний, позаплановий і цільовий інструктаж з ОП;
- затвердження програм/графіка інструктажів;
- зимова і літня сезонна підготовка автобусів.

## Обсяг бібліотеки

- 17 типових програм інструктажів БДР/ОП.
- 11 готових заготовок наказів для БДР, ОП, програм інструктажів і сезонної підготовки автобусів.
- ID шаблонів захищені окремим regression-тестом від випадкових дублікатів.

## Як це працює

- Типова заготовка заповнює тему і текст програми, але весь текст можна відредагувати через «Текст програми…».
- Підготовчий CSV тепер містить не тільки список працівників, а й тему, повний текст програми, підставу, ID шаблону та нормативний орієнтир.
- Taxo не ставить автоматичної позначки «проведено» і не зберігає підпис як доказ інструктажу.
- Квартал у Taxo є робочим календарем підприємства, а не автоматично встановленим нормативним строком.

## Нормативні орієнтири

- Для БДР використано структуру чинного Порядку проведення інструктажів та стажування водіїв колісних транспортних засобів, затвердженого наказом Мінтрансзв'язку України від 05.08.2008 № 975: вступний, первинний, передрейсовий (цільовий), періодичний (повторний), позаплановий (спеціальний); сезонні переходи осінь-зима та весна-літо враховані як теми періодичного інструктажу.
- Для охорони праці використано структуру чинного НПАОП 0.00-4.12-05: вступний, первинний, повторний, позаплановий і цільовий інструктажі.
- Конкретні програми, строки, перелік працівників, професійні інструкції, локальні ризики і накази затверджує/визначає підприємство. Заготовки Taxo не підміняють цього рішення.

## Захист від втрати функції

`tests/test_v10_15_r2.py` перевіряє:
- наявність готового шаблону для кожного видимого виду БДР/ОП;
- окремі зимовий та літній автобусні шаблони;
- зміст ключових зимових ризиків;
- збереження повного тексту програми у підготовчому CSV;
- бібліотеку готових наказів;
- наявність контролів вибору/редагування шаблону в живому UI.

Нових зовнішніх залежностей і змін схеми робочої БД немає. Stable v10.14-r4 цією ревізією не змінюється.
