# Taxo 10.20-r5 — основа для сканів паперових оригіналів

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.18-r3, без змін.

## Що змінилось

- Додано безпечне місце для добровільних сканів паперових оригіналів, прив'язаних до конкретного документа у сховищі.
- Підтримуються PDF, JPG/JPEG, PNG та TIFF.
- Файл перевіряється не тільки за розширенням, а й за фактичним форматом.
- Скан копіюється у робочу папку Taxo як окремий незмінний файл.
- Для нього зберігаються власний ID, розмір і SHA-256.
- Той самий скан двічі до одного документа не додається.
- Зміна або підміна вже збереженого скана виявляється.
- Повна резервна копія Taxo зберігає ці скани й відновлює їх разом із документом.

## Що не змінювалось

- Кнопки «Додати скан» у користувацькому інтерфейсі ще немає.
- Наявність скана не означає «підписано».
- Електронний підпис/КЕП та його перевірка не додавались.
- Старі документи не переносяться автоматично.
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1400 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після сканування.
- Backup → restore для документа зі сканом.
