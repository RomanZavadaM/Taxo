# Taxo 10.25-r2 — «На цей квартал» для інструктажів

**Статус:** Test candidate. Stable/Latest залишається 10.24-r9.

## Що додано

r2 будує робочий квартальний екран поверх immutable planning store з 10.25-r1.

- у вкладці «Інструктажі та журнали» є кнопка **«На цей квартал…»**;
- можна перейти на попередній/наступний квартал;
- таблиця показує дату, напрям, вид, режим, назву програми, кількість працівників і стан;
- напрям фільтрується як «Усі / БДР / Охорона праці»;
- стани показуються чесно як «Заплановано / Підготовлено / Прострочено / Проведено»;
- `overdue` обчислюється під час перегляду і не переписує історію;
- подієві заходи показуються окремим режимом і не закривають планові;
- **«Відкрити програму…»** читає саме ту program revision, на яку посилається session;
- таблиця має вертикальний і горизонтальний скрол, а нижні дії лишаються окремою панеллю;
- strict live route `operations.instructions_quarter` перевіряє mapped + onscreen + usable + activation у вікні 780×540.

## Ідемпотентне явне планування

Новий service helper `ensure_planned_session(...)`:
- повтор з тим самим `planning_key` і тим самим program/date/participants повертає існуючий запис;
- той самий ключ з іншою датою/програмою/людьми → fail-closed conflict;
- існуючий запис не переписується автоматично.

Це підготовка до r3, де з'являться UI редагування програм, груп/працівників і масова підготовка. r2 **не вигадує законодавчу періодичність** і не формує conducted автоматично.
