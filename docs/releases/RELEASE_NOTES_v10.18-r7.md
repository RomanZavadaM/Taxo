# Taxo 10.18-r7 — видимий вхід до бібліотеки шаблонів

**Статус:** тестова ревізія, не Stable. Попередня видана на тестування — 10.18-r6, exact head `ad6f60cf2b95cf79597447e42164c5efd91c0155`.

## Чому потрібне виправлення

Після ручного тесту 10.18-r6 власник надіслав знімок вікна «Експлуатація»: у ньому не було видимого входу до нової бібліотеки. Пункт із r6 існував у меню `Шаблони`, але на Windows нативне меню часто сховане за загальною кнопкою меню. Користувачеві не потрібно шукати нову функцію в прихованій навігації.

## Що змінилося

- У вже наявному вікні «Експлуатація → Документи» в секції **«Накази та розпорядження»** додано кнопку **«Бібліотека шаблонів…»**. Вона розташована у вільній правій комірці поряд з «Каталог типів наказів».
- Кнопка просто делегує до `show_template_library()` із r6; вікно бібліотеки, читач, workspace і захист файлів не дублюються.
- Новий модуль `src/taxo/template_library_operations_entry.py` підключено через `feature_layers.py` **після** r6. Стару реалізацію робочого столу `v10710_features.py` і `main.py` як програмний моноліт не редагували; у `main.py` лише змінено `APP_VERSION`.
- Повторне відкриття «Експлуатації» не створює дублікатів кнопки. Якщо модуль бібліотеки недоступний, попередні робочі сценарії не знищуються.
- Додано окремі синтетичні тести адресності кнопки, відсутності дублювань та незмінності існуючого інтерфейсу.

## Що перевіряти вручну

1. З Windows portable відкрити ліворуч «Експлуатація», перша вкладка «Документи».
2. Унизу секції «Накази та розпорядження» праворуч від «Каталог типів наказів» натиснути «Бібліотека шаблонів…».
3. У дочірньому вікні побачити 28 шаблонів із встановленої приватної бібліотеки у **фактичному workspace**: `<workspace>/TemplateLibrary/manifest.json`.
4. Перевірити категорії, пошук, сортування, «Оновити», X/«Закрити» й повторне відкриття обох вікон.
5. Переконатися, що БД/документи/накази не змінилися, а якщо бібліотеки немає — Taxo працює як раніше.

**Конфіденційність:** приватні шаблони та персональні шляхи не входять до відкритих джерел Taxo, CI/архівів/release. Кнопка використовує бібліотеку на комп'ютері користувача.

**Релізний контроль:** r7 — новий code checkpoint, не перевикористання r6. Перед публікацією потрібні source/start, Windows, Win7, macOS CI на одному exact head; офіційні Pre-release r5/r6 ще необхідно узгодити й завершити окремо, stable r3 не змінювати без команди власника.
