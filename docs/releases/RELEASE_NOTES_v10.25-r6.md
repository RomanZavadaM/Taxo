# Taxo 10.25-r6 — виправлення ручного приймання Інструктажів

**Статус:** Test candidate. Stable/Latest залишається 10.24-r9 до окремого прямого рішення власника.

## Що виправлено

- «Основа програми» в Інструктажах тепер реально читає перевірену `TemplateLibrary` для категорій «Інструктажі» / «Навчальні програми», а також придатні власні копії `CompanyTemplates`.
- Накази, акти та інші невідповідні власні шаблони не підмішуються в список основ інструктажу.
- Програми показуються у зрозумілих лініях: планові / річний цикл; початкові / вступні; цільові / перед роботою; позапланові / за подією.
- Для планових повторних БДР та ОП додано редаговані робочі основи на I–IV квартали. Вони не встановлюють законодавчу періодичність автоматично.
- «За подією…» має окреме поле для конкретного випадку / проблеми / питань, які треба додатково розглянути. Базова програма лишається окремою незмінною редакцією.
- Підготовлений DOCX отримав блок «ЗАТВЕРДЖЕНО», затверджувача з редакції програми, місце для підпису й дати, точну редакцію програми та окремий блок конкретної події.
- Підготовка DOCX як і раніше не означає проведення або підписання інструктажу. Факт проведення фіксується тільки окремою ручною дією з паперовим підтвердженням.
