# Taxo 10.25-r6 — доведення Інструктажів після ручного приймання

**Статус:** Test candidate. Stable/Latest залишається 10.24-r9 до окремого прямого рішення власника.

## Чому з'явився r6

Під час ручного приймання v10.25-r5 власник підтвердив, що базова лінія Інструктажів працює, але виявив практичні проблеми: шаблон із бібліотеки не ставав реальною основою програми, планові теми не були організовані в зрозумілий цикл, позаплановий інструктаж вимагав занадто багато ручного набору, а DOCX виглядав як чернетка без нормальної верхньої частини затвердження.

## Що виправлено

- «Основа програми» тепер реально збирає джерела з трьох місць: вбудовані готові теми Taxo, перевірена TemplateLibrary і власні CompanyTemplates.
- Вибраний шаблон копіює свій текст у конкретну immutable редакцію програми; наступні зміни бібліотеки не переписують уже створену редакцію.
- Власні шаблони фільтруються: накази, акти та інші сторонні типи не показуються як основа інструктажу.
- Програми в списку групуються у зрозумілі лінії: планові / річний цикл, початкові / вступні, цільові / перед роботою, позапланові / за подією.
- Для БДР і охорони праці додано по чотири квартальні робочі теми річного циклу. Це саме редакційний календар підприємства, а не автоматичне встановлення законодавчої періодичності.
- У «За подією…» окремо вводиться підстава і окремо конкретний випадок / що додатково розглянути. Базова програма лишається готовим каркасом.
- DOCX отримав блок «ЗАТВЕРДЖЕНО», поле затверджувача, місце для підпису й дати, точну редакцію програми та окремий блок конкретного випадку для подієвих інструктажів.
- Prepared / conducted / paper-first правила не послаблені: згенерований DOCX не означає проведення або підписання.

## Віртуальна перевірка

- Реальна база власника не відкривалась і не змінювалась.
- Перший prep gate коректно зупинився на двох проблемах: захист видимих кнопок помітив перейменування «Підставити», а історичний тест із датою 27.11.2026 став простроченим 28.11.2026. Кнопку повернуто; історичний тест отримав фіксовану контрольну дату без послаблення реального overdue-контролю.
- Після виправлення START regression suite і кросплатформні prep builds пройшли успішно.
- Додано окремий synthetic test: перевірений шаблон категорії «Інструктажі» з TemplateLibrary реально з'являється як основа програми; його власна копія CompanyTemplates також дає той самий текст.

## Межі r6

Не входять: автоматичне визначення законодавчої періодичності, автоматичне conducted, КЕП, OCR/AI APPLY, фізичне видалення історії, зміна Stable/Latest.
