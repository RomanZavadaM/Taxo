# Taxo 10.3-r7 — backup dialog / recovery protocol

## Виправлення вікна «Резервна копія»

На Windows з масштабуванням інтерфейсу нижня панель модального вікна могла опинятися за межами доступної області: були видні лише верхні краї кнопок, а написи «Створити копію» / «Скасувати» фактично обрізалися.

У 10.3-r7:
- робочу висоту діалогу збільшено;
- основний контент і нижні дії розділено на окремі layout-рядки;
- для кнопок зарезервовано власний footer, тому вони не залежать від висоти блоків над ними;
- логіка вибору складу резервної копії не змінена;
- формат робочого сховища й БД не змінюється.

## START_HERE / відновлення роботи

Після порівняння з актуальним механізмом OVDP Hub у Taxo уточнено:
- роль `PROJECT_RULES.md`, `PROJECT_STATE.md`, `WORKLOG.md` та live ledger Issue #61;
- перевірку фактичного GitHub перед продовженням;
- машинну ідентичність `VERSION.txt` + `main.APP_VERSION`;
- роль release index;
- правило завершення slice;
- значення команди власника «злити у main».

Для Taxo **«злити у main»** тепер явно означає повний релізний checkpoint, а не лише merge PR.

## Дані й сумісність

- міграції БД немає;
- робочі дані не перетворюються;
- попередній stable `v10.3` не пересувається;
- `v10.3-r7` є новим immutable candidate checkpoint.
