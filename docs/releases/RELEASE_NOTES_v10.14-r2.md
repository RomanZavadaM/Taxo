# Taxo 10.14-r2 — накази у DOCX, PDF і JPG

**Статус:** кандидат для перевірки, не stable до повного CI/START і ручного приймання.

## Що змінено
- У «Перегляді наказу» доступні кнопки **Створити DOCX**, **Створити PDF**, **Створити JPG**, **Створити все** — за схемою чинних Бланків підтвердження діяльності.
- Кожен тип можна **переглянути у Taxo** або **відкрити у встановленій програмі** Windows/macOS. Для PDF у вбудованому переглядачі є друк, відкриття у зовнішньому PDF-reader також доступне.
- DOCX редагується у Word/сумісній програмі, генерується локально без запуску Word/LibreOffice.
- JPG — **кожна сторінка PDF окремим файлом**, включно з багатосторінковими наказами. Не обмежується двома сторінками, як фіксований Бланк.
- Для повторного створення файл не перезаписується: новий комплект зберігається поруч із власним спільним іменем.
- PDF і JPG використовують єдине джерело — наявний renderer `operations_orders.export_order_pdf`; DOCX створюється з фактичного `order_preview_text`. Тому DOCX **не гарантує ідентичного посторінкового макета з PDF**, але містить ті самі основні текстові реквізити.
- Окремі невеликі модулі `order_document_formats.py` і `order_pdf_workflow.py`. Жодної нової залежності. Старий прямий PDF-друк збережений.
- Дані БД, накази, статуси, підтвердження оригіналів не змінюються.

## Ліцензійна перевірка — 09.11.2026

Перевірено поточні `requirements.txt` і `requirements-win7.txt`, `PROJECT_RULES.md §17`, `THIRD_PARTY_NOTICES.md`. Впровадження **не додає бібліотек**:
- `python-docx` — MIT; створення DOCX.
- `reportlab` — BSD; існуюче створення PDF.
- `pypdfium2` — BSD-3-Clause / Apache-2.0; PDFium (BSD family та власні downstream notices); рендер JPG.
- `Pillow` — permissive (MIT-CMU / Pillow License); запис JPEG з уже отриманого з PDFium зображення.
- `pypdf` — BSD-3-Clause, уже присутній у Taxo, без нової ролі у цьому зрізі.
- **PyMuPDF, fitz, GPL, AGPL не додано.** Для офіційних executable-пакетів чинний license-bundle gate залишається обов'язковим.

Важливо: програми Word, сторонні переглядачі PDF і зображень **не включено в Taxo**; відкриття через призначену операційною системою програму, її власна ліцензія лишається відповідальністю користувача.
