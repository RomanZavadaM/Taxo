# Taxo 10.12-r4 — reachability gate для вкладених маршрутів

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Продовження Feature Loss Audit без зміни бізнес-логіки.

Після r2/r3 залишалися важливі маршрути, для яких код існував і статичні тести були зеленими, але не було перевірки фактичної видимості після складання інтерфейсу.

## Додано

- реальну перевірку видимості пункту **«Експлуатація»** у лівому меню;
- перевірку, що натискання відкриває відповідний робочий розділ;
- реальну перевірку вкладеної кнопки **«Відомість (додаток 1)»** у військово-транспортному обліку;
- перевірку, що ця кнопка реально натискається й веде до потрібної форми;
- вкладена відомість позначена у реєстрі функцій як обов'язкова для runtime-smoke.

## Не змінено

- дані користувача;
- схема БД;
- правила військово-транспортного обліку;
- правила наказів/експлуатації;
- формування PDF/XLSX;
- stable release.

Це test/contract slice: він має ловити ситуацію «функція в коді є, але користувач до неї більше не може дістатися».
