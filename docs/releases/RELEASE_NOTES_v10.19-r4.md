# Taxo 10.19-r4 — типізована in-memory чернетка шаблону

## Мета

Після стабілізації редактора у 10.19-r3 додано окремий чистий renderer,
який бере перевірену власну редакцію з `CompanyTemplates` і типізовані
фактичні дані, але **не записує** чернетку в шаблон, БД або архів.

## Що реалізовано

- новий модуль `company_template_draft.py`;
- окремий модуль `company_template_facts.py` для типів, нормалізації та відображення facts;
- перевірка оголошених змінних шаблону та їх типів:
  - `text`;
  - `date`;
  - `integer`;
  - `person_ref`;
  - `vehicle_ref`;
  - `pairs`;
  - `participants`;
  - `sections`;
  - `table_rows`;
- явна помилка для відсутнього обов'язкового поля;
- явна помилка для невідомого fact або placeholder;
- структурована підстановка лише у текстові поля блоків, списків, таблиць і
  додатків — без сліпого replace по цілому JSON/DOCX;
- динамічні таблиці формуються з типізованих `pairs`, `participants` або
  `table_rows`;
- `person_ref` і `vehicle_ref` використовують стабільні ID та snapshot-поля,
  сумісні з чинним `entity_choices`;
- дата нормалізується як тип і показується у preview як `DD.MM.YYYY`;
- результат містить exact SHA-256 і номер власної редакції, з якої створено
  чернетку;
- renderer працює на deep copy і повертає in-memory preview.

## Гарантії

Preview:
- не змінює `TemplateLibrary`;
- не змінює `CompanyTemplates`;
- не створює запис у main DB;
- не створює наказ, інструктаж або інший бізнес-факт;
- не створює `DocumentArchive`;
- не створює DOCX/PDF.

Regression-тести перевіряють:
- типізовані значення;
- пари водій–ТЗ;
- учасників;
- таблиці;
- вкладені реквізити працівника/ТЗ;
- missing required;
- неправильні типи;
- unknown fact / placeholder;
- незмінність усіх файлів workspace під час preview.

## Межа r4

У r4 немає нового вікна для ручного збору facts. Це окремий backend-контракт
renderer-а, щоб спочатку зафіксувати безпечну поведінку даних.

Наступний логічний крок — **10.19-r5**: UI збору/вибору fact-ів із чинних
реєстрів Taxo та відображення готової in-memory чернетки, без DOCX/PDF і без
архівування.

Stable/Latest `v10.18-r3` не змінюється автоматично.
