# Taxo 10.24-r1 — фундамент ділової кореспонденції

**Робочий Test-кандидат. Stable/Latest залишається 10.23-r4; поточний опублікований Test — 10.23-r10.**

10.24-r1 відкриває нову ревізійну лінію після завершення read-only AI-ready циклу r6–r10. Перший пакет реалізує безпечну основу двох журналів вхідної та вихідної кореспонденції без UI, вкладень і автоматичного надсилання.

## Що додано

- окремі модулі `correspondence_registry` і `correspondence_service`, без перенесення логіки в `main.py`;
- керований реєстр `Data/Correspondence/registry.json` із форматом `taxo.correspondence-registry.v1`;
- стабільний ID запису `cr-...`;
- незалежні річні номерні послідовності для вхідних та вихідних;
- стандартне відображення `Вх. № 0001/2026` і `Вих. № 0001/2026`;
- preview наступного номера не резервує його, реєстрація резервує номер атомарно;
- окремі `registration_date`, `document_date`, `received_date`, `sent_date`;
- окремий зовнішній номер іншої сторони, кореспондент, тема, короткий зміст, спосіб отримання/відправлення, відповідальний, строк і стан;
- явні посилання вихідної відповіді на вхідний лист та related links;
- `document_ref` лише як стабільне посилання на контрольований готовий документ, без копіювання байтів;
- перевірка пошкодженої номерної послідовності fail-closed, щоб уже виданий номер не був виданий повторно;
- same-process parallel registration серіалізується й не дублює номер;
- дані реєстру автоматично входять у чинний full workspace backup/restore як керований файл у `Data`.

## Важливі межі

- реєстрація вихідного листа **не означає**, що його фактично відправлено;
- вхідний лист можна зареєструвати без скана чи вкладення;
- дати документа, отримання/відправлення та реєстрації не змішуються;
- зовнішній номер кореспондента не конфліктує з нашою номерною послідовністю;
- немає автоматичного e-mail, OCR, зовнішнього AI, AI APPLY або фізичного сортування;
- немає нового сховища копій документів чи запису в DocumentVault;
- UI, вкладення, справи та розширене керування станами будуть окремими наступними ревізіями;
- Stable/Latest змінюється тільки окремим рішенням власника.
