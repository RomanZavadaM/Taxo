# Taxo 10.23-r5 — малий viewport каталогу документів

**Робочий Test-кандидат. Stable/Latest залишається 10.23-r4.**

Один пов'язаний пакет із #556 для вікна **«Документи → Каталог»**:

- дерево навігації та основна таблиця мають компактний початковий запит висоти й далі розтягуються у вільний простір;
- колонка дерева адаптується до фактичної ширини лівої панелі;
- шість дій «Мої папки» перенесено з вузької лівої колонки у повноширинну панель дій; функції та назви дій збережено;
- при малому вікні 760×470 другорядні пояснення не відбирають висоту у таблиці та кнопок;
- ширини великих фільтрів зменшуються лише у вузькому режимі й повертаються при збільшенні вікна;
- додано strict live route `documents.catalog_small_viewport`: перевіряються таблиця, горизонтальна прокрутка, 12 основних нижніх дій і 6 дій власних папок у межах 760×470.

Бізнес-логіка документів, сховище, файли, папки та БД не змінюються. Stable 10.23-r4 не змінювати до окремого рішення власника.
