# Taxo 10.21-r10 — категорії у каталозі «Документи»

Ця ревізія додає один вузький крок до єдиного каталогу готових документів.

## Що змінило

- у таблиці «Документи» з'явилася колонка **«Категорія»**;
- додано read-only фільтр **«Категорія»**, який працює разом із пошуком, джерелом, сканами, періодом і типом документа до розбиття на сторінки;
- для наказів категорія визначається лише зі структурованих полів `order_series` і `order_type`, а не з тексту теми;
- доступні категорії: **Кадрові**, **Експлуатаційні**, **Охорона праці**, **БДР**, **Пожежна безпека**;
- старі Word/DocumentVault записи без структурованого напряму показуються як **«Не визначено»**, без автоматичного вгадування;
- кадрова серія має пріоритет: кадровий наказ не потрапляє в іншу категорію лише через його тип;
- вільний текст теми не може сам змінити категорію.

## Межі ревізії

Не змінюються файли документів, DocumentVault, скани, backup/restore, статуси, схема БД або залежності. Дані не мігруються і старі записи не переписуються.

Механізм пар водій↔ТЗ з r9 не змінюється; його ручне приймання власником триває окремо. Stable/Latest не змінюється без прямого рішення власника.
