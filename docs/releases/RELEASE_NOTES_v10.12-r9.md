# Taxo 10.12-r9 — жива перевірка вибору водіїв для звіту

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Захистити маршрут **«Водії для звіту…»** у місячному графіку змінності від повторної втрати через майбутні зміни компонування інтерфейсу.

## Додано

Жива перевірка реального інтерфейсу гарантує, що:
- кнопка **«Водії для звіту…»** існує і видима;
- натискання відкриває вікно **«Вибір водіїв для звіту»**;
- список водіїв реально формується;
- основна дія **«Застосувати»** доступна користувачу;
- реєстр критичних функцій вимагає runtime-smoke для цього маршруту.

## Не змінено

Планування водіїв, табель, план/факт, робочі БД, PDF/Excel-логіка та дані користувача не змінюються.
