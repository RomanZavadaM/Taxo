# Taxo 10.1-r4 — candidate

**Дата:** 20.09.2026  
**Stable baseline:** Taxo 10.0  
**Previous immutable candidates:** v10.1-r1, v10.1-r2, v10.1-r3

## Що виправлено

r3 уже замінив зовнішній application shell, але частина центральних сторінок візуально залишалась схожою на старий Tkinter-інтерфейс. r4 доводить саме робочі сторінки до затвердженого напрямку.

### Реєстр працівників
- заголовок і основні дії винесені у верхній рівень;
- додано KPI-картки: «Всього», «Працюють», «Водії», «Звільнені»;
- другорядні дії перенесені в окрему панель інструментів;
- пошук лишився постійно видимим;
- таблиця та подвійний клік по працівнику збережені.

### Табель
- дії розділено на «Робота з табелем» та «Звіти та друк»;
- окремо видно PDF і Excel по всьому персоналу;
- збережено деталізацію, контроль, місячний баланс і П-5;
- додано кнопку «Папка звітів» у загальному та персональному блоці звітів;
- структура не повинна розповзатися в один довгий ряд кнопок на меншій ширині.

### Допоміжні вікна
- «Про програму» та «Довідка» використовують динамічну назву підприємства у заголовку;
- затверджений text-free логотип лишається єдиним runtime/build icon.

## Безпека даних
- схема БД не змінюється;
- driver-role fix із 10.1-r1 збережено;
- stable v10.0 та immutable r1/r2/r3 не змінюються;
- робочі БД, скани й персональні файли у prerelease не включаються.

## Gate
Перед merge у main обов’язкові автоматичні regression checks і **ручна Windows-перевірка** вигляду та основних дій. До її підтвердження r4 не є stable.
