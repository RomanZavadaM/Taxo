# Taxo 10.16-r8 — тестовий portable-випуск

**Статус:** prerelease / тільки для тестування. **Стабільна версія: [v10.15-r5](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.15-r5).**

## Що змінилось

- Винесено критичний блок закріплення водіїв і транспортних засобів із загального редактора наказу в окремий модуль `order_editor_assignments_ui.py`.
- `order_editor_ui.py` тепер координує загальну форму і делегує assignment-сценарій через явний API замість утримання всього Tk-коду в одному місці.
- Збережено існуючу поведінку: підготовлені пари не губляться при зміні фокусу, правила масового парування не змінені, порожній наказ потребує окремого підтвердження.
- Транзакційне збереження лишається в `order_editor_persistence.py`; схема БД, формати наказів, архів документів і резервне копіювання не змінені.
- Збережено live-test hooks критичного сценарію вибору пар.
- Додано regression-перевірки для делегування assignment-UI, збереження підготовлених пар і підтвердження порожнього наказу.
- Додатково приведено до читабельнішого оформлення верхню частину координатора редактора наказу без зміни логіки.

## Пакети

Для цього тестового випуску публікуються **лише portable ZIP**: Windows x64, Windows 7 x64 (сумісність), macOS Intel, macOS Apple Silicon і START/source; SHA256SUMS додається окремо. **Інсталятори не публікуються.**

Це тестова структурна гілка, не інтегрована у `main`; реліз не змінює stable/latest. Перед використанням на реальних даних створіть резервну копію. Для перевірки використовуйте окреме тестове сховище.

**CI-перевірка сумісності з Windows 7 не рівнозначна запуску на фізичній Windows 7.**
