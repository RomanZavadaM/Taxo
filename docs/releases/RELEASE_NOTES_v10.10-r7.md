# Taxo 10.10-r7 — Документи працівників: вимоги, строки і резерв

Статус: **candidate / test revision**. Stable залишається `v10.10-r5`.

## Що змінено

- Для кожного працівника і типу документа зберігаються дві незалежні ознаки:
  - **«Обов'язковий для цього працівника»**;
  - **«Контролювати строк дії»**.
- Архівування або заміна старої копії документа не скасовує вимогу до цього типу документа.
- Якщо контроль строку ввімкнений, дата «Чинний до» є обов'язковою.
- Вимогу можна встановити ще до отримання копії документа: у такому разі Taxo показує окрему проблему **«Немає резервної копії файла»**.
- Загальний реєстр показує окремо:
  - чинний;
  - закінчується протягом 30 днів;
  - прострочений;
  - потрібна дата закінчення;
  - строк не контролюється;
  - архівний.
- Додано окремий екран **«Контроль обов'язкових документів і строків»**, який за замовчуванням показує проблеми.
- При виборі локального файла документа Taxo копіює його у власне робоче сховище `Data/EmployeeDocuments` і зберігає переносиме посилання.
- Для обов'язкового документа контроль вважається повним лише тоді, коли Taxo має власну копію файла у workspace; зовнішнє посилання саме по собі не закриває вимогу.
- Додано команду зібрати вже наявні локальні файли документів у сховище Taxo. Оригінали не видаляються.
- Копії документів працівників **завжди входять до повної резервної копії Taxo** без окремої галочки.
- Існуючі записи з уже заповненим строком зберігають контроль строку; обов'язковість для старих документів не вигадується автоматично.

## Безпека даних

- Старі документи та історія не видаляються.
- Перед масовим перенесенням існуючих файлів у сховище Taxo створюється резервна копія БД; якщо це не вдається, перенесення не починається.
- Файли копіюються, а не переміщуються.
- Повна backup/restore копія містить бази та `Data/EmployeeDocuments`.

## Перевірки r7

Нові тести перевіряють:
- що вимога до документа переживає архівування старої копії;
- що контроль строку без дати дає проблему;
- що необов'язковий документ також може мати контроль строку;
- що локальний файл копіюється в workspace;
- що повна резервна копія містить файл документа працівника без додаткової опції.
