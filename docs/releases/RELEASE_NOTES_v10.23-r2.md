# Taxo 10.23-r2 — редагування учасників наказів та контроль функцій

Ця версія розвиває 10.23-r1. Статус Stable/Latest визначається фактично опублікованим релізом GitHub, а не самим цим файлом.

## Зміни для користувача

- У розділі «Експлуатація → Накази → Учасники / ТЗ» додано дію «Змінити роль / примітку…» для одного вже доданого працівника або транспортного засобу.
- Після збереження зберігається виділення того самого рядка, а користувач отримує підтвердження результату.
- Заборонено створювати другу таку саму роль для тієї самої сутності в одному наказі. Редагування не замінює особу/ТЗ, їхній збережений історичний знімок чи порядок.
- Зміни записуються в історію наказу і відображаються в тексті для перегляду/друку.
- Панель дій учасників розташовано у два ряди, щоб зменшити ризик прихованих кнопок на вузькому екрані.
- Загальний механізм захисту функцій розширено до 33 суворих UI-маршрутів. Додано Tk, SQLite reopen, audit та preview-перевірки для редагування учасника.
- Синхронізовано ідентичність 10.23-r2 у програмі, START.bat, VERSION.txt та автоматичних перевірках.

## Межі приймання

Повне ручне приймання зручності наказів (#553) залишається відкритим. Загальний захист усіх функцій Taxo (#556) ще розширюється. Зауваження щодо регульованого розміру внутрішньої робочої області «Документи» відстежується окремо (#562): ця зміна **не входить** до коду 10.23-r2.

## Безпека та оновлення

Робочі SQLite-бази, персональні файли та скани не включаються в пакет програми. Перед заміною версії рекомендовано зробити повну резервну копію робочого сховища. Позначка «підписано» не виставляється автоматично лише через наявність скану. Для інсталяційних та portable-пакетів використовувати лише перевірені файли офіційного GitHub Releases із SHA256.

Контрольні результати CI, точний commit/tag та доступні платформи публікуються у GitHub Releases. Не вважати збірку стабільною, доки GitHub не підтвердить Stable/Latest і повний набір файлів.
