# Taxo 10.22-r8 — Бібліотека готових документів: перегляд за видом та датою

**Статус:** кандидат для перевірки; не Stable, не підтверджений реліз.

## Для користувача

У вікні **«Документи»** ліворуч з'являється дерево перегляду з перемикачем:

- **За видами:** групи реальних видів документів із чинного каталогу;
- **За датами:** роки й місяці за датою **документа**, окрема група **«Без дати»**;
- пункт **«Усі документи»** повертає повний перелік;
- числа біля вузлів показують кількість у повному каталозі;
- натисніть на вузол, щоб відфільтрувати весь каталог, а не лише поточну сторінку. Наявні пошук, фільтри та сортування працюють спільно із деревом.

Це **віртуальні папки**: жоден файл не переноситься, не копіюється і не видаляється; вкладення та паперові підписи не змінюються.

## Межі ревізії

Не додано ще користувацькі папки, реєстрацію вхідної/вихідної кореспонденції, нову схему БД, імпорт листів, автоматичну відправку пошти чи зміну backup/restore. Ці етапи описані в draft PR #543 й Issue #289.

## Для перевірки

- «За видами» → «За датами» → «Усі документи»; переключити роки/місяці та «Без дати»;
- пошук/категорія/тип/дата/скан/працівник/ТЗ разом із вибраним вузлом;
- кількість документів і пагінація;
- відкрити старий DOCX, наказ, скан; спробувати додати скан; потім повернутися у дерево;
- Windows, Windows 7 і macOS з малим екраном та збільшеним шрифтом.

**Після обов'язкових CI, публікації і recovery-оновлення** ревізія може бути позначена завершеною. Stable/Latest лишається v10.21-r2.
