# Taxo 9.1 candidate r4

r4 уточнює поведінку табеля персоналу та друкованого П-5 після експлуатаційної перевірки.

## П-5: години з графіка замість «?»

У попередньому кандидатові робочий день без внесеного факту навмисно показувався як `?`, хоча Taxo вже мав планові години з графіка водія/маршруту.

У r4:
- факт має найвищий пріоритет;
- якщо факту ще немає, П-5 використовує планові години з графіка;
- робочий день друкується як **Р / 01** або **РВ / 06** з годинами;
- ознака «факт ще не внесено» лишається внутрішнім контролем, а не засмічує форму знаками питання.

Для старих або неповних записів додано fallback: якщо у `worklog` є `route_id`, але ще немає скопійованих робочих годин, Taxo читає точний робочий сценарій безпосередньо з `route_segments`.

## Відкриття сформованого файла

Після створення PDF або Excel П-5 програма одразу запитує **«Відкрити зараз?»**.

У **Персонал → Звіти** також є:
- **Відкрити останній PDF**;
- **Відкрити останній Excel**.

Тобто для перевірки документа більше не треба вручну шукати робочий каталог.

## З r3 збережено

- окремий верхній розділ **Персонал**;
- вкладки Реєстр / Планування / Табель / Звіти;
- масове планування робочих змін для будь-якої посади/ролі;
- інтервали відпусток, лікарняних та інших відсутностей;
- режими інтервалу: лише дні з робочим планом / Пн–Пт / усі календарні дні;
- відсутність перекриває план у табелі без фізичного видалення графіка;
- фактичні години не перезаписуються масовою операцією;
- повна легенда П-5 з кодами 01–30;
- PDF та редагований Excel;
- дата формування, підрозділ і ЄДРПОУ.

Схема SQLite не змінюється.
