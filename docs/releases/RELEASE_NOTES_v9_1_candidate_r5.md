# Taxo 9.1 candidate r5

r5 перевіряє і виправляє взаємодію масового планування персоналу з графіком водіїв, внутрішнім сумісництвом та старим табелем робочого часу.

## Внутрішнє сумісництво

Один працівник може виконувати кілька ролей протягом одного дня.

Приклад:
- 07:00–10:00 — механік / випуск на лінію;
- 11:00–17:00 — водій / маршрут.

Такий день дозволений, бо точні інтервали не перетинаються.

Якщо інтервали перетинаються, наприклад:
- механік 07:00–12:00;
- водій 11:00–17:00,

Taxo показує конфлікт і не записує другу зміну.

## Важливе правило про «8 годин»

Значення «8 годин роботи» означає лише тривалість.

Taxo більше не робить припущення, що це 08:00–16:00, 09:00–17:00 чи будь-який інший інтервал.

Якщо водійський план містить тільки тривалість без точного часу:
- планування іншої ролі дозволене;
- у попередньому перегляді показується попередження, що перетин неможливо перевірити;
- години сумуються у денному/місячному обліку без вигаданого часу початку.

Для точних перевірок Taxo використовує:
1. work_segments;
2. межі work_start_time/work_end_time у worklog;
3. як fallback — точні work_start_time/work_end_time у route_segments.

## Роль «Водій»

Якщо працівник уже пов'язаний з карткою водія, роль «Водій» не записується повторно в employee_shifts через масове планування персоналу.

Водійська робота планується в **Графіку водіїв / маршруті**, а модуль «Персонал» використовується для додаткових ролей: механік, інженер, диспетчер тощо.

## Відпустки та старий табель

Підтверджено проблему r4: масова відсутність записувалась у employee_time_entries, тоді як старий табель водія читав worklog.

У r5:
- відпустка/лікарняний із персоналу відображається і в старому табелі водія;
- старий місячний баланс не додає робочі години дня, перекритого відсутністю;
- сам маршрут/worklog фізично не видаляється, тому історія плану зберігається;
- після завершення відсутності вихідний графік знову доступний.

## З r4 збережено

- П-5 використовує планові години маршруту до появи факту;
- факт має пріоритет над планом;
- PDF/XLSX можна відкрити одразу після формування;
- повна легенда П-5 01–30;
- масові інтервали відсутностей;
- окремий розділ «Персонал»;
- покращене оформлення шляхового листа.

Схема SQLite не змінюється.
