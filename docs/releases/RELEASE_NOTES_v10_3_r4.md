# Taxo 10.3-r4 — candidate

## Фактична межа бланка задається після факту

Реальне тестування показало, що різниця між плановою межею бланка і фактичною межею роботи трактувалась неправильно: спочатку як окремий короткий бланк, потім — як автоматичне розширення існуючого бланка.

У 10.3-r4 це виправлено.

### Нове правило

- План використовується лише для підготовки бланка наперед.
- До завершення роботи фактична межа вважається невідомою.
- Різниця між планом і фактом не створює окремий бланк.
- Ця різниця не додається до існуючого бланка автоматично.
- Після факту користувач уточнює межу існуючого бланка.
- «Фактичне закінчення попередньої роботи» визначає початок бланка.
- «Фактичний початок наступної роботи» визначає кінець бланка.
- Для позицій 14/15/16 ці межі одночасно стають фактичними межами суміжного робочого часу, якщо worklog існує.
- План при цьому не переписується.

Stable 10.1 не змінюється.
