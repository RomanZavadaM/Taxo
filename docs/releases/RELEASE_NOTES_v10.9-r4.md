# Taxo 10.9-r4 — робочий час та відпочинок

Fast-test ревізія, stacked поверх immutable `v10.9-r3`. Stable `v10.3` не змінюється.

- контроль відпочинку тепер охоплює краї контрольного вікна;
- якщо кваліфікованого щоденного/щотижневого відпочинку немає, це явно потрапляє в попередження;
- перекриття змін позначається як помилка даних;
- збережена модель 3+9;
- додано контроль шести 24-годинних періодів між щотижневими відпочинками;
- додано консервативний двотижневий контроль щотижневого відпочинку;
- PLAN і FACT залишаються розділеними.

Злиття в `main` — тільки за окремою командою власника.
