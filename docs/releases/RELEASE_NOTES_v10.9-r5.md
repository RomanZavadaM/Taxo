# Taxo 10.9-r5 — тахограф / 60-денний реєстр

Fast-test ревізія поверх immutable `v10.9-r4`. Stable `v10.3` не змінюється.

- реєстр більше не перетворює відсутні дані на відпочинок або перерву;
- невідомі хвилини показуються як `Невизначено`;
- явні позначки відпочинку з тахографа лишаються явним джерелом;
- непідтверджений авто-кандидат тахографа більше не перекриває підтверджені/табельні джерела;
- ручне підтвердження оператора лишається найвищим пріоритетом.

Злиття в `main` — тільки за окремою командою власника.
