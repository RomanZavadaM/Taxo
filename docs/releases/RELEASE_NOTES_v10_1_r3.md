# Taxo 10.1-r3

**Candidate / approved UI shell checkpoint — 20.09.2026**

10.1-r3 виправляє головну проблему 10.1-r2: r2 змінив кольори й окремі вікна, але залишив старий каркас Tkinter. У r3 перероблено саме application shell так, щоб він відповідав затвердженому макету.

## Що змінилось у каркасі

- Windows/Linux більше не показують старий native menu row над програмою; повне меню доступне через кнопку `☰` у шапці;
- стандартний ряд вкладок `ttk.Notebook` прихований; Notebook лишається внутрішнім контейнером сторінок;
- додана постійна ліва синя навігаційна панель з окремими іконками;
- верхня шапка побудована як у затвердженому макеті: логотип, `Taxo / <назва підприємства>`, підзаголовок, слоган, дата/час, користувач, Налаштування та меню;
- використовується саме затверджений користувачем логотип-автобус без напису підприємства, а не програмно перемальована приблизна версія;
- назва підприємства лишається динамічною і не вбудовується в графіку;
- додано нижній operational status bar: база, користувач, робоче місце, підприємство та версія;
- у нижній частині sidebar додано дорожній мотив «Дороги об’єднують!»;
- вікно загального табеля переведено на той самий візуальний shell: верхня шапка, sidebar, робоча область і status bar.

## Навігація

Sidebar містить прямі переходи: Працівники, Табель обліку, Графіки, Транспорт, Маршрути, Документи, Тахограф, Звіти, Налаштування.

На macOS системне меню лишається у штатному глобальному menu bar; на Windows/Linux воно не займає окремий рядок усередині вікна.

## Збережено

- driver-role fix із 10.1-r1;
- звіти, картки показників і «Про програму» / F1-довідку з 10.1-r2;
- прямі кнопки табеля: деталізація, PDF, Excel, контроль, місячний баланс, П-5;
- text-free logo / app icon із динамічною назвою підприємства.
