# Taxo 10.21-r4 — candidate release notes

Один вузький крок із Issue #289: у загальному каталозі «Документи» натискання на заголовок **«Дата»** перемикає порядок **новіші ▼ / старіші ▲**.

- Сортування відбувається після пошуку та наявних фільтрів, але **перед розбиттям на сторінки**.
- Записи без коректної дати залишаються в кінці в обох напрямках; однакові дати зберігають попередній відносний порядок.
- Перемикання повертає користувача на першу сторінку; інформація про вибрані фільтри не губиться.
- Каталог тільки читає записи: сховище, скани, файли, резервні копії й бізнес-статуси не змінено.
- Інші колонки не сортуються в цій ревізії. Без міграції, нових залежностей, OCR, КЕП чи автоматичного статусу підпису.
