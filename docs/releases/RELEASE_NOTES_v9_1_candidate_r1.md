# Taxo 9.1 candidate r1

Функціональний кандидат для експлуатаційної перевірки поверх стабільної 9.0.1.

## Місячне планування лікаря/механіка

У вікні **«Випуск на лінію — зміни персоналу»** додано кнопку **«План на місяць»**.

Можна:
- бачити весь місяць однією таблицею: лікар I/II та механік I/II;
- вибрати працівника, зміну, час, D+, місце випуску та діапазон дат;
- застосувати схему **щодня**, **Пн–Пт**, **вибрані дні тижня**, **через день**, **2/2**, **7/7** або власний цикл;
- перед записом переглянути, які дні буде додано, пропущено або заблоковано через конфлікт;
- за окремим прапорцем замінити існуючий план цієї ролі/зміни/місця.

Записи, де вже внесено фактичний час, масове планування не перезаписує.

## Шляховий лист

- якщо назва підприємства заповнена, текст «Місце для штампа автопідприємства» не друкується;
- назва підприємства займає весь відведений блок і автоматично масштабується;
- підставлені програмою дані візуально відокремлені від службових підписів бланку більшим жирним шрифтом;
- посилено видимість ПІБ водія, автобуса, маршруту, дат/часів, лікаря, механіка та показників спідометра.

## Виправлення

Виправлено відому помилку Tkinter `bad window path name ".!toplevel..."` при відкритті табеля персоналу після закриття вікна реєстру працівників.

## Сумісність
