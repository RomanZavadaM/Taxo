# Taxo 10.22-r3 — Test Portable

## Що нового

У загальному вікні «Документи» додано кнопку **«Скинути фільтри»**.

- Одним натисканням повертає всі джерела та всі документи.
- Очищає пошук, період «Від / До», рік, місяць, тип, категорію, фільтр сканів, працівника й автомобіль.
- Повертає сортування за датою (новіші першими) та першу сторінку.
- Скидання запускає лише одне оновлення переліку, не залишає відкладеного повторного пошуку.
- Жодні документи, скани, дані БД, налаштування роботи чи пари водій↔ТЗ не змінюються.

Окремі регресійні перевірки: повний склад полів, повторне скидання, підключення кнопки до оновлення списку.
