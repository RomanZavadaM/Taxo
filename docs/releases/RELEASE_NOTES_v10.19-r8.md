# Taxo 10.19-r8 — запис підготовленого Word у каталог Taxo

Відгук власника: після створення інструкції, власного шаблону, чернетки та DOCX файл не з'являвся у каталозі. r8 додає окрему явну дію «Зберегти DOCX у каталозі Taxo».

У каталозі Data/PaperDocuments зберігається окремий DOCX, побудований з уже збереженої незмінної чернетки. Запис має ID чернетки, ID і редакцію CompanyTemplates, SHA256 вихідної редакції та статус prepared. Підпис не виставляється; дата реєстрації не вважається датою набуття чинності інструкції.

Попередні записи PaperDocuments та чинний каталог наказів не мігруються і не переписуються. Повторна спроба реєстрації тієї самої чернетки відхиляється. Файли залишаються у робочому сховищі, яке входить до повного резервування.

Не входить: імпорт зовнішнього редагованого DOCX, скани, PDF, друк, фінальний DocumentVault, цифрові підписи, автоматичні факти про проведені інструктажі/накази. Власні шаблони — CompanyTemplates; початкова TemplateLibrary read-only. Stable/Latest не змінюється.
