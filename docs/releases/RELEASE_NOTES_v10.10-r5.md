# Taxo 10.10-r5 — release notes

Статус: **STABLE / Latest**. `v10.10-r5` замінює `v10.10-r4`, яка мала підтверджену проблему запуску на macOS.

## Виправлено

- Усунуто аварійне завершення Taxo на macOS під час побудови навігації «Працівники».
- На macOS цей елемент може бути не кнопкою і не підтримувати параметр `command`. Тепер програма перевіряє тип елемента: для кнопки використовує звичайну команду, для іншого елемента — обробку кліку.
- Поведінка Windows не змінюється.

## Перевірено власником 04.11.2026

На Apple Silicon Mac mini:
- запуск із Finder — успішний;
- головне вікно відкривається;
- робоча база підключається;
- «Працівники» відкриваються і показують реєстр.

Перевірена діагностична збірка ще мала старе маркування r4. Оскільки r4 вже видана, офіційна виправлена ревізія — **10.10-r5**.

## Дані

- міграцій робочої БД немає;
- схема даних не змінюється;
- робочі БД, скани й персональні файли до пакетів не входять.

## Перевірка

Повний контроль пройдено успішно: Windows 10/11, Windows 7, macOS ARM64, macOS Intel, START/source та SHA-256. Реліз зібрано з перевіреного main checkpoint.


## Статус попередніх версій

- `v10.10-r4` — superseded через проблему запуску на macOS;
- `v10.9-r10` — попередній безпечний rollback checkpoint.
