# Taxo 10.19-r2 — редактор власних шаблонів

## Мета

Другий крок системи шаблонів після 10.19-r1. Редагується тільки власна копія
підприємства у `CompanyTemplates`; початкова `TemplateLibrary` залишається
read-only і не змінюється редактором.

## Що додано

- окреме вікно «Власні шаблони» з переліком створених копій;
- структурований редактор текстових частин шаблону без перетворення всього
  документа на один суцільний текст;
- підтримка великих текстів для інструкцій та інструктажів;
- редагування назви, опису, текстів блоків, пунктів списків, заголовків і
  клітинок статичних таблиць, текстів додатків;
- службові поля, ID, типи блоків, змінні та data source не редагуються;
- «Зберегти» створює нову власну редакцію; попередній файл редакції зберігається;
- optimistic concurrency: друге застаріле вікно не може мовчки перезаписати
  вже збережену редакцію;
- «Скасувати» та X попереджають про незбережені зміни;
- читання і збереження виконуються поза Tk UI thread;
- редактор, storage і UI залишаються окремими модулями, без логіки у `main.py`.

## Цілісність і межі

- vendor `TemplateLibrary` не змінюється;
- нова редакція зберігає початкове походження template/revision/package/SHA-256;
- індекс `CompanyTemplates` залишається точкою поточного стану;
- backup уже охоплює всі файли `CompanyTemplates`, тому попередні редакції
  потрапляють у повну резервну копію;
- невідомі ключі редактора не можуть змінити службову структуру шаблону.

## Не входить у r2

- підстановка фактичних даних підприємства/працівників/ТЗ;
- генерація DOCX/PDF;
- друк кінцевого документа;
- `DocumentArchive` і міграція `Data/PaperDocuments`;
- видалення або порівняння старих власних редакцій через UI;
- автоматичне юридичне затвердження текстів.

Stable/Latest `v10.18-r3` не змінюється автоматично.
