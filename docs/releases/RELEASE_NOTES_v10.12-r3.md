# Taxo 10.12-r3 — fail-safe маршрут Personnel Data Center

**Дата:** 07.11.2026  
**Тип:** candidate / UI reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Проблема

`Дані / Дія / документи…` був центральним входом до реєстрових даних, документів працівників, масових дій, Дії та військового обліку, але сам вхід додавався runtime-пошуком кнопки `Новий працівник`.

Гірше: старі окремі кнопки ховались **до** перевірки, що новий центральний маршрут реально вдалося створити. Після майбутнього UI-refactor це могло сховати одразу кілька робочих сценаріїв.

## Виправлення

- `Працівники` тепер має постійну штатну кнопку **«Дані / Дія / документи…»**.
- r6 compatibility layer спочатку шукає/гарантує центральний маршрут.
- Старі окремі кнопки ховаються лише після того, як replacement route існує.
- Якщо немає ні постійного входу, ні compatibility anchor, installer нічого не ховає.
- Старий dynamic fallback збережений для історичних composition.

## Regression

Runtime Tk tests перевіряють:
- permanent route не дублюється;
- replacement route mapped;
- legacy entries ховаються тільки після гарантії replacement;
- при відсутньому anchor legacy route лишається mapped;
- fallback button реально викликає callback.

Бізнес-логіка реєстрів/Дії/документів, DB schema і user data не змінюються.
