# Taxo 10.24-r4 — фактичні стани кореспонденції та контроль строків

**Test-кандидат. Stable/Latest залишається 10.24-r3.**

10.24-r4 продовжує окремий модуль кореспонденції після r1 registry, r2 controlled attachments і r3 journal/card UI. Ця ревізія додає лише явні фактичні бізнес-стани та контроль строків; вона не додає автоматичне надсилання e-mail і не вигадує факт отримання/відправлення.

## Що додано

- для вхідних листів окремий явний перехід **«Отримано…»** з обов'язковою фактичною датою отримання;
- для вихідних листів окремий явний перехід **«Надіслано…»** з обов'язковою фактичною датою відправлення;
- реєстрація без фактичної дати не означає sent/received;
- безпечна матриця лише дозволених переходів уперед; закриті/скасовані записи не повертаються у попередні стани;
- окремий append-only журнал переходів стану з from/to, фактичною датою дії та timestamp зміни;
- fail-closed перевірка пошкодженого або нелогічного state-history ланцюжка;
- legacy registry v1 читається й мігрує без втрати нумерації;
- due date використовується для read-only ознаки **«Прострочено»** лише для відкритих записів;
- загальний лічильник прострочених листів у центрі кореспонденції;
- діалог **«Змінити стан…»** показує тільки легальні наступні стани;
- окремий перегляд **«Історія…»**;
- повна резервна копія/відновлення зберігає state history і next number;
- дії стану винесено з resizable card-pane у постійну нижню панель вкладки, тому **«Отримано…» / «Надіслано…» / «Змінити стан…» / «Історія…»** залишаються фізично доступними при minimum viewport 760×520.

## Важливі межі

- attachment не означає sent/received/delivered/signed;
- порожній sent_date або received_date не перетворюється на факт автоматично;
- фактичне «отримано/надіслано» не можна поставити через загальний status picker — лише окремою дією з датою;
- overdue не змінює статус автоматично; це обчислювана контрольна ознака;
- немає автоматичного e-mail, OCR, зовнішнього AI, AI APPLY або physical attachment purge;
- cases/threads та зовнішні інтеграції залишаються окремими наступними ревізіями.
