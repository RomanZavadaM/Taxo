# Taxo 10.18-r5 — тестовий Portable checkpoint

**Статус:** кандидат Pre-release. Не Stable.  
**Вихідна база:** перевірений 10.18-r4 з [PR #393](https://github.com/RomanZavadaM/Taxo/pull/393).  
**Кодова гілка:** `work/v10.18-r5-template-library-reader`, [PR #396](https://github.com/RomanZavadaM/Taxo/pull/396).

## Нове

- Перший окремий, документований read-only модуль `src/taxo/template_library_reader.py`.
- Перевірка встановленої бібліотеки в окремому каталозі `<Taxo-workspace>/TemplateLibrary` (можна читати й переданий явний шлях).
- Стан бібліотеки `NOT_INSTALLED`, `AVAILABLE`, `DAMAGED`, `INCOMPATIBLE`, `UNAVAILABLE`.
- Перевірка manifest, версії, переліку шаблонів, SHA-256, небезпечних шляхів і некоректних умов; без виконання коду з шаблонів.
- Нові синтетичні регресійні тести на читання, незмінність файлів, некоректний вміст, конфлікти ID і небезпечні посилання.
- Історичні тести далі перевіряють старі функції та приймають новий номер `10.18-r5`.

## Що навмисно не зроблено

- Бібліотека **ще не підключена до UI Taxo**, її встановлення і редактор не реалізовані.
- Немає міграцій SQLite, змін архіву документів, руху `Data/PaperDocuments`, зміни механізму резервування або інсталятора.
- Не включено реальних шаблонів, персональних документів чи матеріалів з приватного репозиторію.
- Stable/Latest `v10.18-r3` і rollback `v10.17-r10` не змінюються.

## Контроль

Цей файл не є твердженням, що GitHub Pre-release уже опубліковано. Перед видачею користувачу перевірити на **точному source head** CI START/source, Windows, Win7, macOS Intel/ARM, фактичний release tag, 8 assets, checksum та `prerelease=true`.

Ручне UI/DPI приймання з r4 для ще не перевірених сценаріїв залишається окремим завданням.

**Для тестування після публікації:** завантажити portable для відповідної ОС, перевірити запуск, чинні операції з наказами й сортування тахографа; функція бібліотеки не повинна відображатися як вже готова користувацька можливість.
