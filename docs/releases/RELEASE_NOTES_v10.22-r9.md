# Taxo 10.22-r9 — «Мої папки» для готових документів

**Статус:** кандидат для перевірки; Test Portable, не Stable/Latest.

## Для користувача

У каталозі **«Документи»** до переглядів «За видами» та «За датами» додано режим **«Мої папки»**.

- можна створювати власні папки та вкладені папки;
- папку можна перейменувати;
- вибраний документ можна розмістити в одній або кількох власних папках;
- зміна розміщення не переносить, не перейменовує і не копіює Word/PDF/скани;
- документ не губиться з папки після збереження його точної редакції у DocumentVault;
- дерево папок та розміщення документів входять до повної резервної копії Taxo і відновлюються разом із робочим сховищем.

## Надійність

- Дані папок зберігаються окремо у `Data/DocumentLibrary/collections.json`; самі готові документи залишаються у своїх чинних контрольованих сховищах.
- Запис індексу атомарний; перевіряються дублікати назв одного рівня, відсутні батьківські папки, цикли дерева та дубльовані прив'язки.
- Один документ може бути у кількох папках без створення кількох фізичних копій.
- Пошкоджений індекс не перезаписується «мовчки».
- DocumentVault, скани, позначки паперового підпису, накази й бізнес-дані при операціях із папками не змінюються.

## Межі цієї ревізії

Ділова кореспонденція (вхідні/вихідні журнали, нумерація, кореспонденти, відповіді та строки) **ще не реалізується** — її план залишається окремим наступним етапом після фундаменту бібліотеки.

**Stable/Latest:** 10.21-r2 — без змін.
