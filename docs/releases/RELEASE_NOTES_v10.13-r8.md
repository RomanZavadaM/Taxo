# Taxo 10.13-r8 — безпечне масове закріплення

**Статус:** candidate / у перевірці.  
**Stable не змінюється:** v10.12-r10.

## Що виправлено

10.13-r7 додала масове формування наказу про закріплення, але self-audit перед видачею власнику виявив один суперечливий сценарій: чернетка дозволяла вибрати одного водія для кількох ТЗ з однаковим періодом, тоді як чинний захист введення наказу в дію правильно забороняє одночасне закріплення одного водія за різними ТЗ.

У r8 цей конфлікт прибрано ще на етапі вибору.

Дозволено:
- **1 ТЗ → кілька водіїв**;
- **N ТЗ ↔ N різних водіїв** — пари за порядком вибору;
- старий сценарій однієї пари.

Блокується:
- **1 водій → кілька ТЗ** з одним періодом;
- неоднозначна різна кількість ТЗ/водіїв більше одного.

## Перевірка введення в дію

Нові тести проходять через реальний чинний approval guard:
- 1 ТЗ + кілька водіїв — наказ успішно вводиться в дію;
- N різних пар — наказ успішно вводиться в дію;
- вручну створений конфлікт одного водія на кілька ТЗ — approval блокується й наказ лишається чернеткою.

## Що не змінено

- автонумерація r7 лишається без змін;
- work/personnel series лишаються окремими;
- frozen snapshots r6 лишаються;
- історія та immutability чинних наказів лишаються;
- stable/release/security не змінюються.
