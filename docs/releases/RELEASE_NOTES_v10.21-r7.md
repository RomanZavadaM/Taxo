# Taxo 10.21-r7 — Test prerelease

У вікні **«Шляхівки»** до навігації з r6 додано кнопку **«Дата…»**, яка відкриває той самий календар, що й у «Графіки».

- Можна вибрати будь-який день календаря без ручного введення та послідовних переходів.
- Вибір дня відразу оновлює шляхівки; закриття календаря без вибору нічого не змінює.
- Ручна дата, Enter, «Перейти», «День -», «Сьогодні», «День +» залишаються.
- Лише UI-навігація. Пробіг, видача шляхівок, дані, схема БД, резервування, безпека та залежності без змін.
