## Що змінилося

- Вікно «Перегляд наказу» більше не стискає довгі кнопки DOCX/PDF/JPG у чотири колонки: дії згруповані у дві адаптивні колонки.
- Нижні дії «Оновити зміст / Редагувати / Сформувати PDF / Закрити» мають стабільну 2×2 сітку.
- Пояснювальний текст перегляду й статус формату адаптуються до фактичної ширини вікна.
- Верхній опис центру «Експлуатація» переноситься за реальною шириною робочої області.
- Живий Tk-тест виявив і закрив реальний дефект: при 760×560 стандартна висота Text могла повністю витиснути блок форматів за межі видимої області.
- Додано strict runtime route `operations.order_preview_formats`; у stable r4 реєстр має 37 strict live routes.

## Що ще входить у r4

Stable r4 включає інтегровані зміни r2/r3: редагування ролі/примітки учасника наказу, накопичення вибору при пошуку, тему активного наказу й прямий перехід до закріплень, регульовану область «Документи → Бланки» та регульовану ширину дерева каталогу.

Бізнес-логіка наказів, схема БД і формати документів у r4 не змінювалися. Ручне приймання саме r4 виконано; ширші #553/#556 залишаються відкритими до окремого повного закриття.
