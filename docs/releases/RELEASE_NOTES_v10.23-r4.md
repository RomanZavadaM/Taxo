# Taxo 10.23-r4 — адаптивний перегляд наказів

Робочий кандидат. Окремий реліз створювати лише після завершення пов'язаного пакета та перевірок. Stable 10.23-r1 не змінюється; v10.23-r3 навмисно не публікувався.

- Вікно «Перегляд наказу» більше не стискає довгі кнопки DOCX/PDF/JPG у чотири колонки: дії згруповані у дві адаптивні колонки.
- Нижні дії «Оновити зміст / Редагувати / Сформувати PDF / Закрити» мають стабільну сітку замість зустрічного pack.
- Пояснювальний текст перегляду й статус формату адаптуються до фактичної ширини вікна.
- Верхній опис центру «Експлуатація» переноситься за реальною шириною робочої області, а не фіксованими 1180 px.
- Додано strict runtime route для створення/перегляду форматів наказу та живу перевірку малого вікна 760×560 / центру 940×600.

Бізнес-логіка наказів, дані, схема БД та формати документів не змінюються. #553/#556 залишаються відкритими до ручного приймання.
