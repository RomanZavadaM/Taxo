# Taxo 10.8-r3 — release checkpoint notes

## Відомість ТЦК: виправлення дати

Виправлено помилку формування відомості ТЦК, яка виникала при звичайній для Taxo даті у форматі **ДД.ММ.РРРР** (`30.09.2026`).

Раніше внутрішній код очікував лише ISO-формат `YYYY-MM-DD` і викликав `date.fromisoformat()` без нормалізації. Тепер модуль приймає `ДД.ММ.РРРР`, ISO, `date` та `datetime` і переводить дату у внутрішній ISO-формат перед запитами до БД.

Додано regression tests для:

- `30.09.2026`;
- `2026-09-30`;
- `date` / `datetime`;
- помилкової дати з зрозумілим повідомленням користувачу.

## Реквізити відомості у картці транспортного засобу

До панелі **«Картка транспортного засобу»** додано дію **«Реквізити ТЦК»**.

Для конкретного ТЗ можна зберігати:

- належність до власного / балансового парку для цієї відомості;
- тип ТЗ;
- технічний стан;
- залишкову (балансову) вартість, тис. грн;
- примітку.

Ці поля **не є обов'язковими для звичайної картки автомобіля**. Вони використовуються при формуванні відповідної відомості ТЦК. Якщо належність до власного/балансового парку не визначена, Taxo не включає автомобіль до офіційної відомості мовчки, а залишає його для уточнення.

Реквізити зберігаються у вже наявній таблиці `vehicle_military_transport_statement_data`; нова паралельна сутність не створюється.
