# Taxo 10.21-r5 — test prerelease candidate

Один вузький крок з Issue #289: у загальному каталозі «Документи» заголовок **«№»** перемикає сортування за номером (зростання ▲ / спадання ▼).

- Числові частини порівнюються чисельно: 2 перед 10; у складних номерах 2-А перед 10-А.
- Порожні номери — в кінці у двох напрямках, однакові сортувальні ключі зберігають вихідний порядок.
- Сортування застосовується до повного відфільтрованого списку **перед пагінацією**, комбінується з пошуком, джерелом, типом, сканами та датами.
- Перемикання колонки повертає першу сторінку. Сортування за «Дата» з r4 збережене.
- Без запису у сховище, змін сканів, схеми БД, backup/restore, бізнес-статусів, КЕП чи нових залежностей.
