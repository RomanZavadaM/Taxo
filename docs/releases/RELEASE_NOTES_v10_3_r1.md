# Taxo 10.3-r1 — candidate

## Бланк підтвердження: межі відпочинку ≠ межі тахокарти

Водій може виконувати роботу до першої лінії керування і після останньої: підготовка до рейсу, оформлення документів, медогляд, робота з автомобілем тощо. Цей час не повинен автоматично потрапляти у відпочинок.

### Нова модель
- `start_time/end_time` — керування/маршрут;
- `work_start_time/work_end_time` — повна робоча зміна;
- межі Бланка визначаються за повною робочою зміною;
- перед-/післямаршрутний запас береться індивідуально зі сценарію маршруту;
- при зміщенні фактичного маршруту запас переноситься разом із ним;
- фіксованого буфера N хвилин немає.

### Зміна Бланка → зміна робочого часу
Для вже існуючого Бланка:
- новий «Період з» автоматично стає кінцем попередньої роботи;
- новий «Період по» автоматично стає початком наступної роботи;
- `work_hours` і крайні `work_segments` перераховуються;
- час керування `start_time/end_time` не переписується;
- якщо межа Бланка потрапляє всередину керування, операція блокується.

Механізм r10 «УТОЧНИТИ БЛАНК» та r9-перевірка DOCX збережені.

Stable 10.1 не змінюється.
