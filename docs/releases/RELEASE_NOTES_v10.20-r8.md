# Taxo 10.20-r8 — безпечне прибирання помилкового скана

**Тип:** тестова ревізія / Test prerelease.  
**Stable/Latest:** v10.20-r5, без змін.

## Що змінилось

- У вікні **«Скани паперових оригіналів»** для вибраного скана додано явну дію **«Прибрати»**.
- Перед дією Taxo просить підтвердження і прямо пояснює, що незмінний файл не видаляється фізично.
- Прибраний скан більше не показується у звичайному активному списку документа.
- Сам файл залишається у workspace як immutable-копія, тому історія не губиться і випадкове прибирання не стирає доказовий матеріал.
- Дія записується в окрему перевірювану історію з часом, ID документа та ID скана.
- Кнопка **«Історія…»** показує прибрані скани користувачу.
- Прибрані файли залишаються під контролем SHA-256 та перевіряються на цілісність.
- Чинний повний backup/restore переносить і immutable-файл, і його історію.
- Додавання, відкриття, прибирання та перегляд історії виконуються без зміни бізнес-статусу документа.

## Що не змінювалось

- Скан не означає, що документ підписано.
- КЕП / електронний підпис не додавались.
- Автоматичний статус «підписано» не встановлюється.
- Фізичний purge файла не реалізований.
- Однокнопкова заміна скана не входить у цю ревізію.
- Старі документи не переносяться автоматично.
- Stable/Latest не змінюється автоматично.

## Перевірка

- 1414 regression tests.
- Windows, Windows 7, macOS Intel та Apple Silicon.
- Microsoft Defender для Windows/Win7.
- Перевірка цілісності пакетів після антивірусного сканування.
