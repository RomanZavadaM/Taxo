# Taxo 10.1

**Stable release — 21.09.2026**  
**Previous stable / rollback:** Taxo 10.0  
**Verified candidate before stable:** v10.1-r5

Taxo 10.1 переводить перевірену лінію 10.1-r1…r5 у стабільну експлуатаційну версію. Основний акцент релізу — новий інтерфейс, коректне розділення статусу працівника і ролі водія, впорядковані звіти та усунення циклічного відкриття повних вікон програми.

## Інтерфейс
- новий application shell: світла брендована шапка, синій sidebar, центральна робоча область і нижній status bar;
- точний text-free логотип використовується в програмі й пакетах;
- назва підприємства береться з налаштувань і не вшита в логотип;
- реєстр працівників має KPI-картки, видимий пошук і окремі основні/другорядні дії;
- «Про програму» та F1-довідка оформлені в єдиному стилі.

## Працівники та роль водія
- статус працевлаштування не змішується з роллю «Водій»;
- завершення ролі водія не позначає працівника звільненим;
- після перезапуску завершена роль водія не відновлюється;
- історична дата завершення ролі зберігається окремо;
- повторне прийняття працівника не активує роль водія автоматично.

## Звіти і табель
- головний пункт «Звіти» відкриває сторінку в основному workspace;
- «Звіти → Працівники → Звіти» не створює нових головних вікон;
- детальний табель персоналу працює як single-instance secondary window;
- у детальному табелі немає дубльованого повного sidebar;
- збережено PDF/Excel, П-5, місячний баланс, контроль і пряме відкриття папки звітів.

## Дані та сумісність
- схема робочої БД у 10.1 не змінюється;
- оновлення використовує існуюче робоче сховище;
- повторно вводити дані не потрібно;
- робочі БД, SQLite, скани, кеші й персональні документи не входять у GitHub artifacts;
- перед оновленням рекомендована резервна копія.

## Перевірка
Останній кандидат **v10.1-r5** пройшов:
- source / START — **157 tests / OK**;
- Windows — **157 tests / OK** + START preflight OK;
- macOS ARM64 — **157 tests / OK**;
- macOS Intel x86_64 — **157 tests / OK**;
- ручний Windows UI/navigation gate — підтверджено користувачем 21.09.2026.

Після merge stable publisher повторно виконує regression suite вже з версією 10.1 та формує всі офіційні пакети.
