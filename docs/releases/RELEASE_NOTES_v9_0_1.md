# Taxo 9.0.1

**Taxo 9.0.1 — стабільне експлуатаційне виправлення гілки 9.0.**

## Що виправлено

- головне вікно тепер показує актуальну версію **Taxo 9.0.1**, а не застарілий напис `v8.70 r9`;
- вікно **«Про програму»** також показує актуальну версію й актуальний опис системи;
- START-архів формується з очищеної експлуатаційної гілки `main`, тому в ньому більше немає старих `CHECKPOINT_v8*`, `TEST_REPORT_v8*`, `PUBLISH_STATUS_v8*`, патчів і ранніх службових матеріалів розробки;
- робоча база, структура даних і функціонал Taxo 9.0 не змінюються.

## Відоме питання в діагностиці

Під час експлуатації зафіксовано Tkinter-помилку `bad window path name`. Для точного виправлення потрібен traceback із локального журналу `Taxo_errors.log`; проблема не маскується припущенням і буде виправлена окремо після підтвердження конкретного callback.

## Пакети

Реліз містить:

- Windows x64 — Setup;
- Windows x64 — Portable;
- macOS ARM64 — Portable;
- macOS Intel x86_64 — Portable;
- `Taxo_v9_0_1_START.zip` для перевірки через `START.bat`;
- файл контрольних сум SHA-256.

Робочі бази, скани тахокарт і персональні документи до релізу не включаються.
