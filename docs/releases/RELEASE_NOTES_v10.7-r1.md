# Taxo 10.7-r1 — безпечне повторне розпізнавання тахографічних шайб

**Дата:** 29.09.2026  
**Тип:** candidate / fast-test  
**Stable baseline:** `v10.3`  
**Попередній full checkpoint:** `v10.6-r10`

## Виправлено

Під час аудиту актуального `main` підтверджено кілька дефектів контрольного модуля аналогових тахографічних шайб.

### Ручні інтервали більше не видаляються

Раніше `recognize_all()` та `recognize_selected()` повністю очищали таблицю `intervals` для шайби перед створенням нових автокандидатів. Через це повторне розпізнавання могло видалити вже перевірені оператором рядки `source='manual'`.

У 10.7-r1 автоматичне повторне розпізнавання замінює тільки `source='auto'`. Ручні інтервали зберігаються.

### Імпорт не перераховує весь каталог

Раніше після кожного імпорту викликався `recognize_all()`. Тепер автоматично обробляються тільки щойно імпортовані записи з визначеним колом.

### Без прихованої зміни даних при виборі запису

Простий вибір шайби більше не запускає неявне автодобудовування інтервалів. Розпізнавання виконується тільки явною командою користувача або для нових записів одразу після імпорту.

### Межа 00:00

- виправлено circular run у `_polar_signal`, коли темний слід переходить через 00:00;
- шкала дня тепер малює інтервал через 00:00 двома сегментами замість майже нульової смужки.

### Імпорт без знайденого кола

Відновлено реальне попередження користувачу. Такий запис зберігається, але автрозпізнавання не запускається.

## Regression

Додано тести на:

- збереження `manual` при заміні `auto`;
- circular run через 00:00;
- нормальні та wrap-around сегменти шкали дня;
- синхронізацію `10.7-r1` у `VERSION.txt`, `main.APP_VERSION` і entry-point.

## Не змінено

- основний `worklog`, табель і графіки;
- plan/fact semantics;
- схема основної БД;
- видані historical tags/releases;
- stable `v10.3`.

## Далі

Після видачі 10.7-r1 наступна кодова ревізія — `10.7-r2`. Окремими slices перевірятимуться пріоритети факт/план у 60-денному реєстрі, тижневі межі, режими праці та інші підтверджені дефекти.
