# Taxo 10.12-r10 — жива перевірка «План → факт»

**Дата:** 07.11.2026  
**Тип:** candidate / Feature Loss reachability hardening.  
**Stable:** без змін, `v10.10-r5`.

## Мета

Захистити живий користувацький маршрут **«План → факт»** у табелі персоналу, не змінюючи його бізнес-логіку.

## Додано

Жива перевірка реального інтерфейсу гарантує, що:
- дія **«План → факт»** реально доступна у щоденному табелі;
- натискання проходить через явне підтвердження користувача;
- перевірка виконує реальний запис у тимчасовій ізольованій SQLite-БД, а не лише шукає кнопку;
- план копіюється у факт лише там, де факт відсутній;
- уже наявний підтверджений факт не змінюється;
- планові поля та примітки не переписуються побічно;
- реєстр критичних функцій вимагає runtime-smoke для цього маршруту.

## Безпека даних

Regression-тест створює власну тимчасову БД і не звертається до робочого сховища користувача. Після тесту тимчасові дані знищуються.

## Не змінено

Алгоритм **«План → факт»**, схема робочої БД, планування, звіти, release/build механізми та реальні дані користувача не змінюються.
