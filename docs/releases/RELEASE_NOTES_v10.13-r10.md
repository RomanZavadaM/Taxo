# Taxo 10.13-r10 — видимий наказ і прямий друк

**Статус:** owner fast-test candidate.  
**Stable не змінюється:** v10.12-r10.

## Чому зроблено

Після ручного тестування 10.13-r9 власник підтвердив, що створення наказу вже не падає, але готовий текст наказу і шлях до друку неочевидні.

Технічно PDF існував, однак:
- кнопка «Сформувати PDF» була захована серед дій реєстру;
- після створення наказу про закріплення Taxo переходив на вкладку закріплень;
- фактичний текст, який друкується для наказу про закріплення, не показувався як цілісний документ до PDF.

## 10.13-r10

### «Перегляд наказу»

Додано окреме вікно з фактичним змістом наказу перед друком:
- «Н А К А З»;
- підприємство;
- дата, номер, місце;
- тема;
- вступ / підстава;
- «Н А К А З У Ю»;
- для закріплення — усі вибрані пари ТЗ / водій;
- контроль за виконанням;
- підписний блок.

Для інших типів наказів preview показує збережені пункти та структурованих учасників / ТЗ.

### Прямий друк

У preview є велика кнопка **«Сформувати PDF / друк»**. PDF створюється тим самим чинним механізмом і автоматично відкривається для перегляду / друку.

У реєстрі наказів окремо є **«Переглянути / друк»**.

Подвійний клік по наказу також відкриває preview.

### Після створення

Після створення Taxo:
1. лишається на вкладці «Накази»;
2. виділяє новий наказ;
3. автоматично відкриває його текст.

Тобто користувач одразу бачить, що саме створено і що піде на друк.

## Regression

Нові тести перевіряють:
- r10 identity;
- preview реального наказу з кількома водіями;
- номер, дату, місце, тему, «НАКАЗУЮ»;
- наявність усіх пар ТЗ/водій;
- контроль та підписний блок;
- preview порожньої чернетки без закріплень;
- прямі UI-входи «Переглянути / друк» і «Сформувати PDF / друк»;
- автоматичне відкриття preview після створення;
- double-click по реєстру.

## Версійний цикл

10.13-r10 завершує цикл 10.13. Наступна кодова ревізія після видачі r10 — **10.14-r1**.
