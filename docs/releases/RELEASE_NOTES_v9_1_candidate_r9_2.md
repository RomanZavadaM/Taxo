# Taxo 9.1 candidate r9.2

Контрольна source/START точка після r9.1.

## Зрозумілий статус відсутності

Фраза:
- «план перекрито відсутністю»

замінена на:
- **«План збережено; день позначено як відсутність»**.

Це точніше описує модель Taxo: історичний графік/маршрут не видаляється, але для табеля день обліковується як відсутність.

## Перевірка вже введених графіків

У вкладці «Графік водіїв» додано кнопку **«Перевірити графіки»**.

Перевірка охоплює:
- усі записи водіїв вибраного місяця;
- усі активні маршрути.

Шукаються:
- перекриття робочих частин;
- перекриття інтервалів керування;
- неповні пари часу «від–до»;
- керування, яке виходить за межі відповідного робочого інтервалу;
- некоректні часові значення.

Результат показується окремим списком із водієм/датою або маршрутом, типом проблеми, тривалістю та деталями. Запис можна відкрити безпосередньо зі списку.

Аудит **не виправляє дані автоматично**. Це свідомо: старі графіки залишаються історично незмінними, поки користувач не підтвердить конкретне виправлення.

## Захист нового введення

Залишається захист r9.1:
- новий день із перекриттям не зберігається;
- маршрут із перекриттям не зберігається;
- конфліктний день не копіюється на інші дати;
- шляхівка не видається, поки є перекриття робочих частин.

Stable baseline — Taxo 9.0.1. r9.2 не зливається в main до експлуатаційної перевірки.
