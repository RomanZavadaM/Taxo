# Taxo 10.4-r2 — UI cleanup, vehicle documents and waybill readability

**Дата:** 26.09.2026  
**Тип:** full multi-platform candidate checkpoint  
**Stable baseline:** Taxo 10.3 (`v10.3`)

## Що змінено

### Інтерфейс

Ревізія реалізує пріоритетні пункти аудиту `AUDIT_UI_10_4_R1.md` без зміни розрахункової бізнес-логіки:

- виправлено перекриття кнопки «Зберегти» у формі точки маршруту;
- document viewer і вікна документів ТЗ підганяються під доступний розмір екрана;
- toolbar переглядача документа розкладено на адаптивні рядки;
- додано горизонтальні scrollbars у широких реєстрах документів і планувальниках персоналу;
- сторінка «Працівники → Звіти» стала прокручуваною;
- панель дій реєстру працівників більше не конкурує за один рядок із пошуком;
- для вузьких/невисоких екранів головний shell переходить у compact mode: менший header/sidebar і без декоративного road block;
- нижній status bar більше не має жорсткої висоти;
- Treeview row height залежить від системного шрифту;
- додано X11 mouse-wheel підтримку для scrollable вкладок Linux;
- критичні action-glyphs замінено текстовими підписами для сумісності з Windows 7;
- покращено контраст muted/warning/accent кольорів;
- назви «Працівники / Персонал / Водії» у навігації зведено до зрозумілішого entry point «Працівники».

### Документи транспортних засобів

- додано тип **«ДЦВ страхування»** — договір додаткової відповідальності;
- ДЦВ є **необов'язковим** документом: його відсутність не блокує й не попереджає під час формування шляхівки;
- новий документ більше **не архівує автоматично** інші активні документи того самого типу;
- у формі документа є явний прапорець **«Вивести інші активні документи цього типу в архів»**;
- кілька активних документів одного типу можуть співіснувати — це важливо, зокрема, для кількох тимчасових талонів;
- «Примітка» стала багаторядковою;
- при контрольному зведенні, якщо активних документів одного типу кілька, Taxo вибирає найкращий чинний запис без прихованого архівування інших.

### Шляховий лист

- дані, які Taxo підставляє при виписці, друкуються приблизно на **20% більшим шрифтом**;
- статичні назви полів форми не збільшуються, щоб не ламати A4-макет;
- у штатному верхньому лівому полі формується **кутовий штамп підприємства**;
- штамп використовує лише реальні реквізити з налаштувань: назву, адресу, телефон, факс та e-mail; відсутні реквізити не вигадуються;
- двосторінковий A4-макет перевірено тестовим рендером після зміни шрифтів.
