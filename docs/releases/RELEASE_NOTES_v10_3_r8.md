# Taxo 10.3-r8 — macOS sidebar contrast

## Причина

Ручне тестування на macOS показало, що ліве меню Taxo слабко читається: білі підписи та іконки можуть опинятися на світлій системній поверхні кнопки.

Це специфіка Aqua/Tk: native `tk.Button` на macOS може малювати власний фон і не гарантує використання заданого Taxo `background`.

## Виправлення

На macOS:
- navigation sidebar більше не використовує native `tk.Button`;
- використовується clickable `tk.Label`, який точно зберігає фірмовий синій фон і білий текст;
- звичайний стан — `sidebar` blue;
- активний пункт — темний `navy`;
- hover / keyboard focus — `blue_dark`;
- підтримані click, Enter і Space;
- іконки лишаються білими.

На Windows/Linux існуючий button rendering не змінено.
