# Taxo 10.11-r4 — захист історії контрольних протоколів тахографа

**Дата:** 06.11.2026  
**Статус:** **PRERELEASE / кандидат для користувацького тестування**.  
**Stable:** без змін, `v10.10-r5`.  
**Попередній immutable candidate:** `v10.11-r3`.

## Зміни

- Збережений «Протокол контролю тахокарти» тепер захищає свою вихідну тахокарту від видалення.
- У тахографічній SQLite-БД додано DB-level trigger: навіть прямий `DELETE FROM discs` не може каскадно стерти збережений `control_protocols`.
- Кнопка видалення в UI перед видаленням перевіряє наявність протоколів і пояснює, чому історичний запис захищений.
- Чернеткову тахокарту без збереженого контрольного протоколу, як і раніше, можна видалити; її чернеткові інтервали видаляються каскадно.
- Не перебудовуються таблиці і не переписуються існуючі протоколи; guard додається штатним `init_tacho_db()`.

## Regression

Нові поведінкові тести перевіряють:
- helper не видаляє тахокарту зі збереженим протоколом;
- DB-trigger блокує пряме каскадне видалення;
- snapshot протоколу залишається без змін;
- тахокарта без протоколу видаляється штатно разом із чернетковими інтервалами;
- guard реально встановлюється в існуючу схему при ініціалізації.

## Що не змінюється

- `v10.11-r3` immutable і не переписується.
- Stable `v10.10-r5` не змінюється.
- Dependency/security findings Issue #175, UX Issue #164 та CI optimization PR #142/#152 залишаються окремими напрямками.
- Основний worklog/графік/табель водіїв і персоналу не змінюються.
