# Taxo 10.2-r6

**Candidate / secondary-window UI checkpoint — 21.09.2026**

10.2-r6 продовжує затверджений application shell stable 10.1 і прибирає залишки старого вигляду у великих службових вікнах.

## Оформлено

На спільну брендовану шапку Taxo переведено:
- «Стан документів транспортних засобів»;
- «Резервна копія»;
- «Робоче сховище»;
- «Реєстр усіх працівників»;
- «Місячний табель / баланс»;
- «Аудит графіків»;
- «Місячний графік змінності водіїв»;
- «Випуск на лінію — зміни персоналу»;
- «Шляхівки»;
- «Підсумки та контроль №340»;
- «Контроль бланків»;
- «Історія змін Бланка».

## Візуальна логіка

У всіх цих вікнах:
- використовується затверджений text-free logo;
- назва підприємства береться динамічно з реквізитів;
- показується поточна версія Taxo;
- застосовується однакова палітра і базове оформлення Toplevel.

## Безпека

Цей revision не змінює:
- схему БД;
- розрахунок робочого часу;
- П-5;
- роль водія;
- фактичні дані;
- історичні stable/candidate tags.
