## Мета

Довести імпорт ліцензійного реєстру «Шлях» до тієї ж покомпонентної моделі звірки, яка використовується для державних даних працівників: не лише показувати стан цілого ТЗ, а бачити кожне поле, рішення користувача й історію наступних квартальних звірянь.

## Реалізовано

- окремий `vehicle_reconciliation.py` поверх перевіреного parser/import layer `vehicle_registry.py`;
- для кожного поля зберігаються Taxo value, registry value, стан, джерело, SHA-256 витягу, рядок джерела та часові мітки;
- стани: `Відповідає`, `Можна доповнити`, `Розбіжність`, `Критичний конфлікт`, `Немає у витягу`;
- VIN і державний номер — критичні ідентифікаційні поля;
- рішення: `Прийняти дані реєстру`, `Залишити Taxo`, `Потрібно виправити у реєстрі`, `Відкласти`;
- append-only history рішень;
- `Потрібно виправити у реєстрі` автоматично переходить у `Розбіжність усунена`, коли наступний свіжий витяг уже збігається з Taxo;
- прийняття реєстрового значення може змінити рівно одне вибране поле;
- порожнє/відсутнє поле «Шлях» ніколи не очищає Taxo;
- `Є у Taxo, але немає у витягу` лишається інформаційним станом без видалення або деактивації;
- попередні масові режими `Лише звірити / Доповнити порожні / Оновити непорожні + доповнити` збережені, але для режиму повної заміни показується явне попередження;
- створення відсутньої картки ТЗ після підтвердження збережено;
- UI: ліворуч ТЗ, праворуч поля Taxo ↔ «Шлях» із кольорами та рішеннями; доступна історія конкретного поля;
- окреме вікно `Дані «Шлях»` для вибраного ТЗ показує останній покомпонентний стан;
- локальні документи ТЗ і військово-транспортний облік залишаються окремими контурами.

## Інваріанти

1. Державний реєстр — зовнішній офіційний зріз, а не заміна локальної БД Taxo.
2. Відсутність/порожнє значення у витягу не є командою видалити або очистити локальні дані.
3. Розбіжність ідентифікаційного поля не приймається як звичайна описова різниця.
4. Локальний контроль документів, «Шлях» і військово-транспортний облік не змішуються.
5. Квартальний імпорт створює новий зріз і може закривати раніше зафіксовані розбіжності.
