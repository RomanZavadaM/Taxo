# Taxo 10.12-r1 — повернення постійного входу до вибіркового графіка працівників

**Дата:** 06.11.2026  
**Статус:** candidate / test revision.  
**Stable:** без змін, `v10.10-r5`.

## Проблема

Функція простого місячного графіка з явним вибором працівників залишалась у коді, але кнопка додавалась до `Персонал → Планування` динамічно: модуль шукав іншу кнопку за точним текстом і вставляв дію поруч.

Після подальших перебудов UI це стало ненадійним маршрутом — функція могла фактично зникнути з інтерфейсу, хоча сам модуль і export PDF/Excel не були видалені.

## Виправлення

- `Персонал → Планування` тепер має постійну видиму кнопку **«Простий місячний графік…»**.
- Вона відкриває існуючий екран із мультивибором працівників.
- PDF/Excel для вибраних працівників збережені.
- Старий runtime-injector більше не додає дубль, якщо постійна кнопка вже присутня; він лишається fallback для старих composition.
- Бізнес-логіка графіка, БД, plan/fact і наявні exports не змінюються.

## Regression

Додано `tests/test_v10_12_r1.py`, який перевіряє:
- постійну кнопку у штатному Personnel UI;
- зв'язок із `open_simple_month_schedule_r8`;
- відсутність дублювання legacy injector;
- збереження мультивибору та PDF/Excel exports.
