# Taxo 10.14-r10 — холодний запуск і конфлікт pack/grid

**Дата:** 09.11.2026  
**Тип:** candidate / critical startup regression fix.  
**Stable:** без змін, `v10.14-r4`.

## Реальний дефект

На Windows exact-main START 10.14-r9 падав під час запуску до появи робочого вікна:

`_tkinter.TclError: cannot use geometry manager pack ... which already has slaves managed by grid`

Traceback вказав на `src/taxo/v1048_features.py` — кнопку реєстру «Шлях».

## Першопричина

Старий шар 10.4-r8 знаходив кнопку «Контроль документів», брав її `anchor.master` і додавав туди кнопки «Шлях» через `pack()`.

Пізніший шар 10.6-r6 переводить основні кнопки того самого контейнера на `grid()` для адаптивного компонування.

Tkinter забороняє одночасно `pack` і `grid` в одному parent. У повному реальному App ланцюг шарів доходив до цієї комбінації й падав.

Особливо важливо: старий `test_v10_8_r1.py` знав про цю ситуацію, але перевіряв, що небезпечний код **залишається**. Тобто тест законсервував відомий дефект замість того, щоб його заборонити.

## Виправлено

- для реєстрових/облікових дій ТЗ створена окрема панель **«Реєстри та облік ТЗ»**;
- «Реєстр “Шлях”…» та «Дані “Шлях”» більше не додаються в legacy core-toolbar;
- військово-транспортні дії, які знаходять «Дані “Шлях”», природно додаються в цю саму окрему безпечну панель;
- адаптивний `grid` основних кнопок ТЗ і `pack` реєстрових кнопок тепер мають різні parent-контейнери;
- старий regression переписано: тепер він вимагає, щоб geometry-conflict був **усунений**, а не присутній.

## Новий обов'язковий startup-smoke

`test_v10_14_r10.py` виконує справжній холодний запуск у тестовому ізольованому workspace:

1. `main.init_db()`;
2. `taxo_app.App()` з усім реальним ланцюгом feature layers;
3. `update_idletasks()`;
4. перший `update()`;
5. перевіряє, що App живий;
6. перевіряє окрему vehicle-registry toolbar і кнопки «Шлях».

Цей тест має запускатися в загальному regression suite на Windows, Windows 7 та macOS. Саме такий тест мав зловити r9 до видачі користувачу.

Stable / Latest не пересувається без окремого рішення власника.
