# Taxo 10.22-r2 — Test Portable

## Що змінилось

У спільному каталозі **«Документи»** додано точну навігацію за **працівником** і **транспортним засобом**.

- списки містять лише працівників/ТЗ, які реально пов'язані зі структурованими наказами;
- однакові ПІБ не змішуються: використовується стабільний Taxo ID;
- для звичайних наказів читається історичний frozen snapshot, для наказів про закріплення — фактичні пари;
- вільний текст теми не використовується для автоматичного «вгадування» зв'язку;
- фільтри працюють разом із роком/місяцем, датами, типом, категорією, джерелом, сканами й пошуком до розбиття на сторінки;
- колонка «Працівники / ТЗ» показує, кого або чого стосується наказ, якщо структурований зв'язок є.

Старі документи без структурованих зв'язків не переписуються і залишаються доступними у звичайному каталозі.
