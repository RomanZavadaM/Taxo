# Taxo 10.15-r4 — контроль файлів документів працівників

Кандидат у підготовці; Issue #302.

Контроль перевіряє реальну наявність локального файла документа, а не лише адресу в записі. Відсутній файл показується у списку проблем; строк дії контролюється незалежно. Враховуються переносні та старі адреси й зовнішні посилання. Записи і файли не змінюються під час перевірки.

Автоматичні перевірки та приймання власником ще не підтверджені. Stable v10.14-r4 не змінюється.

Тестовий START-пакет створюється для перевірки виправлення власником.
