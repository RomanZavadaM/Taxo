# Taxo 10.15-r4 — контроль файлів документів працівників

**Тип:** тестовий кандидат. **Стабільний випуск:** 10.14-r4.

## Що виправлено

У контролі документів працівників відсутній локальний файл більше не показується як наявна копія. Якщо файл зник або недоступний, контроль показує проблему; окремо зберігається контроль строку дії. Переносні, старі та зовнішні шляхи враховано; вебпосилання не перевіряються як локальні файли.

Сам запис документа і файл при перевірці не змінюються. Якщо файл повернувся на своє місце, натисніть «Оновити» у вікні контролю.

## Перевірки

Власник повідомив, що протестував кандидат і він, за його оцінкою, працює. Автоматичні перевірки на Windows, у середовищі сумісності Windows 7, macOS Intel і Apple Silicon включають перевірку інтерфейсу та відновлення сховища з відсутнім файлом.

Windows 7 перевірено у середовищі сумісності, а не шляхом ручного запуску на фізичному комп'ютері з Windows 7. Для реальних даних перед оновленням зробіть резервну копію робочого сховища.
