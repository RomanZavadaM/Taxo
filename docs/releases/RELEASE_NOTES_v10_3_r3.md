# Taxo 10.3-r3 — candidate

## Залишкові хвости після очищення старих фрагментів

Реальне тестування показало два пов'язані дефекти:
- після очищення старих шматків могли залишатися дрібні хвости на кшталт 10 хвилин як окреме «ПІДГОТУВАТИ»;
- «УТОЧНИТИ БЛАНК» могло падати, якщо старий суміжний worklog уже був видалений/очищений.

### Виправлено

- Немає правила «ігнорувати до 10/15 хв». Короткий фактичний інтервал не приховується.
- Якщо один missing-фрагмент однозначно прилягає до одного активного бланка в тому самому потрібному періоді, Taxo пропонує нову ревізію цього ж бланка з розширеною межею.
- Якщо фрагмент лежить між двома бланками або суміжність неоднозначна, автоматичного поглинання немає.
- Відсутність старого попереднього/наступного worklog більше не блокує редагування бланка.
- План не переписується. Фактичний worklog коригується тільки коли суміжний запис реально існує.

Stable 10.1 не змінюється.
