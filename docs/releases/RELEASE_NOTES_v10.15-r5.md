# Taxo 10.15-r5 — перший спільний перегляд документів

**Стабільна версія 10.15-r5.** Прийнята власником для основної роботи; подальші 10.16 — лише тестові релізи, без заміни стабільної версії.

У «Експлуатації» є кнопка «Документи…». Каталог показує разом наявні накази та підготовлені документи інструктажів і стажування. Пошук працює за всім доступним переліком, не тільки першою тисячею наказів. Список завантажується у фоновому режимі; окремий фільтр показує підготовлені Word-документи за часом створення; відомий DOCX і пов'язаний наказ можна відкрити; для наказу без установленого зв'язку з файлом показано «Файл не прив'язаний». Відсутній DOCX і помилки джерел показуються окремо.

Читання каталогу не переносить старі документи та не ініціалізує схему бази. Відкриття наказу використовує наявний перегляд наказів. Функції завантаження сканів тут **ще немає**; вона запланована окремо разом із перевіркою збереження й резервування.

Для перевірки використовуйте окреме тестове сховище та зробіть резервну копію перед оновленням.
