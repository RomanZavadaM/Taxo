# Taxo 10.15-r5 — перший спільний перегляд документів

**Тестова версія.** Стабільна: [10.15-r4](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.15-r4).

У «Експлуатації» є кнопка «Документи…». Каталог показує разом наявні накази та підготовлені документи інструктажів і стажування. Пошук працює за всім доступним переліком, не тільки першою тисячею наказів. Список завантажується у фоновому режимі; відомий DOCX і пов'язаний наказ можна відкрити; для наказу без установленого зв'язку з файлом показано «Файл не прив'язаний». Відсутній DOCX і помилки джерел показуються окремо.

Читання каталогу не переносить старі документи та не ініціалізує схему бази. Відкриття наказу використовує наявний перегляд наказів. Функції завантаження сканів тут **ще немає**; вона запланована окремо разом із перевіркою збереження й резервування.

Для перевірки використовуйте окреме тестове сховище та зробіть резервну копію перед оновленням.
