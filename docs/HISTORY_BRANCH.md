# Історія розробки Taxo

Повна історія розробки до переходу на експлуатаційний baseline **Taxo 9.0** збережена в окремій Git-гілці:

[`history/development-v8`](https://github.com/RomanZavadaM/Taxo/tree/history/development-v8)

У цій гілці залишені історичні checkpoint-файли, test reports, publish status, patch-файли та старі source/release-артефакти, які більше не повинні захаращувати основну гілку `main`.

`main` призначена для актуального продукту, експлуатаційної документації, поточного вихідного коду та релізної інфраструктури.
