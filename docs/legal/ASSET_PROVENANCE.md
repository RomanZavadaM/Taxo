# Taxo asset provenance

## Ownership model

Taxo / Driver Worktime is a personal software product of **Roman Zavada (Роман Завада)**. The transport enterprise that currently uses the program is separately owned and does not, merely by using Taxo, become the copyright owner of the Taxo source code.

## Brand artwork

The current Taxo logo embedded in `branding_asset.py` is the user-supplied and user-approved artwork used for the application identity. The enterprise name is not baked into the artwork; the program renders the configured enterprise name dynamically.

Before licensing Taxo to unrelated third parties, retain the original source/provenance evidence for the logo and any separately supplied graphic elements.

## Official/document templates

`Бланк підтвердження.docx` and `attestation_visual_template.pdf` implement an operational form layout used by Taxo. Their legal status and source should be treated separately from the Taxo source code. Taxo-specific filling logic, program code, and generated-file workflow remain part of the Taxo software product.

## Rule for future assets

For every new logo, icon set, font, template, photograph, scan, or other non-code asset added to the repository, record at minimum: source, date added, author/rightsholder when known, license/permission, and whether redistribution in commercial Taxo packages is permitted.
