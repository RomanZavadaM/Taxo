# Інструкція для персоналу з роботи в Taxo 9.0

Ця інструкція призначена для працівників, які щодня вносять або перевіряють дані в системі.

## Обов'язкові правила

1. Працюйте тільки у своїй актуальній копії Taxo 9.0 або новішій сумісній версії.
2. Перед внесенням даних перевіряйте дату, водія, автомобіль і маршрут.
3. Не запускайте дві копії Taxo одночасно на одному спільному робочому сховищі.
4. Не переносіть і не перейменовуйте вручну файли бази даних, скани та архіви документів.
5. Не виправляйте невідомий час у 60-денному реєстрі на «відпочинок» без підтвердження.
6. Автоматично розпізнані тахографічні інтервали перевіряйте по зображенню перед підтвердженням.
7. При повторному друці шляхівки відкривайте існуючий документ — не створюйте новий номер замість нього.
8. Якщо програма показує попередження про пробіг, час або конфлікт даних, спочатку перевірте первинні дані.
9. Після завершення роботи закривайте Taxo штатно.
10. У хмарному сховищі після закриття програми дочекайтесь повної синхронізації перед роботою на іншому комп'ютері.

## Щоденний порядок роботи диспетчера / оператора

- перевірити дату;
- перевірити актуальний склад водіїв та персоналу;
- відкрити графік і внести/уточнити робочі зміни;
- перевірити маршрут і автомобіль;
- сформувати необхідні шляхові листи;
- внести фактичні показники, якщо вони вже відомі;
- перевірити табель та відхилення;
- опрацювати наявні тахографічні дані;
- за потреби сформувати контрольний протокол або 60-денний реєстр.

## Що не робити

- не видаляти базу даних, щоб «почати заново»;
- не копіювати стару базу поверх новішої без процедури відновлення;
- не змінювати офіційні номери документів поза штатними функціями;
- не відкривати один і той самий файл бази в сторонніх SQLite-редакторах під час роботи Taxo;
- не вважати автоматичне розпізнавання тахокарти безумовним фактом;
- не ігнорувати `Невизначено` у 60-денному реєстрі, якщо звіт готується для контролю.

## Якщо щось не сходиться

Зупиніть подальше редагування саме цього запису, зробіть скриншот, запишіть водія, дату і дію, яка призвела до проблеми. Не намагайтесь «вирівняти» дані випадковими змінами. Передайте інформацію відповідальній особі для перевірки.

## Відповідальність за дані

Taxo виконує розрахунки на підставі внесених та підтверджених даних. Працівник, який вносить первинну інформацію, відповідає за її відповідність фактичним документам і подіям.
