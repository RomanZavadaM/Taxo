# Taxo / Driver Worktime

[Українська](../../README.md) · [English](README.en.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Taxo는 운송업체를 위한 데스크톱 프로그램으로 직원과 차량, 운전자 일정과 근무 시간, 업무 문서와 보고서를 관리합니다.

## 주요 기능

- 직원과 운전자: 기록, 역할 이력, 문서, 유효기간 및 누락된 로컬 첨부 파일 확인.
- 일정과 근무 시간: 노선, 교대, 근태표 및 계획 시간과 실제 시간의 분리.
- 운전자 관리: 운전·근무·휴식 및 휴게 시간, 개인 보고서와 60일 활동 기록.
- 차량과 정비: 차량 정보, 주행거리, 문서, 유지보수와 수리.
- 운행 업무: 운행일지, 명령서, 운전자와 차량 배정, 활동 확인서 및 문서 출력.
- 교육과 실습: 수정 가능한 Word 교육자료, 서명 목록, 실습 양식과 기본 문서 목록.
- 아날로그 타코그래프 차트: 스캔, 보기 및 수동 검토가 필요한 보조 인식.
- 보고서와 백업: PDF/Excel 보고서와 작업 저장소 백업.
