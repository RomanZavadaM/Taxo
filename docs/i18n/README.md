# Taxo — multilingual overview

Українська версія є канонічною та знаходиться у корені репозиторію: [README.md](../../README.md).

## Актуальний стан

- **Стабільна / остання версія:** [Taxo 10.18-r3](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.18-r3) — 12.11.2026.
- **Попередня стабільна / rollback:** [Taxo 10.17-r10](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.17-r10).
- **Наступна кодова ревізія:** 10.18-r4.
- У Stable 10.18-r3 додано сортування таблиць військового обліку та СТОІР, відновлення вибору після оновлення, безпечні дії і повторне відкриття вікон. Ручне приймання власником — 25/25 PASS; спеціальні DPI-тести ще відкриті.
- Бібліотеку шаблонів і сховище документів у цьому циклі не реалізовували.
