# Taxo — multilingual overview

Українська версія є канонічною та знаходиться у корені репозиторію: [README.md](../../README.md).

## Актуальний стан

- **Стабільна / остання версія:** [Taxo 10.14-r4](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.14-r4) — 09.11.2026.
- **Попередня стабільна / повернення:** [Taxo 10.12-r10](https://github.com/RomanZavadaM/Taxo/releases/tag/v10.12-r10).
- **Наступна кодова ревізія:** 10.14-r5.
- У 10.14-r4 накази мають узгоджені DOCX/PDF/JPG, масовий вибір водіїв і ТЗ, окремі номери, редагування й видалення незалежно від статусу/підпису.
- Офіційний контроль наказів відбувається за паперовими примірниками; Taxo — допоміжне робоче середовище.
