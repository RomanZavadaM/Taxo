## 10.12-r10 からの変更点

運行・整備画面の改善、複数ドライバー・車両の割当、人事・業務命令の別々の採番、書類プレビュー、編集可能な Word と PDF/JPG、統一された表とレイアウト。

Taxo の命令書は業務支援文書です。状態や紙の署名マークによって編集・削除は制限されません。正式な紙の原本は利用者が管理します。

業務データベース、スキャン、個人書類、キャッシュは配布物に含まれません。更新前にバックアップしてください。
