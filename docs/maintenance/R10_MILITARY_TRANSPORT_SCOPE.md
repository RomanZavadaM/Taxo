# Taxo 10.4-r10 — військово-транспортний облік ТЗ

Робочий scope-файл. Не є release note і не змінює stable `v10.3`.

## Межі

- окрема модель військово-транспортного обліку ТЗ;
- не змішувати з реєстром «Шлях»;
- не змішувати з локальним контролем страхування, діагностики, реєстраційних і тахографічних документів;
- одна робоча картка ТЗ лишається джерелом ідентичності: зв'язок тільки через `vehicle_id`; VIN/держномер — реквізити для звірки, не нова картка;
- зберігати історію підстав, статусів, документів, звірянь/подій без руйнування попередніх записів;
- відсутність первинної підстави не трактувати автоматично як порушення;
- історичні записи до запуску r10 не створювати як прострочені задачі без фактичної підстави;
- реальні службові/персональні дані у GitHub не публікувати;
- після завершення видати окремий `Taxo_v10_4_candidate_r10_START`;
- після виданого r10 наступний кодовий крок — `10.5-r1`.

## Перед реалізацією

Перевірити чинну на 2026 рік нормативну модель військово-транспортного обов'язку та не кодувати строки/форми за старою пам'яттю. Юридично чутливі строки повинні мати явне джерело або залишатися інформаційними/ручними, якщо достатньої підстави немає.
