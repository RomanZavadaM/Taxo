# Перевірка фільтра сканів — Taxo 10.21-r1

Дата: 17.11.2026. Issue #289, product PR #490.

## Межа зміни

Один read-only крок у загальному каталозі «Документи»: фільтр за станом сканів. Він не додає, не прибирає й не замінює вкладення, не змінює статус документа та не торкається резервної копії.

## Перевірена поведінка

- «Усі» зберігає попередню поведінку каталогу.
- «Є скани» показує записи DocumentVault з одним або більше активними сканами.
- «Немає сканів» показує записи DocumentVault з нульовою кількістю активних сканів.
- «Помилка перевірки» окремо показує записи DocumentVault, для яких кількість сканів безпечно визначити не вдалося.
- Word-only та інші записи без `vault_id` не потрапляють у вузькі режими.
- Фільтр поєднується з текстовим пошуком і джерелом.
- Відбір виконується до пагінації, тому сторінки формуються вже з відфільтрованого списку.
- Невідомий внутрішній режим безпечно повертається до «Усі».

## Реалізація

Змінено лише логіку каталогу `src/taxo/document_catalog.py`, UI `src/taxo/document_catalog_ui.py`, версію й тести/документацію. Додано regression-тести для всіх режимів, комбінацій, порядку «фільтр → сторінки», виключення non-vault записів та UI-підключення.

КЕП/e-signature, auto «підписано», physical purge, migration, нові залежності, формати зберігання та бізнес-статуси не додавались.
