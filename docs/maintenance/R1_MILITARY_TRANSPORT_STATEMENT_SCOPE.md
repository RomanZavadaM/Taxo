# Taxo 10.5-r1 — scope: відомість власного транспорту

**Branch:** `work/v10.5-r1-military-transport-statement`  
**Base:** `5c964a2278d59f40542cb5b4679b95cc56b809fb`  
**Legal marker:** Положення про військово-транспортний обов'язок №1921, чинна редакція 25.12.2025.

## Призначення

Окремий офіційний звіт військово-транспортного обліку для власного/балансового парку підприємства.

Відомість не є:
- списком нарядів;
- звітом «Шлях»;
- звітом про страховки/реєстраційні документи;
- списком лише `active` ТЗ;
- списком лише ТЗ зі статусом `designated/ordered`.

## Правило включення

Кожна картка ТЗ має окреме рішення для відомості:
- `unknown` — потрібно визначити;
- `own` — власний / балансовий парк, включати;
- `excluded` — не включати до цієї відомості.

Taxo не вгадує це рішення з інших контурів.

## Джерела полів

- ТЗ: локальна картка `vehicles`;
- тип/технічний стан/залишкова балансова вартість: локальні реквізити відомості;
- працівник: тільки явний link `vehicle_military_transport_workers`;
- ПІБ/рік народження/адреса: картка працівника;
- ВОС/військове звання: `employee_military_profile`;
- підприємство/підписант: `company`.
