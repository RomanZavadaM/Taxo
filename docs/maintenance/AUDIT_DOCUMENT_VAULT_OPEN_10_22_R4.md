# 10.22-r4 — безпечне відкриття документа зі сховища

- До r4 кнопка «Відкрити вибране» для запису DocumentVault лише показувала пояснення й не відкривала сам документ.
- Тепер каталог завантажує документ через перевірений API DocumentVault: індекс, розмір і SHA-256 мають збігатися.
- Незмінний об'єкт сховища не відкривається напряму. Для перегляду створюється окрема тимчасова DOCX-копія з вимкненим записом.
- Пошкоджений або підмінений об'єкт не матеріалізується для перегляду.
- Зміни не зачіпають БД, формат DocumentVault, скани, backup/restore, бізнес-статуси чи механізм підпису.
