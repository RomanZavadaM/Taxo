# Аудит персоналу, балансу та П-5 — Taxo 10.9-r6

**Дата:** 01.10.2026  
**База:** immutable `v10.9-r5` / `bb2f4424d12cab1fa479950a0743910b909e9fc6`  
**Ревізія:** `10.9-r6`

## Підтверджені проблеми

1. `NONWORK_OVERRIDE_TYPES` містив `Вихідний` і `Відпочинок`, а `_employee_absence_adjustment_minutes()` використовував цей самий набір для зменшення норми. Через це плановий вихідний міг поводитися як відпустка/лікарняний при розрахунку скоригованої норми.
2. Legacy overlay місячного балансу спочатку зводив зв'язки до `{driver_id: employee_id}`. Така форма втрачає історичну відмінність записів при legacy/відновлених даних і не повинна бути джерелом історичного вибору працівника.
3. Індивідуальні цикли 2/2 та довільний цикл уже підтримуються `pattern_dates()`, але r6 додає явні поведінкові тести для 2/2 і 3/3.

## Виправлення

- додано additive runtime layer `v1096_personnel_balance.py` без зміни схеми БД;
- `Вихідний`/`Відпочинок` залишаються не-робочими override-позначками, але не зменшують норму як законна неявка;
- monthly balance overlay отримує базовий баланс без старих overlay і накладає неявки один раз через date-aware join `employee_time_entries -> employees`;
- при виборі історичної неявки враховуються `employment_date`/`dismissal_date`, а не поточний `active`;
- збережено старі видані модулі, нова поведінка підключена окремим feature layer;
- `START.bat` перевіряє наявність нового runtime-модуля.

## Поведінкові сценарії r6

- `Вихідний` не зменшує норму;
- `Відпочинок` не зменшує норму;
- щорічна відпустка та оплачувана непрацездатність зменшують норму за наявним правилом;
- історична неявка працівника лишається доступною незалежно від сьогоднішнього `active`;
- legacy-сценарій з двома employment rows одного логічного водія не губить неявки різних періодів;
- 2/2 лишається прив'язаним до дати початку циклу;
- довільний 3/3 формує три робочі / три вихідні дні повторювано.

## Межі зміни

- фактичні години не підміняються планом;
- схема БД не змінюється;
- `main` не змінюється;
- `v10.9-r5` не рухається і не перевидається;
- merge r6 у `main` — лише за окремою командою власника.
