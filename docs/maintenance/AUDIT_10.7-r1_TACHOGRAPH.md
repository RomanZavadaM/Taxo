# Audit 10.7-r1 — тахографія

**Старт:** 29.09.2026  
**Base:** `main` після повного checkpoint `v10.6-r10`.

Незалежні зауваження використані тільки як покажчик місць для перевірки. Нижче записані лише дефекти, які підтверджені безпосередньо в актуальному коді Taxo.

## Підтверджено

1. `import_scan()` після імпорту викликає `recognize_all()` і повторно обробляє всі шайби, а не лише щойно імпортовані.
2. `recognize_all()` та `recognize_selected()` виконують повне `DELETE FROM intervals WHERE disc_id=?`, тому ручні інтервали (`source='manual'`) можуть бути втрачені при повторному автоматичному розпізнаванні.
3. `select()` має неявне автодобудовування кандидатів для порожнього запису, тобто простий вибір запису може змінити дані без окремої команди користувача.
4. `_import_one()` має недосяжне попередження «не вдалося автоматично знайти коло»: порожній `circles` замінюється на `[(0,0,0)]` до перевірки.
5. `_polar_signal()` некоректно закриває темний run, який переходить через межу 00:00; хвіст такого інтервалу може губитися.
6. `draw_timeline()` застосовує `% 1440` до кінця інтервалу до визначення переходу через 00:00, через що wrap-around інтервал малюється неправильно.

## Межі 10.7-r1

- автоматичне повторне розпізнавання замінює тільки `source='auto'`, ручні інтервали зберігаються;
- після імпорту автоматично обробляються тільки нові записи;
- вибір запису більше не запускає приховане розпізнавання;
- відновлюється реальне попередження про невиявлене коло;
- виправляється circular run через 00:00;
- шкала дня правильно малює інтервали через 00:00;
- додаються regression-тести на ці інваріанти.

Інші зауваження (оцінка максимальної швидкості, семантика автокандидатів, 60-денний реєстр, режими роботи, тижневі межі, шляхівка) не змішуються з цим slice і перевірятимуться окремо.
