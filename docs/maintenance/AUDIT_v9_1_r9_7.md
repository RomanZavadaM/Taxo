# AUDIT — Taxo 9.1 candidate r9.7

**Дата:** 19.09.2026  
**Stable:** Taxo 9.0.1  
**Previous candidate:** r9.6  
**Причина:** у місячному графіку змінності відсутня дія прямого відкриття PDF деталізації.

## Ручне підтвердження

На скріншоті r9.6 видно кнопки:
- Excel — редагувати;
- PDF — графік;
- PDF — деталізація;
- Відкрити графік PDF.

Кнопки **«Відкрити деталізацію»** немає.

## Fix

- додано `open_monthly_shift_detail_pdf()`;
- додано кнопку `Відкрити деталізацію`;
- кнопка завжди формує актуальний PDF для поточного періоду й одразу відкриває його;
- повторно використано `export_monthly_shift_detail_pdf`, без дублювання розрахунків;
- додано окремий default path для detail PDF;
- текст підказки у вікні актуалізовано;
- кнопки графіка та деталізації згруповано логічними парами.

## Automated gate

Новий regression test:
- source-level UI binding;
- behavioral test нового action через mocked writer/export/open_external.

Повний CI має залишатися зеленим на Windows і macOS. START full/incomplete preflight r9.6 не повинен регресувати.

## Manual gate

Після публікації r9.7:
1. завантажити новий START ZIP;
2. повністю розпакувати;
3. запустити Taxo;
4. відкрити місячний графік;
5. натиснути «Відкрити деталізацію»;
6. підтвердити відкриття PDF без Save As;
7. продовжити решту operational gate.
