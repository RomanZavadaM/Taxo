# Release checklist

Актуальний чекліст для супроводу Taxo 9.x.

1. Зміни виконувати в окремій гілці через Pull Request.
2. Не включати БД, скани тахокарт або персональні документи до Git/релізу.
3. Перед змінами даних перевірити резервну копію.
4. Виконати compile/test/regression checks.
5. Перевірити запуск через START для кандидатних змін.
6. Виконавчі пакети публікувати на обраних стабільних контрольних точках.
7. Для stable release перевірити Windows x64, macOS ARM64 та macOS Intel, SHA-256 і release notes.
8. Після релізу оновити документацію експлуатації лише там, де поведінка реально змінилася.
