# Taxo 10.7-r8 — структура наказів з експлуатації

## Мета
Прибрати плоский список і не втратити накази, які стосуються реальної експлуатації АТП.

## Групи
1. **Водії та організація роботи** — закріплення ТЗ, робочий час, місця відпочинку, підготовка/стажування.
2. **Транспорт і технічна експлуатація** — зберігання ТЗ, технічний контроль, ТО/ремонти/техогляди.
3. **Безпека та розслідування** — БДР, навчання/перевірка знань, ДТП/комісії, охорона праці, пожежна безпека.
4. **Інші накази** — універсальний тип без нав'язаної нормативної підстави.

Класифікація використовується для навігації та пошуку, а не як твердження про юридичну обов'язковість конкретного наказу.
