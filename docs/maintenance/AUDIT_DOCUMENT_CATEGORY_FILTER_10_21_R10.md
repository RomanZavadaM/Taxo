# Аудит категорій каталогу «Документи» — 10.21-r10

Дата: 18.11.2026.

## Мета

Додати зрозумілий зріз каталогу за категоріями без вгадування по вільному тексту і без зміни самих документів.

## Джерело категорії

Для наказів використовуються тільки вже наявні структуровані поля:
- `order_series=personnel` → **Кадрові**;
- `road_safety`, `accident_commission` → **БДР**;
- `occupational_safety`, `safety_training` → **Охорона праці**;
- `fire_safety` → **Пожежна безпека**;
- решта робочих наказів → **Експлуатаційні**.

Якщо старий Word/DocumentVault запис не має структурованого напряму, він отримує **«Не визначено»**. Назва, тема або довільний текст не використовуються для автоматичної класифікації.

## Перевіряється

- категорія визначається перед pagination;
- фільтр комбінується з джерелом, сканами, періодом, типом та текстовим пошуком;
- «Не визначено» не приховує старі записи;
- кадрова серія має пріоритет над типом наказу;
- БДР/ОП/пожежна безпека не виводяться з ключових слів теми;
- таблиця показує категорію окремою колонкою;
- старі сценарії каталогу лишаються read-only.

## Не входить

Навігація за конкретним працівником або ТЗ, міграція старих документів, ручне редагування категорії, OCR, КЕП, зміна статусів чи схеми сховища.
