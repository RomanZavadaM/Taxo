# Taxo 9.0.1 — поточна експлуатаційна контрольна точка

**Stable:** Taxo 9.0.1 · 17.09.2026.

Taxo 9.0 лишається базовою архітектурною версією. 9.0.1 — перше локальне експлуатаційне виправлення без зміни схеми БД та без міграції даних.

Підтверджені зміни 9.0.1:
- актуальний номер версії у заголовку головного вікна;
- актуальне вікно «Про програму»;
- чистий START-пакет без історичних службових файлів v8.x;
- окрема release-лінія 9.0.1 для Windows/macOS/START.

Повний зафіксований стан до очищення `main` збережений у гілці [`history/development-v8`](https://github.com/RomanZavadaM/Taxo/tree/history/development-v8).

Поточна політика: реальна експлуатація, наповнення бази даними, накопичення тахографічних сценаріїв і точкові виправлення відтворюваних дефектів. Не змінювати схему даних або базову архітектуру без окремої підтвердженої потреби з експлуатації.

Відоме питання: `bad window path name` очікує точного traceback із `Taxo_errors.log` перед виправленням.
