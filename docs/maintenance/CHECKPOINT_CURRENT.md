# Taxo 9.0 — поточна експлуатаційна контрольна точка

**Stable:** Taxo 9.0 · 17.09.2026.

Цей файл є короткою актуальною контрольною точкою після очищення `main` від історичних артефактів версій 8.x.

Повний зафіксований стан до очищення збережений у гілці [`history/development-v8`](https://github.com/RomanZavadaM/Taxo/tree/history/development-v8). Поточна політика: реальна експлуатація, наповнення бази даними, накопичення тахографічних сценаріїв і точкові виправлення відтворюваних дефектів.

Не змінювати схему даних або базову архітектуру без окремої підтвердженої потреби з експлуатації. Перед змінами, що торкаються збережених даних, обов’язкові резервна копія і регресійні тести.
