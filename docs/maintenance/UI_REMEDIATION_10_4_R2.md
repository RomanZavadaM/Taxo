## Додатково знайдено під час cleanup

Документація містила кілька застарілих формулювань, які вже суперечили чинним правилам:

- старе твердження, що новий документ ТЗ автоматично архівує попередній;
- старе розділення «Персонал» та «Водії» як двох рівноправних реєстрів;
- застарілий quick start із назвами пакетів Taxo 10.0;
- старий опис бланка, де план міг трактуватися як факт автоматично.

У 10.4-r2 ці тексти синхронізовано з `PROJECT_RULES.md`: **plan != fact**, бланк є фактичним документом, а архівування документів ТЗ — явна дія користувача.

## Не змінювалося

- схема робочої БД не мігрується;
- історичні записи не видаляються;
- правила розрахунку робочого часу/керування не переробляються в цьому UI slice;
- stable `v10.3` не пересувається.
