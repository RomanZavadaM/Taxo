# 10.22-r3 — контроль кнопки «Скинути фільтри»

- Виявлена незручність: для повернення всіх документів доводилося очищати кілька незалежних фільтрів вручну.
- Додано одну кнопку, яка повертає повний каталог за замовчуванням (новіші документи першими).
- Скидання не перезапитує дані без потреби та скасовує запланований відкладений пошук.
- Зміни лише в інтерфейсі каталогу; зберігання файлів, сховище, скани, база та відновлення не зачіпаються.
- Перевірки: повне скидання, повторне скидання, одноразова зміна стану кожного поля, наявність кнопки та прив'язки.
