# Taxo — спрощення інтерфейсу та назв файлів

Дата: 05.11.2026. Підстава: користувацький огляд Taxo 10.10-r10 (п'ять скриншотів).
Цей документ — робочий план збереження всіх функцій без переведення користувача між численними несумісними вікнами.

## Проблема для людини

- Немає явного розрізнення: план водія, табель (план/факт), місячний графік змінності, баланс часу, простий графік персоналу.
- У робочих вікнах одночасно присутні кілька кнопок для споріднених форматів.
- Назви експортованих файлів не містять складу звіту; різні вибірки можуть зберігатися під одним ім'ям.
- Є технічні позначення («3ч»), які не пояснюють, що число — кількість частин, а не години.

## UX Core

1. Звичайний користувач бачить єдиний послідовний потік: **кого → коли → що подивитися → що зробити**.
2. Першочерговий екран не показує два взаємозамінні експорти чи довгі довідкові абзаци. Допомога/деталі — за запитом.
3. Підписи дій: **«Переглянути»** (відкриває актуальну версію), **«Зберегти…»** (вибирає файл), **«Надрукувати»** (лише коли потрібний прямий друк).
4. План, факт, відсутність і порушення — чітко розділені; жодна зміна вигляду не змінює облікові дані.
5. Один набір вибраних водіїв для перегляду/експорту всередині конкретного вікна; у загальному внутрішньому перегляді не показувати службових проблем інших людей.
6. Для всіх нових назв: **тип документа + рік-місяць + коло осіб + формат**. Не використовувати нечитабельні технічні префікси.
7. Немає автоматичного перезапису попередніх фінальних документів: явно відрізняти «тимчасовий перегляд» від «Зберегти…».
8. Основний водійський worklog — джерело правди для графіка водія, не створювати дубль у employee_shifts.

## Поточна реалізація 10.11-r1 (вибірковий перший етап)

- Вікно **«Місячний графік змінності водіїв»**: замість п'яти кнопок — вибір одного з трьох документів, «Переглянути», «Зберегти…».
- Скорочена інструкція в один рядок, зрозуміле позначення «част.».
- Файли: `Графік_змінності_2026-11_усі-водії.pdf`,
  `Графік_змінності_2026-11_обрані-5-<код>.pdf`,
  `Деталізація_змін_2026-11_водій-3.pdf`, відповідні .xlsx.
- Суфікс коду для кількох вибраних потрібний, щоб два різні склади однакової кількості не перезаписували один одного.

## Подальша робота без зміни обліку

Аудит входів «Табель обліку», «Графіки», «Працівники», «Звіти», «Маршрути»:
інвентаризувати дублікати кнопок; на стартовій картці показувати опис «для чого», «кому», «які дані»;
зробити єдину процедуру вибору працівників; уніфікувати назви файлів для всіх типів документів;
зберегти старі окремі функції як внутрішні дії, не видаляти модулі.
Окремо перевірити масштаби 100/125/150 %, великі таблиці, клавіатурну навігацію та Windows 7/macOS.

## Приймання

- Людина може відкрити водійський графік, вибрати водіїв і створити один потрібний файл без здогадів.
- PDF/Excel містять тільки обраних водіїв; тип і коло звіту впізнаються з назви.
- Зміна періоду або вибору не відкриває застарілий PDF.
- Жодних змін у фактичному обліку, графіках, маршрутах чи персональних документах.
- CI Windows, Windows 7, macOS Intel/ARM і START; підтвердження на реальному інтерфейсі власником.
