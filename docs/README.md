# Документація Taxo 9.0

Цей каталог містить експлуатаційну документацію стабільної версії **Taxo 9.0**.

## Для кого ця документація

- диспетчер / оператор — щоденне внесення і перевірка даних;
- кадровий або відповідальний працівник — реєстр персоналу і табелі;
- механік / відповідальний за транспорт — автомобілі, пробіг, маршрутні дані;
- адміністратор — робоче сховище, резервні копії, оновлення, відновлення;
- керівник — контрольні звіти, 60-денний реєстр, протоколи та архіви.

7. [Стан розробки](DEVELOPMENT_STATUS.md) — зафіксований baseline v9.0 і правила подальших змін.

## Основний принцип експлуатації

Taxo зберігає робочі дані окремо від самої програми. Оновлення або заміна виконуваного файла не повинні вимагати повторного введення даних. Робоче сховище є ціннішим за інсталяційний пакет, тому його резервне копіювання є обов'язковою частиною експлуатації.
