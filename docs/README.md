# Taxo 9.0 — документація

Цей каталог містить **чинну експлуатаційну документацію** для стабільного релізу **Taxo 9.0**.

> Документи `CHECKPOINT_*`, `PUBLISH_STATUS_*`, `PATCH_*` та старий `PROJECT_STATE.md` у корені репозиторію збережені як історія розробки. Для повсякденної роботи з системою використовуйте документацію з цього каталогу.

## З чого почати

- [Опис системи](SYSTEM_OVERVIEW.md) — призначення, склад і основний функціонал.
- [Керівництво персоналу](USER_GUIDE.md) — щоденна робота оператора/диспетчера/відповідального працівника.
- [Ролі та робочі процеси](ROLES_AND_WORKFLOWS.md) — хто що робить у системі.
- [Експлуатація, дані та резервування](OPERATIONS_GUIDE.md) — робоче сховище, резервні копії, перенесення, оновлення.
- [ТАХО та 60-денний реєстр](TACHOGRAPH_GUIDE.md) — робота з тахокартами, інтервалами й реєстром діяльності.
- [Типові проблеми](TROUBLESHOOTING.md) — що перевіряти до звернення розробнику.
- [Стан розробки](DEVELOPMENT_STATE.md) — зафіксована базова точка v9.0 і правила подальших змін.

## Актуальна версія

**Taxo 9.0** — стабільний реліз від 17.09.2026.

GitHub Release містить Windows x64 Setup/Portable, macOS ARM64/Intel Portable, `START`-архів для перевірки з Python та SHA-256 контрольні суми.

Користувацькі бази даних і персональні дані **не входять** у репозиторій або релізні архіви.

## Принцип документації

Документація описує саме стабільну версію 9.0. Нові експериментальні функції не повинні потрапляти сюди до прийняття у стабільну лінію.
