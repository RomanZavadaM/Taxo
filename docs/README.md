# Документація Taxo 9.0

Цей каталог є основним входом у документацію стабільної версії **Taxo 9.0**.

Taxo 9.0 переведено з активної розробки у режим **експлуатації та накопичення реальних даних**. Подальші зміни виконуються переважно за результатами практичної роботи: виправлення помилок, уточнення розрахунків, покращення зручності та документовані зміни вимог.

## Керівництва з експлуатації

- [Швидкий старт](guides/QUICK_START.md) — встановлення, перший запуск і мінімальне початкове налаштування.
- [Інструкція для персоналу](guides/STAFF_OPERATIONS.md) — щоденна робота диспетчера, табельника/кадровика та відповідального за тахограф.
- [Адміністрування системи](guides/ADMINISTRATION.md) — робоче сховище, резервні копії, оновлення та робота з кількох комп’ютерів.
- [Звіти та контроль](guides/REPORTS_AND_CONTROLS.md) — табелі, баланс робочого часу, контроль №340, 60-денний реєстр діяльності, бланки та шляхові листи.
- [Типові проблеми](guides/TROUBLESHOOTING.md) — що робити, якщо файл зайнятий, сховище заблоковане, PDF не відкривається або дані не збігаються.
