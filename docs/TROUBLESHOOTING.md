# Taxo 9.0 — типові проблеми

## Програма не запускається

Для `START.bat` перевірте:

- встановлений Python 3.13;
- доступ до інтернету для першого встановлення залежностей;
- відсутність помилок у вікні консолі;
- наявність `requirements.txt` і `taxo_app.py` поруч із `START.bat`.

Для Setup/Portable перевірте, чи антивірус або Windows SmartScreen не заблокували файл. Не вимикайте захист без потреби — спочатку звірте файл із SHA-256 релізу.

## Повідомлення про зайняте робоче сховище

Найчастіше інша копія Taxo ще працює.

1. Перевірте інші комп'ютери.
2. Переконайтесь, що попередня копія справді закрита.
3. Для хмари дочекайтесь синхронізації.
4. Лише якщо попередній запуск аварійно завершився, використовуйте штатний механізм відновлення блокування.

Не видаляйте lock-файл вручну без розуміння причини.

## Не видно потрібного водія

Перевірте:

- чи активна роль `Водій`;
- дату прийняття;
- дату завершення ролі;
- вибрану дату графіка/табеля;
- чи відкрито правильне робоче сховище.

## Неправильний час у табелі

Перевірте:

- усі частини зміни;
- окремо робочий час і керування;
- перехід через північ;
- чи не застосовано помилково копіювання дня;
- джерело плану та факту.

## 60-денний реєстр показує `Невизначено`

Це не помилка само по собі. Це означає, що для цього проміжку немає достатньо підтверджених даних.

Перевірте тахокарту, табель, бланк підтвердження та інші первинні дані. Не змінюйте `Невизначено` на `Відпочинок` без підстави.

## PDF не перезаписується

Якщо PDF відкритий у переглядачі, Windows може блокувати перезапис.

Закрийте PDF і натисніть `Повторити`, або використайте штатну опцію створення копії з новою назвою.

## Відкривається старий PDF

Переформуйте документ через відповідну кнопку в Taxo. Для контрольних звітів користуйтеся `Відкрити PDF`, щоб спочатку створити актуальну версію, а потім її відкрити.

## Помилка або дивний результат ТАХО

1. Відкрийте скан у збільшеному режимі.
2. Перевірте дату й водія.
3. Порівняйте проблемний інтервал зі шкалою.
4. Виправте/підтвердіть інтервал вручну.
5. Якщо помилка повторюється — збережіть приклад для розробника.

## Номер шляхівки або пул номерів поводиться неочікувано

Перевірте:

- дату роботи документа;
- активний період пулу;
- серію;
- діапазон і наступний номер;
- чи це первинна видача, повторний друк або анулювання.

Попередній перегляд не повинен витрачати номер.

## Дані зникли після оновлення

Насамперед перевірте, чи нова версія підключена до того самого робочого сховища. Дані не повинні зберігатись усередині каталогу програми.

Не створюйте нові записи, поки не перевірите шлях до сховища — це може ускладнити відновлення.

## Що передати розробнику

Для відтворюваної проблеми достатньо:

- версія Taxo;
- операційна система;
- точні кроки 1–2–3;
- очікуваний результат;
- фактичний результат;
- скриншот;
- за потреби — журнал помилок;
- мінімальний тестовий приклад без зайвих персональних даних.

Не публікуйте у відкритому GitHub реальні БД, скани тахокарт або документи з персональними даними.
