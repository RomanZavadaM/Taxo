# Типові структури експлуатаційних документів

## Наказ

Базовий каркас, підтверджений реальними документами АТП:

1. Найменування підприємства.
2. Вид документа — `НАКАЗ`.
3. Номер.
4. Дата.
5. Місце складання.
6. Заголовок / тема `Про ...`.
7. Підстава / вступ.
8. Формула `НАКАЗУЮ:`.
9. Нумеровані пункти.
10. За потреби — структурована таблиця.
11. Контроль виконання.
12. Посада, підпис, ПІБ керівника.
13. Додатки з посиланням `Додаток N до наказу від ... № ...`.

## Наказ про закріплення ТЗ

Структурна таблиця:
- №;
- марка / модель;
- державний номер;
- водій;
- дата початку дії;
- дата завершення за потреби;
- примітка.

## Тематика / програма як додаток

Типові поля:
- номер теми;
- назва теми;
- відповідальний / викладач;
- за потреби кількість годин;
- підпис відповідального за програму.

## Журнал інструктажів

Модель для подальшого уточнення за джерелами:
- дата/час;
- вид інструктажу;
- тема/підстава;
- працівник;
- інструктуючий;
- пов'язаний наказ/програма;
- результат / допуск;
- підписні реквізити або ознака паперового запису.

## Протокол комісії

Модель для уточнення:
- номер/дата;
- склад комісії;
- підстава;
- питання порядку денного;
- рішення;
- особи, яких стосується рішення;
- додатки;
- підписи.

## Акт / перевірка технічного стану

Модель для уточнення за майбутніми реальними формами:
- ТЗ;
- дата/час;
- пробіг;
- вид перевірки;
- перелік перевірених вузлів/систем;
- виявлені дефекти;
- рішення про допуск;
- відповідальна особа;
- пов'язаний ремонт / повторна перевірка.

## Важливо

Це не перелік обов'язкових сучасних форм. Він описує **патерни реального документообігу**, які мають бути звірені з чинними нормами перед використанням як блокуючих або обов'язкових правил Taxo.
