# База знань Taxo — експлуатація транспорту

Ця гілка зберігає **структуровані знання**, отримані з реальної багаторічної практики АТП, нормативних джерел та перевірених вимог до Taxo.

## Принципи

- Оригінальні скани, персональні дані, підписи, печатки та службові архіви **не публікуються** у відкритому GitHub.
- У GitHub зберігаються лише узагальнені, знеособлені висновки, структури документів, перевірені правила та вимоги до програми.
- Історичний документ не вважається чинною нормою автоматично. Його використовуємо як доказ реальної практики АТП; нормативну чинність перевіряємо окремо.
- Кожна вимога для коду Taxo повинна мати походження: реальний документ / чинна норма / рішення власника продукту.
- Plan != Fact. Паперовий підписаний документ є зовнішнім оригіналом; Taxo веде структуровані дані та історію змін.

## Структура

- `SOURCE_INVENTORY.md` — облік наборів джерел та тем, які вони покривають.
- `DOMAIN_MAP.md` — карта предметної області експлуатації АТП.
- `LEGAL_REGISTER.md` — реєстр нормативних питань, які треба підтверджувати за чинними джерелами.
- `TAXO_REQUIREMENTS.md` — перевірені вимоги до модулів Taxo.
- `DOCUMENT_PATTERNS.md` — типові структури наказів, журналів, актів, інструктажів та інших форм.

## Поточні тематичні блоки

1. Організація експлуатації ТЗ.
2. Закріплення ТЗ за водіями та відповідальними.
3. Безпека руху.
4. Охорона праці та пожежна безпека.
5. Передрейсовий / післярейсовий контроль.
6. ТО, ремонти, технічний стан, ОТК.
7. Стажування, навчання та інструктажі водіїв.
8. Місця зберігання ТЗ та відпочинку водіїв.
9. Комісії, протоколи, плани заходів.
10. Ліцензійні та довідкові матеріали.
