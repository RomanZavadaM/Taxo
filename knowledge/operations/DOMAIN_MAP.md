# Карта предметної області — експлуатація АТП

## 1. Організаційний контур

- накази та розпорядження;
- відповідальні особи та їх періоди повноважень;
- комісії;
- плани заходів;
- протоколи;
- підписані паперові оригінали та скани;
- історія редагувань у Taxo.

## 2. Транспортний засіб

- картка ТЗ;
- технічні документи;
- закріплення за водіями;
- закріплення за відповідальними;
- місце зберігання;
- технічний стан;
- огляди, ТО, ремонти, дефекти;
- допуск / недопуск до виїзду;
- ОТК та інші періодичні контролі.

## 3. Водій

- право керування / категорії;
- стажування;
- наставник;
- інструктажі;
- навчання й перевірка знань;
- допуск до конкретного ТЗ / типу ТЗ;
- режими праці та відпочинку;
- передрейсові / післярейсові процедури;
- фактична історія роботи.

## 4. Безпека руху

- служба / відповідальний з БР;
- план заходів;
- тематичне навчання;
- передрейсовий інструктаж;
- журнали інструктажів;
- аналіз ДТП / порушень;
- комісії та протоколи;
- перевірки водіїв;
- контроль виконання заходів.

## 5. Охорона праці та пожежна безпека

- відповідальні;
- накази;
- програми / тематики;
- інструктажі;
- перевірка знань;
- протоколи / комісії;
- інструкції за професіями та роботами;
- пожежна безпека й дії при аварійних ситуаціях.

## 6. Експлуатаційний цикл рейсу

1. План / випуск.
2. Передрейсові перевірки водія і ТЗ.
3. Допуск до рейсу.
4. Шляховий лист / пов'язані документи.
5. Виконання рейсу.
6. Повернення.
7. Післярейсові процедури.
8. Фіксація дефектів / відхилень.
9. ТО / ремонт / повторний допуск за потреби.

## 7. Документні сутності Taxo

Кожний тип документа повинен мати:

- тип / групу;
- номер;
- дату;
- період дії, якщо застосовно;
- тему;
- підставу;
- текст або структуровані пункти;
- пов'язані ТЗ / працівників / маршрути;
- відповідального за виконання;
- додатки;
- статус паперового оригіналу;
- посилання на скан, якщо він зберігається;
- історію змін;
- ознаку нормативного / внутрішнього / історичного документа.
