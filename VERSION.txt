Version: 10.1-r3
Release date: 2026-09-20
Release type: candidate / UI shell checkpoint
Stable baseline: Taxo 10.0
Stable tag: v10.0
Stable target: 91c0d6365a40eb09fe40f97a2965da40b314bc15
Previous candidates: v10.1-r1, v10.1-r2

Taxo 10.1-r3 — виправлення невідповідності між затвердженим макетом і фактичним інтерфейсом.

Основне:
- старий native Tk menu row прибрано з Windows/Linux; повне меню доступне через кнопку ☰ у шапці;
- старий видимий рядок вкладок Notebook прибрано: Notebook лишається лише внутрішнім контейнером сторінок;
- додано повноцінну ліву синю навігацію з іконками;
- додано світлу верхню шапку з логотипом, dynamic enterprise name, слоганом, датою/часом, користувачем і Налаштуваннями;
- додано нижній operational status bar: база, користувач, робоче місце, підприємство, версія;
- у sidebar додано декоративний дорожній мотив «Дороги об’єднують!»;
- вікно «Табель робочого часу всіх працівників» переведено на той самий application-shell із лівою навігацією та status bar;
- збережено прямі дії табеля: деталізація, PDF, Excel, контроль, місячний баланс, П-5;
- логотип залишається без фіксованої назви; назва підприємства рендериться окремо з поля «Назва підприємства»;
- збережено driver-role fix 10.1-r1 та функціональні зміни 10.1-r2.

Статус:
- candidate / UI shell checkpoint, не stable;
- stable v10.0, v10.1-r1 та v10.1-r2 не змінюються;
- перед злиттям у main потрібні regression gate і ручна Windows-перевірка.
