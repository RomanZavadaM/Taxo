Taxo 10.5-r8 — сумісність Windows 7 / Python 3.8 з XLSX реєстру «Шлях».

Основне:
- r7 залишається виданою immutable ревізією; її код і тег не переписуються;
- повний checkpoint r7 виявив відмінність тексту TypeError у Python 3.8/openpyxl для атрибута tabId;
- r8 розпізнає обидва фактичні варіанти помилки «unexpected keyword argument tabId» і виконує той самий безпечний in-memory retry;
- вихідний XLSX користувача не змінюється;
- сторонні TypeError не маскуються;
- бізнес-логіка r7 не змінюється.

Нумерація:
- 10.5-r1..r7 вже видані та immutable;
- поточний кодовий крок — 10.5-r8;
- після видачі 10.5-r8 наступний кодовий крок — 10.5-r9.
