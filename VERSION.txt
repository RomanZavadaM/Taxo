Taxo / Driver Worktime
Version: 9.1 candidate r2
Candidate date: 2026-09-18
Release type: functional candidate
Baseline: Taxo 9.0.1

Taxo 9.1 candidate r2 — виправлення місячного планування після експлуатаційної перевірки r1.

Зміни r2:
- усунено падіння UNIQUE constraint у масовому плануванні лікаря/механіка;
- попередній перегляд тепер враховує реальний ключ БД: працівник + роль + дата + № зміни, незалежно від місця;
- існуючий фактичний запис ніколи не перезаписується;
- без прапорця заміни існуючий план цього працівника пропускається;
- з прапорцем заміни можна замінити лише план цього самого працівника; план іншого працівника в цільовій зміні не видаляється;
- запис кожного дня захищено SAVEPOINT: навіть при неочікуваному конфлікті пакет не падає і не втрачає попередній план;
- збережено зміни r1: місячний огляд, шаблони графіків та покращене оформлення шляхового листа;
- збережено виправлення bad window path name для табеля персоналу.

Схема БД не змінюється. Робочі бази, скани та персональні дані до пакета не включаються.
