Taxo / Driver Worktime
Version: 9.0.1
Release date: 2026-09-17
Release type: stable hotfix
Baseline: Taxo 9.0

Taxo 9.0.1 — експлуатаційне виправлення стабільної гілки 9.0.

Зміни 9.0.1:
- виправлено назву головного вікна: більше не показується застаріле «v8.70 r9»;
- виправлено вікно «Про програму»: воно показує актуальну версію Taxo 9.0.1;
- START-архів формується з очищеної експлуатаційної гілки main без старих checkpoint/test/publish-файлів версій 8.x;
- функціонал Taxo 9.0, структура робочої БД та робоче сховище не змінюються.

Окремо продовжується діагностика експлуатаційної помилки Tkinter «bad window path name» за журналом Taxo_errors.log.

Пакети 9.0.1: START source ZIP, Windows x64 Portable, Windows x64 Setup, macOS arm64 Portable та macOS x86_64 Portable. Робочі бази та персональні дані до релізів не включаються.
