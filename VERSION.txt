Route model from v8.66 r10 remains: one route = one exact time scenario.
Tachograph recognition algorithm is unchanged.

Distribution: r9 is an executable checkpoint. GitHub Actions builds Windows Setup/Portable, native macOS arm64/x86_64 packages, a source ZIP and shared SHA-256 checksums. No user database is bundled.
