Route model from v8.66 r10 remains: one route = one exact time scenario.
Tachograph recognition algorithm is unchanged.

Distribution: START.bat for routine candidates. GitHub Actions compiles/tests source on every change and builds Windows/macOS executables only when manually requested at an executable checkpoint. No user database is bundled.
