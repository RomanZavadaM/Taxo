Taxo / Driver Worktime
Version: 9.0
Release date: 2026-09-17
Release type: stable
Baseline: v8.70 candidate r11

Taxo 9.0 establishes a new stable baseline for the next development stage.

Included in 9.0:
- standalone 60-calendar-day driver activity register with minute-by-minute coverage;
- daily 24:00 control with driving, other work, availability, breaks, rest, absence and undefined time;
- exact source/confidence labelling for tachograph, worklog, confirmation forms and calculated intervals;
- missing information stays «Невизначено» instead of being silently converted to rest;
- single-driver №340 control with weekly balances separated into work time up to 60:00 and driving up to 56:00;
- driver selection directly inside the №340 / 60-hour balance window;
- editable report formation date for the №340 PDF and the 60-day activity-register PDF;
- one-click opening of the current №340 PDF;
- configurable local/network/cloud-synchronized workspace from v8.70 r9;
- preserved route, timesheet, odometer, waybill and tachograph functionality from the verified v8.70 line.

Distribution for 9.0: START source ZIP, Windows x64 Portable, Windows x64 Setup, macOS arm64 Portable and macOS x86_64 Portable. User databases and personal data are never bundled.
