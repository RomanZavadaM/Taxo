# Taxo v8.56

Контрольний реліз Taxo v8.56 від 11.09.2026.

## Windows

- `Taxo_v8_56_Setup_Windows_x64.exe` — рекомендований інсталятор Windows x64.
- `Taxo_v8_56_Windows_x64_Portable.zip` — portable-версія без інсталяції.
- `Taxo_v8_56_source.zip` — контрольний пакет вихідного коду.
- `SHA256SUMS_RELEASE.txt` — SHA-256 релізних файлів.

Програма та оновлення не містять базу користувача. Постійні дані зберігаються окремо у `%USERPROFILE%\Documents\DriverWorktime\` і не видаляються інсталятором або деінсталятором.

## Основна зміна v8.56

Додано підготовку поточного Бланка підтвердження діяльності до наступного запланованого ТАХО-виїзду. Історичні незакриті проміжки залишаються доступними для аварійного відновлення.

Portable-збірка v8.56 була зібрана і успішно запущена на Windows перед публікацією релізу.
