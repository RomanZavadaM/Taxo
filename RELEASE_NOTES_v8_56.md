# Taxo v8.56

Контрольний реліз Taxo v8.56 від 11.09.2026.

## Що завантажувати

Для звичайного встановлення на Windows x64 використовуйте:

- `Taxo_v8_56_Setup_Windows_x64.exe` — рекомендований інсталятор;
- `Taxo_v8_56_Windows_x64_Portable.zip` — portable-версія без встановлення;
- `Taxo_v8_56_source.zip` — контрольний пакет вихідного коду;
- `SHA256SUMS_RELEASE.txt` — SHA-256 релізних файлів.

Для `Setup.exe` і portable-версії **не потрібно окремо встановлювати Python**.

## Встановлення

1. Завантажте `Taxo_v8_56_Setup_Windows_x64.exe` з цього релізу.
2. Якщо Taxo вже використовувалась раніше, перед оновленням бажано зробити копію каталогу `%USERPROFILE%\Documents\DriverWorktime\`.
3. Запустіть інсталятор і пройдіть стандартні кроки встановлення.
4. Після встановлення запускайте Taxo з ярлика або меню Windows.

Поточний тестовий реліз ще не має комерційного цифрового підпису. Windows SmartScreen може показати попередження про невідомого видавця. Запускайте файл лише якщо він завантажений з офіційного репозиторію `RomanZavadaM/Taxo`; за потреби звірте SHA-256 із `SHA256SUMS_RELEASE.txt`.

## Дані користувача

Програма та оновлення **не містять робочу базу користувача**. Постійні дані зберігаються окремо:

```text
%USERPROFILE%\Documents\DriverWorktime\
```

Основна база:

```text
Documents\DriverWorktime\Data\driver_worktime.sqlite3
```

Тестовий модуль тахографа використовує окрему БД:

```text
Documents\DriverWorktime\Data\tachograph_test.sqlite3
```

Інсталятор/деінсталятор не повинен видаляти цей каталог даних.

## Перший запуск і базова робота

Після запуску рекомендується пройти таку послідовність:

1. перевірити або заповнити картки **водіїв**;
2. перевірити довідники **автомобілів і маршрутів**;
3. сформувати або відкрити **планований графік**;
4. вести фактичні дані у **табелі**;
5. користуватися **Підсумки / контроль** для перевірки даних;
6. формувати потрібні **PDF/XLSX**, графіки та деталізацію;
7. створювати й контролювати **Бланки підтвердження діяльності**;
8. у модулі **ТАХО** імпортувати скани, перевіряти розпізнані інтервали та лише після перевірки використовувати їх у фактичному обліку.

Автоматичне розпізнавання аналогової шайби є допоміжним механізмом і потребує візуальної перевірки перед перенесенням результатів у робочий облік.

## Portable-версія

1. Завантажте `Taxo_v8_56_Windows_x64_Portable.zip`.
2. Повністю розпакуйте архів.
3. Відкрийте папку `Taxo`.
4. Запустіть `Taxo.exe`.

Не переносіть один `Taxo.exe` окремо: portable-збірка має структуру `onedir`, і поруч потрібна папка `_internal`.

```text
Taxo\
├── Taxo.exe
└── _internal\
```

Portable-версія використовує той самий каталог даних `Documents\DriverWorktime`.

## Оновлення Taxo

Перед переходом на нову контрольну версію рекомендовано зробити резервну копію:

```text
%USERPROFILE%\Documents\DriverWorktime\
```

Після цього встановіть новий `Setup.exe`. Оновлення програми не повинно вимагати повторного внесення водіїв, табелів, маршрутів чи інших постійних даних.

## Перевірка SHA-256

У PowerShell:

```powershell
Get-FileHash .\Taxo_v8_56_Setup_Windows_x64.exe -Algorithm SHA256
```

Значення повинно збігатися з відповідним рядком у `SHA256SUMS_RELEASE.txt`.

## Основна зміна v8.56

Додано підготовку **поточного Бланка підтвердження діяльності до наступного запланованого ТАХО-виїзду**. Історичні незакриті проміжки залишаються доступними для аварійного відновлення.

Дата бланка відповідає даті завершення періоду, який він закриває. Якщо два ТАХО-дні йдуть послідовно календарно, зайвий бланк між ними не формується.

## Стан Windows-збірки

Portable-збірка v8.56 була зібрана й успішно запущена на Windows до публікації релізу. Після merge контрольна GitHub Actions-збірка на `main` також завершилася успішно та сформувала інсталятор, portable ZIP, source ZIP і SHA-256 файл.
